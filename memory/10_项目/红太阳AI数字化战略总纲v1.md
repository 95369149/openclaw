**发布日期**: 2026-02-26

## 一、七大项目优先级排序

### P1 提示词工程体系（基础设施）
**理由**: 所有 AI 项目的底层能力，投入产出比最高。不建好这个，后面全是空中楼阁。

### P2 外贸自动拓客（现金流引擎）
**理由**: 直接带来订单，3个月回本。30人销售团队效率翻倍，外贸业务是增长点。

### P3 智能售后/销售客服（降本增效）
**理由**: 7×24h 覆盖，释放人力做高价值工作。WhatsApp 已接入，技术就绪。

### P4 TikTok/YouTube 推广（品牌曝光）
**理由**: 长期品牌建设，配合拓客形成闭环。短视频成本低，试错快。

### P5 谷歌一条龙量产（内容工厂）⚡ 已全线打通
**理由**: Veo 3 Vertex AI API 已开放（$0.10-0.40/秒），Lyria 3 音乐生成已在 Gemini 内（2026-02-18 发布），Imagen 3 API 已开放。全链路可自动化，优先级应提前。

### P6 Seedance 2.0 长视频（高端内容）
**理由**: 5-10分钟工业视频需求低频，且技术未成熟。先用短视频积累经验。

### P7 数字分身建号（实验性）
**理由**: 技术风险高，合规风险大。等前6个项目跑通再考虑。

## 四、全链路内容工厂方案

### 工作流设计（n8n 自动化）

```
触发器：每日 9:00 AM
  ↓
[1] Gemini 3.0 Pro 生成内容
  - 输入：主题关键词（从内容日历读取）
  - 输出：标题 + 正文 + 图片描述 + 视频脚本
  ↓
[2] Imagen 3 生成配图
  - 输入：图片描述（来自步骤1）
  - 输出：1024x1024 PNG（保存到 Google Drive）
  ↓
[3] Runway Gen-4 生成视频（可选）
  - 输入：图片（来自步骤2）+ 运动提示词
  - 输出：10s MP4（保存到 Google Drive）
  ↓
[4] Suno 生成配乐（可选）
  - 输入：视频情绪标签（欢快/专业/科技感）
  - 输出：30s 音频（保存到 Google Drive）
  ↓
[5] 自动发布
  - 图文：发布到公众号/小红书（API 对接）
  - 视频：上传到抖音/TikTok（手动或 API）
  ↓
[6] 数据回传
  - 记录发布时间/平台/链接到 Notion
  - 次日抓取播放量/点赞数，写入数据看板
```

### 技术实现细节

**n8n 节点配置**:
1. **Schedule Trigger**: Cron 表达式 `0 9 * * *`（每日9点）
2. **HTTP Request**: 调用 Gemini API（`https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:generateContent`）
3. **HTTP Request**: 调用 Imagen 3 API（`https://aiplatform.googleapis.com/v1/projects/{project}/locations/us-central1/publishers/google/models/imagen-3:predict`）
4. **HTTP Request**: 调用 Runway API（需申请 API 密钥）
5. **Google Drive**: 保存生成文件
6. **Webhook**: 触发发布脚本（Python/Node.js）

**成本优化**:
- Gemini 用免费额度（15 次/分钟）
- Imagen 3 用 AI Studio 免费额度（1000 张/月）
- Runway 按需购买 credits（$12/100 credits，约 10 个视频）
- Suno 用 Pro 版（$10/月，500 首）

**容错机制**:
- API 调用失败 → 重试 3 次 → 发送告警到 Telegram
- 生成内容不合规 → 跳过发布 → 人工审核
- 每日生成日志保存到 `/Users/apple/.openclaw/workspace/memory/logs/`
