# Kitt 超级大脑 — 模型军团路由规则
> 项目代号：SuperBrain
> 创建：2026-02-19
> 状态：Phase 1 实施中

## 核心理念
Kitt 是总指挥，不是传话筒。
厂长只管提需求，Kitt 自己判断任务类型，自动派给最合适的模型。
厂长不需要知道谁在干活，只需要看到结果。

## 自动路由原则
1. 厂长发消息 → Kitt（Gemini 3 Pro）接收
2. Kitt 5 秒内判断任务类型（聊天/代码/推理/抓取/生成/分析）
3. 简单任务 → Kitt 自己处理
4. 复杂任务 → Kitt 自动 spawn 到对应模型，拿到结果后汇报厂长
5. 厂长全程无感，只看到 Kitt 一个人在干活

## 路由规则（按任务类型）

### 1. 日常聊天/快速问答
→ 主脑（Gemini 3 Pro）直接回复
- 不需要 spawn，主会话处理
- 包括：闲聊、简单查询、天气、提醒

### 2. 代码/配置修改
→ 代码手（Sonnet）
- 修改 openclaw.json、写脚本、debug
- `sessions_spawn(model="mynewapi/claude-sonnet-4-6")`

### 3. 复杂推理/架构设计
→ 推理王（Opus）
- 系统架构、长期规划、复杂分析
- 仅在 Sonnet 搞不定时升级
- `sessions_spawn(model="mynewapi/claude-opus-4-6")`

### 4. 中文内容生成
→ 中文王（DeepSeek V3.2）或 中文笔（Qwen3）
- 文案、摘要、翻译、文档提取
- DeepSeek 优先（更稳定），Qwen 备用
- `sessions_spawn(model="siliconflow/deepseek-ai/DeepSeek-V3.2")`

### 5. 信息抓取/上网冲浪
→ 快枪手（Groq Llama）
- 网页抓取、搜索汇总、英文资料
- 速度快，适合批量任务
- `sessions_spawn(model="groq/llama-3.3-70b-versatile")`

### 6. 实时热点/X平台
→ 叛逆者（Grok 4）
- X/Twitter 热点、不审查内容、实时信息
- 付费，仅在需要时调用
- `sessions_spawn(model="v1api/grok-4")`

### 7. 数学/逻辑推理
→ 深思者（DeepSeek R1）
- 数学题、逻辑推理链、数据分析
- `sessions_spawn(model="v1api/deepseek-r1")`

### 8. 图片分析
→ 闪电侠（Gemini Flash）或 豆包
- 图片理解、OCR、视觉问答
- imageModel 已配置自动路由

### 9. 长文档处理（待接入 Kimi 后）
→ 长文王（Kimi K2.5）
- 超长文档阅读、论文分析、合同审查
- 256K 上下文，中文优化

### 10. 记忆/大脑维护
→ 代码手（Sonnet）
- 修改 SOUL.md / MEMORY.md / 强制规则
- 需要理解上下文 + 精确修改

## 成本控制
- 免费模型优先：Gemini > DeepSeek > Groq > Qwen
- 付费模型按需：Sonnet > Grok > R1 > Opus
- Opus 是最后手段，不主动调用
- 每日成本目标：< $1
