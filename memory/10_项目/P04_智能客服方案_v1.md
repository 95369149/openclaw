# P04 智能售后/销售客服方案 v1

## 1. 需求分析
针对济南红太阳数控设备有限公司（HTYCNC）的60人团队规模及主营数控木工设备业务，AI智能客服系统的核心需求如下：
- **售前场景**：
  - 产品参数解答：能够快速调取开料机、封边机等设备的参数配置。
  - 报价与选型：基于客户的加工需求（如板材材质、产量要求）推荐合适的设备型号并给出初步报价区间。
- **售后场景**：
  - 故障诊断：通过多轮对话引导客户排查数控设备常见故障（如主轴异响、驱动报警等）。
  - 维修与配件查询：提供对应型号设备的维修视频或图文指导，以及配件更换清单。
  - 工单创建：无法通过AI解决的复杂故障，自动生成售后工单流转至人工技术团队。
- **多语言支持**：
  - 考虑到外贸业务，系统必须原生支持中文和英文，并能根据客户语种自动切换，保障跨国沟通无障碍。

## 2. 平台选型对比

| 维度 | Coze（字节跳动） | Dify（开源） | FastGPT（开源） | 自建（完全定制） |
|---|---|---|---|---|
| **核心优势** | 丰富的插件生态，多渠道一键发布（如微信、飞书、WhatsApp等），免部署。 | 强大的RAG（检索增强生成）能力，支持私有化部署，数据安全性高。 | 专注知识库问答，操作极简，支持深度定制复杂业务流。 | 完全自主可控，深度绑定企业内部ERP/CRM。 |
| **部署难度** | 极低（SaaS模式，开箱即用） | 中（需准备服务器，可通过Docker部署） | 中（需服务器，支持私有化） | 极高（需专业开发团队） |
| **知识库管理** | 基础，适合结构化文档和网页抓取。 | 优秀，支持多格式文档，分块与召回策略灵活。 | 极佳，专门针对知识库优化，准确率高。 | 依开发能力而定。 |
| **多语言支持** | 强（依托底层大模型，如豆包、GPT-4等） | 强（可接入各家大模型） | 强（可接入各家大模型） | 强 |
| **API与集成** | 良好，提供开放API及丰富的预置工作流。 | 极强，设计之初即为开发者提供便利的API及节点流转。 | 强，易于与现有系统集成。 | 完美适配 |
| **成本/价格** | 免费/低（国内版基础功能免费，海外版按量计费） | 免费（社区版）或按需付费（云端版），另需模型API成本及服务器成本。 | 免费（开源版），另需模型API成本及服务器成本。 | 研发及维护成本高昂（几十万起步） |

**结论与推荐**：
综合考量HTYCNC 60人团队规模及预算，**优先推荐使用 FastGPT 或 Dify**。这两者在知识库问答（特别是产品手册和FAQ）方面表现优异，且开源免费，数据可私有化掌控，成本可控。如果对快速上线及多渠道一键分发有极高要求且对数据完全私有化要求不苛刻，**Coze** 是最快见效的方案。

## 3. 知识库建设
高质量的知识库是智能客服的灵魂：
- **产品手册库**：将数控开料机、封边机、排钻的所有型号说明书、参数表、操作手册（PDF/Word格式）导入系统。
- **FAQ库（售后）**：整理历史工单，提取高频故障现象及标准解决方案，形成问答对（Q&A）。例如：“主轴不转怎么办？” -> “1. 检查变频器是否报警...”。
- **话术库（售前）**：录入销冠的优秀销售话术、产品卖点对比分析、常见竞品应对策略，辅助AI进行促单转化。

## 4. 接入渠道
为实现全域覆盖，系统需接入以下触点：
- **官网在线客服**：通过嵌入JS代码，在公司中英文官网右下角悬浮AI对话框。
- **WhatsApp Business**：外贸客户的核心沟通渠道，通过官方API接入，实现海外全天候自动回复与营销推送。
- **微信生态**：接入微信公众号菜单栏及微信小程序，方便国内客户随时随地发起咨询。

## 5. 工单流转机制
AI无法替代所有人工，需设定清晰的“兜底”机制：
1. **意图识别与拦截**：AI首先尝试解决问题。
2. **人工转接条件**：当客户情绪负面、连续3次提问未解决、或主动要求“转人工”时，触发转接机制。
3. **工单生成**：AI自动总结历史聊天记录（提取设备型号、故障现象、客户联系方式），通过Webhook推送至企业微信/钉钉或内部CRM工单系统。
4. **人工跟进**：售后工程师接单，直接定位问题，避免客户重复描述。

## 6. 预算估算（基于FastGPT/Dify SaaS版或轻量私有化）
- **搭建与部署成本**：
  - 若使用云端SaaS版：0元。
  - 若轻量级私有化部署（阿里云/腾讯云基础服务器）：约 3000-5000元/年。
- **模型API调用成本**：采用高性价比的国产大模型（如DeepSeek、Kimi或百川等），预计月度调用费在 100-500元人民币（视咨询量而定）。
- **人力维护成本**：需指定1名内部人员兼职“AI训练师”，每周耗时约2-4小时用于补充新知识、修正AI错答。
- **综合月度运营成本**：极低（<1000元）。

## 7. 实施路线图（4周上线计划）
- **第1周：需求梳理与平台初始化**。确定选用平台（如FastGPT），注册账号/完成部署。收集各部门产品手册、报价单和历史FAQ。
- **第2周：知识库构建与模型调试**。导入并清洗数据，设置Prompt（系统提示词），内部团队开始高强度内测，发现并纠正AI的“幻觉”与错误回答。
- **第3周：渠道集成与工作流测试**。完成微信公众号、官网及WhatsApp的API对接。跑通“AI无法解决 -> 自动生成工单推送至企微”的流转闭环。
- **第4周：灰度上线与培训**。先对部分老客户开放测试，随后全渠道上线。对销售和售后团队进行使用培训，建立长效的“AI错题本”反馈机制。
