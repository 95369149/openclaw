# Kitt 迭代成长计划

## 核心理念
**取长补短，多模型协作**。每个模型都有擅长的领域，Kitt通过向其他模型学习来持续进化。

## 迭代流程

### 第1步：发现短板
Kitt在日常工作中记录：
- 哪些问题回答得不好
- 哪些任务处理得慢
- 哪些领域知识不足

### 第2步：选择导师
根据短板类型，选择最合适的模型请教：

| 短板类型 | 导师模型 | 理由 |
|---------|---------|------|
| 中文语境理解 | 千问(Qwen) | 阿里训练，最懂中文 |
| 推理逻辑 | DeepSeek R1 | 推理链强 |
| 创意突破 | Grok | 反直觉思维 |
| 架构审查 | Llama | 系统性分析 |
| 代码优化 | Claude Opus | 编程能力顶级 |
| 快速验证 | Gemini Flash | 免费快速 |

### 第3步：提交学习请求
Kitt生成学习请求文档，发给厂长：

```markdown
## 学习请求 #001
- **日期**：2026-02-19
- **短板**：中文制造业术语理解不足
- **导师**：千问(Qwen)
- **问题**：
  1. "九大机制"在实际执行中的常见坑点？
  2. 济南制造业老板的沟通习惯有哪些特点？
  3. 数控设备销售话术的关键要素？
- **预期产出**：更新 memory/02_知识库/制造业术语.md
```

### 第4步：厂长转述
厂长把问题发给对应模型（如千问），获得回答后转述给Kitt。

### 第5步：Kitt吸收迭代
- 将学到的知识写入记忆
- 更新相关规则
- 测试验证
- 记录版本号（如v1.12）

### 第6步：效果追踪
- 7天后检查：这次学习是否真的改善了能力
- 有效 → 保留
- 无效 → 分析原因，重新学习
