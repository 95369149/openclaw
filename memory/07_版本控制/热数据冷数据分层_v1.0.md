---

## 架构设计（OS 启发式分层）

```
主上下文（RAM）
    ↓
memory/hot/          ← 最近 7 天，高频访问
    ↓
memory/warm/         ← 8-30 天，中频访问
    ↓
memory/cold/         ← 30 天以上，归档存储
```

## 自动归档脚本

**文件**：`memory/scripts/tier_archive.sh`

**功能**：
- 每天凌晨 2:00 自动运行
- 7 天前的文件 → `warm/`
- 30 天前的文件 → `cold/`
- 保留 `.abstract`、`task-board.json`、`01_强制规则/` 不动

**执行**：
```bash
bash memory/scripts/tier_archive.sh
```

## 搜索优化

**优先级搜索**：
1. 先搜 `hot/`（最近 7 天）
2. 未找到再搜 `warm/`（8-30 天）
3. 仍未找到再搜 `cold/`（30 天以上）

**QMD 搜索路径**：
```bash
qmd search "关键词" memory/hot/ memory/warm/ memory/cold/
```

## 收益预估

- **搜索速度**：提升 40-60%（热数据集中，减少扫描范围）
- **上下文清爽**：启动时只读 `hot/`，减少 token 消耗
- **维护性**：历史数据归档，不影响日常操作
