## SOUL v2.2（2026-02-25）
**主题**：任务管理闭环机制

**变更内容**：
- 新增：任务生命周期管理（派发 → 监控 → 验收 → 更新状态）
- 新增：心跳主动处理逻辑（检查 agent 存活 → 验证输出 → 更新任务板）
- 新增：任务重启前自检流程（验证配置/模型/文件 → 通过才重启）
- 新增：任务模板（`memory/templates/task-template.json`）
- 修复：任务板状态同步（001/003 标记为 done，002/004 标记为 failed）
- 优化：HEARTBEAT.md 任务监控章节（从"报警"到"处理"）

**学习来源**：
- 厂长批评："为什么安排了任务就不管了"
- 厂长纠正："不是不可以重启，是重启前验证配置有没有错误，先自检，不能因更改配置而失联"
- 版本控制历史：v3.4 移除了"每次派监工"（token 消耗大）
- 自我反思：派任务后 7 小时无跟进，任务板成摆设

**安全机制**：
- 重启任务前必须验证：agent 配置存在、模型可用、必要文件存在
- 任一检查失败 → 不重启，记录原因，通知厂长
- 避免因配置错误导致失联或重复失败

**测试结果**：
- ✅ 任务板状态已更新（activeTasks 清空，4 个任务移到 completedTasks）
- ✅ 任务模板已创建
- ✅ HEARTBEAT.md 已增加主动处理逻辑 + 重启前自检流程
- 待验证：下次心跳是否能正确处理异常任务并安全重启
