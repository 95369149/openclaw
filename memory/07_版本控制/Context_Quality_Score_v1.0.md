# Context Quality Score 评分系统 v1.0

> 为每次子 Agent 派发打分（0-100），低于 60 分自动补充上下文
> 创建时间：2026-03-14

---

## 评分维度（5 个维度，各 20 分）

### 1. 任务清晰度（20 分）

- **20 分**：任务描述具体、可执行、有明确交付物
- **15 分**：任务描述清晰，但缺少部分细节
- **10 分**：任务描述模糊，需要猜测意图
- **5 分**：任务描述不清，无法直接执行
- **0 分**：任务描述缺失或完全不可理解

**检查点**：

- ✅ 有明确的动词（写、分析、生成、修复）
- ✅ 有明确的输出格式（文件路径、字数、结构）
- ✅ 有明确的成功标准

### 2. 背景信息完整度（20 分）

- **20 分**：提供了所有必要的背景信息和上下文
- **15 分**：提供了主要背景，但缺少部分细节
- **10 分**：背景信息不足，需要子 Agent 自己查找
- **5 分**：几乎没有背景信息
- **0 分**：完全没有背景信息

**检查点**：

- ✅ 相关文件路径已提供
- ✅ 历史决策/已有方案已说明
- ✅ 约束条件已明确

### 3. 输入数据可用性（20 分）

- **20 分**：所有输入数据已准备好，路径正确
- **15 分**：主要数据已准备，部分需要查找
- **10 分**：数据路径不明确，需要搜索
- **5 分**：数据缺失，需要子 Agent 自己收集
- **0 分**：完全没有输入数据

**检查点**：

- ✅ 文件路径存在且可读
- ✅ API 凭证已配置
- ✅ 依赖工具已安装

### 4. 输出规范明确度（20 分）

- **20 分**：输出格式、路径、命名规则完全明确
- **15 分**：输出格式明确，但路径/命名需要推断
- **10 分**：输出格式模糊，需要猜测
- **5 分**：输出要求不清
- **0 分**：没有输出要求

**检查点**：

- ✅ 输出文件路径明确（含目录和文件名）
- ✅ 输出格式明确（Markdown/JSON/代码）
- ✅ 输出长度/结构有要求

### 5. 错误处理指引（20 分）

- **20 分**：明确了失败场景和处理方式
- **15 分**：提到了可能的问题
- **10 分**：没有错误处理指引，但任务简单
- **5 分**：复杂任务但没有错误处理指引
- **0 分**：高风险任务且没有任何指引

**检查点**：

- ✅ 明确了"如果失败怎么办"
- ✅ 提供了兜底方案
- ✅ 明确了不该做什么

## 评分示例

### ❌ 低分示例（35 分）

```
task: "帮我写个报告"
```

- 任务清晰度：5 分（动词模糊，无交付物）
- 背景信息：0 分（完全没有）
- 输入数据：0 分（没有）
- 输出规范：10 分（隐含是文档，但格式不明）
- 错误处理：20 分（任务简单，不需要）

### ✅ 高分示例（95 分）

```
task: "
⚠️ 强制前置步骤：
1. read /Users/apple/.openclaw/workspace/memory/task-board.json
2. exec: ls /Users/apple/.openclaw/workspace/memory/shared/ | tail -5
3. 创建文件 /Users/apple/.openclaw/workspace/memory/shared/2026-03-14_deep_销售分析.md

任务：分析 2026-02 销售数据
背景：数据在 /path/to/sales.xlsx，需要计算同比环比
输出：Markdown 报告，包含：销售额、客单价、成交率，控制在 1000 字以内
失败处理：如果文件不存在，输出错误信息到 manifest 的 notes 字段
"
```

- 任务清晰度：20 分（动词明确，交付物清晰）
- 背景信息：20 分（数据路径、计算要求都有）
- 输入数据：20 分（路径明确）
- 输出规范：20 分（格式、路径、长度都明确）
- 错误处理：15 分（有失败处理，但不够详细）

## 自动补充规则

**分数 < 60 分时，Jimmy 必须补充上下文：**

1. **任务清晰度不足**：
   - 追问厂长："你要的是什么格式？多长？"
   - 或者根据历史任务推断

2. **背景信息不足**：
   - 自动读取相关文件（task-board.json、最近的 shared/ 文件）
   - 追加到任务描述

3. **输入数据不足**：
   - 搜索相关文件路径
   - 检查文件是否存在

4. **输出规范不足**：
   - 根据任务类型设置默认输出路径
   - 明确输出格式

5. **错误处理不足**：
   - 添加默认错误处理："失败时写入 notes 字段"
