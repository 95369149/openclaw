# 醒来自检流程

> **触发时机**: Context 重置、Gateway 重启、长时间休眠后首次对话  
> **最后更新**: 2026-02-25

---

## 第一步：读大脑中枢（强制）

**必须第一时间读取** `memory/00_大脑中枢.md`，这是唯一真相源。

包含：
- 当前系统架构（6 agents 配置、模型分配）
- 外链配置（Perplexity 3 Tab、豆包 Tab ID）
- 备份策略（GitHub 为主，iCloud 手动）
- 关键文件位置和数量
- API 余额和配额状态

**如果发现大脑中枢信息过时**：
- 立即更新（agent 模型、文件数量、余额等）
- 记录更新时间
- 不要等厂长提醒

---

## 第二步：读今日日志

读取 `memory/05_日常日志/YYYY-MM-DD.md`（当天日期）

- 如果不存在 → 创建新日志
- 如果存在 → 读取最新进展，了解今天已完成的工作

---

## 第三步：检查待办事项

1. 读取 `memory/task-board.json`（任务看板）
2. 检查是否有未完成的任务
3. 检查是否有需要跟进的子 agent 任务

---

## 第四步：快速健康检查

1. **API 可用性** - ping 核心 API（mynewapi、xjrouter）
2. **Gateway 状态** - `openclaw gateway status`
3. **余额告警** - 如果上次检查超过 24 小时，查询余额

---

## 第五步：汇报状态

向厂长简要汇报：
- 醒来时间
- 大脑中枢状态（是否需要更新）
- 今日进度
- 待办任务
- 健康检查结果

格式：简洁、数据化、可执行

---

## 禁止行为

- ❌ 跳过读大脑中枢
- ❌ 发现大脑过时不更新
- ❌ 不读今日日志就开始干活
- ❌ 冗长的自检报告（控制在 5 句话以内）

---

## 更新大脑的时机

随时更新，不要等：
- Agent 模型配置变更 → 立即更新
- API 余额变化 > $5 → 立即更新
- 文件数量变化 > 50 → 立即更新
- 备份策略调整 → 立即更新
- 外链配置变更 → 立即更新

**原则**：大脑中枢永远是最新的，不是历史记录。
