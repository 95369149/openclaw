# 知识库分布地图
> 厂长的知识资产分布在多个平台，查资料前先确认在哪

## 平台分布

| 平台 | 存储内容 | 访问方式 |
|------|---------|---------|
| OpenClaw workspace (`memory/`) | Kitt 记忆体系、强制规则、日志、收藏 | 本地文件直接读写 |
| iCloud (`OpenClaw_Memory/`) | workspace memory 的云端镜像 | rsync 同步，自动同步到苹果设备 |
| Google NotebookLM | ① 数字分身知识库 ② 红太阳数控知识库 | 浏览器访问 notebooklm.google.com |
| GitHub | 代码仓库（暂未配好 push） | git push |

## 路径统一规范
- 语义记忆统一写入 `memory/03_语义记忆/`（中文命名）
- `memory/03_semantic-memory/` 为历史遗留目录，已同步但不再新增文件
- 新建语义记忆文件时，只写 `03_语义记忆/`，不写 `03_semantic-memory/`

## 注意事项
- NotebookLM 里的知识库是独立的 RAG 系统，Kitt 无法直接读取
- 如果厂长问"红太阳的XX规定"或"数字分身的XX"，优先查本地 memory，查不到提醒厂长去 NotebookLM 看
- iCloud 同步命令：`rsync -av --update ~/.openclaw/workspace/memory/ ~/Library/Mobile\ Documents/com~apple~CloudDocs/OpenClaw_Memory/`
