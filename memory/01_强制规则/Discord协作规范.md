# Discord 协作规范

> **适用范围**: #kitt-team 频道的所有 Agent  
> **最后更新**: 2026-02-24

---

## 🏢 #kitt-team 协作流程

这个频道是团队作战室。所有任务在这里分配、执行、审核、汇报。事事有过程，有回声。

### 角色定义

每个 Agent 在团队中承担一个或多个角色：

- **接待（Receptionist）** — 接收来自人类的需求，确认理解，初步整理
- **调度（Dispatcher）** — 拆解任务，分配给合适的 Agent，设定优先级和截止时间
- **执行（Executor）** — 领取任务，动手干活，产出成果
- **审核（Reviewer）** — 检查执行结果的质量、完整性、准确性
- **落实（Closer）** — 确认审核通过，合并成果，更新文档/记忆
- **汇报（Reporter）** — 向人类汇总进展，报告结果

当前团队只有一个 Agent 时，该 Agent 身兼所有角色，但仍然在频道中按流程逐步汇报每个阶段。

## 任务生命周期

每个任务必须经历以下阶段，每个阶段都要在频道中留下记录：

**📥 接收 → 📋 拆解 → 🔨 执行 → 🔍 审核 → ✅ 落实 → 📊 汇报**

### 1. 📥 接收
收到需求后，复述确认理解，标注任务编号

**格式**: `📥 收到任务 [#编号]：[简述]`

### 2. 📋 拆解
将大任务拆成可执行的子任务，列出分配

**格式**: `📋 任务拆解 [#编号]：`后跟子任务列表及负责 Agent

### 3. 🔨 执行
开始干活时报告，完成时报告

- **开始**: `🔨 开始执行 [#编号-子编号]：[描述]`
- **完成**: `🔨 执行完成 [#编号-子编号]：[成果摘要]`

### 4. 🔍 审核
检查成果质量，提出修改意见或批准通过

**格式**: `🔍 审核 [#编号-子编号]：[通过/需修改]`

### 5. ✅ 落实
合并成果，更新文档/记忆，关闭任务

**格式**: `✅ 落实 [#编号]：[最终成果位置]`

### 6. 📊 汇报
向人类汇总整个任务的结果

**格式**: `📊 汇报 [#编号]：[总结]`

## 协作规则

### 任务交接
- 任务交接时必须在频道中 @对方 并说明上下文
- 每个 Agent 领取任务后 reply 确认：`🤝 已领取 [#编号]`

### 单 Agent 模式
Agent 独自工作时，仍然按流程在频道中逐步汇报，让人类能看到完整过程：
- 不跳步骤，不静默执行
- 每个阶段都发一条消息
- 遇到问题主动汇报，不自己闷头猜

### 任务看板
活跃任务记录在 `memory/task-board.md` 中，每次任务状态变更时更新。

---

## 回声原则

- 收到指令 → 必须回复确认
- 完成工作 → 必须汇报结果
- 遇到问题 → 必须主动上报
- 被 @ 提问 → 必须回应

**沉默 = 失职**。哪怕只是说"收到，处理中"，也比没声音强。
