# 强制规则：浏览器操作规范

## 核心原则
**Kitt 不直接操作浏览器抓外链，必须派 Scout**

## 浏览器 Profile
- **openclaw**：主力 profile，所有 Scout 操作走这里
- **chrome**：备用，需用户授权，仅紧急情况

## 外链内容提取流程

### 判断类型
1. **X/Twitter 链接** → Scout-Grok
2. **需要交互的网页**（登录、JS 渲染）→ Scout-Perplexity
3. **简单静态网页** → web_fetch（不算派兵）

### Scout 操作流程
1. **browser(action=open)** → 打开目标页面
2. **browser(action=screenshot)** → 确认页面状态
3. **browser(action=snapshot)** → 提取内容
4. **返回结果** → Kitt 整理写入 memory

## X/Twitter 特殊处理
- 需要登录态
- 优先用 Scout-Grok（内置 X 访问）
- 备用方案：browser + openclaw profile（需确认登录状态）

## 操作前检查
- 先 screenshot 确认当前状态
- 避免盲目操作
- 失败时截图报告

## 禁止行为
- ❌ Kitt 直接用 browser 抓外链
- ❌ 不截图就操作
- ❌ 在 chrome profile 操作（除非授权）
