# 强制规则：文档脱敏规范

## 核心原则
**任何发送到外部的内容都必须脱敏**

## 必须删除的信息

### 1. 认证信息
- API key（所有平台）
- 密码
- Token
- 证书

### 2. 个人信息
- 真实姓名
- 电话号码
- 邮箱地址
- 家庭住址
- 身份证号

### 3. 公司信息
- 公司全名（用 [COMPANY_NAME]）
- 员工姓名
- 客户信息
- 财务数据
- 商业机密

### 4. 基础设施
- 服务器 IP 地址
- 端口号
- 域名（内部）
- 数据库连接串

### 5. 代码和配置
- 完整的配置文件（只贴相关部分）
- 包含敏感信息的代码
- 内部工具路径

## 脱敏方法

### 占位符替换
```
原始：apiKey: "sk-jhpciggnnbqbquuuxwfrwmkvtkgylhwfqosozetqnxerjjyo"
脱敏：apiKey: "[SILICONFLOW_API_KEY_1]"

原始：济南红太阳数控设备有限公司
脱敏：[COMPANY_NAME]

原始：厂长：张三，电话：138****1234
脱敏：[USER_NAME]，电话：[PHONE]

原始：服务器：192.168.1.100:8080
脱敏：服务器：[SERVER_IP]:[PORT]
```

### 结构保留
- 保留配置结构（JSON/YAML 格式）
- 保留关键字段名
- 只替换敏感值

### 示例对比

#### ❌ 错误（未脱敏）
```json
{
  "siliconflow": {
    "apiKey": "sk-jhpciggnnbqbquuuxwfrwmkvtkgylhwfqosozetqnxerjjyo",
    "models": ["deepseek-ai/DeepSeek-V3.2"]
  },
  "company": "济南红太阳数控设备有限公司",
  "owner": "张三",
  "phone": "13812345678"
}
```

#### ✅ 正确（已脱敏）
```json
{
  "siliconflow": {
    "apiKey": "[SILICONFLOW_API_KEY]",
    "models": ["deepseek-ai/DeepSeek-V3.2"]
  },
  "company": "[COMPANY_NAME]",
  "owner": "[USER_NAME]",
  "phone": "[PHONE]"
}
```

## 适用场景
1. **外部模型碰撞**：发给 Perplexity/Grok/Gemini
2. **GitHub issue**：提交问题报告
3. **Discord 公开频道**：分享配置
4. **文档示例**：写教程或文档
5. **截图分享**：任何可能外传的截图

## 检查清单
发送前必须检查：
- [ ] 所有 API key 已替换
- [ ] 所有密码已删除
- [ ] 个人信息已脱敏
- [ ] 公司信息已脱敏
- [ ] 服务器地址已脱敏
- [ ] 内部路径已脱敏

## 违规后果
- 泄露 API key → 立即撤销，重新生成
- 泄露个人信息 → 严重信任危机
- 泄露商业机密 → 法律风险
