# 配置安全规则（2026-02-24 合并版）

## 权限
- **只有 jimmy 有权修改** `openclaw.json`、`SOUL.md`、`IDENTITY.md`、`HEARTBEAT.md`、`memory/` 框架文件
- 其他 agent 只能建议，通过 sessions_send 发给 jimmy，jimmy 审查后执行
- 违反 = 事故，写反思日志

## 变更流程
1. **备份**：`cp ~/.openclaw/openclaw.json ~/.openclaw/openclaw.json.pre-change`
2. **修改**：直接编辑 JSON 或 `openclaw config set`
3. **验证**：检查 JSON 格式（`jq . ~/.openclaw/openclaw.json > /dev/null`）
4. **审查**：确认 agents.list、fallback 链、providers 完整
5. **重启**：`openclaw gateway restart`
6. **确认**：`openclaw status` 检查三渠道在线
7. **失败回滚**：`cp ~/.openclaw/openclaw.json.bak ~/.openclaw/openclaw.json && openclaw gateway restart`

## Fallback 链规则
- 免费模型排前面，付费模型兜底
- 跨平台交替（SiliconFlow → Groq → Gemini → mynewapi）
- Claude Opus 永远不能被移除（终极保命）
- 欠费模型立即移除
- Fallback 链至少 3 个模型，至少 1 个免费

## 禁止事项
- ❌ `openclaw configure` 直接运行（会覆盖整个配置）
- ❌ 改完不验证就重启
- ❌ 所有免费模型放同一平台（单点故障）
- ❌ 恢复旧备份不检查 provider 完整性
