# 文档清理安全流程 v1.0

## 核心原则
**删除前必须比对内容，不能只看时间和文件名**

## 安全流程

### 1. 识别冗余文档
```bash
# 列出所有相关文档
find memory/01_强制规则 -name "*Agent*" -o -name "*调度*" -o -name "*路由*"
```

### 2. 比对内容（必须执行）
```bash
# 对于每个疑似冗余的文档：
# 1. 读取文档内容
# 2. 与保留的核心文档比对
# 3. 检查是否有独特内容
# 4. 确认是否真的冗余
```

### 3. 决策标准
**保留条件**（满足任一即保留）：
- 包含核心文档没有的信息
- 版本号更新
- 修改时间更晚且内容不同
- 有独特的配置/规则/案例

**删除条件**（必须全部满足）：
- 内容完全被其他文档覆盖
- 版本号更旧
- 明确标记为"已废弃"或"已合并"

### 4. 备份机制
```bash
# 删除前必须备份
mkdir -p memory/90_归档/文档清理_$(date +%Y%m%d)
cp [要删除的文件] memory/90_归档/文档清理_$(date +%Y%m%d)/
```

### 5. 记录变更
```markdown
# 在今日日志中记录：
- 删除了哪些文档
- 删除原因
- 备份位置
- 保留了哪些文档
```

## 禁止行为

❌ **只看文件名就删除**  
❌ **只看修改时间就删除**  
❌ **批量删除不检查内容**  
❌ **删除前不备份**  
❌ **删除后不记录**
