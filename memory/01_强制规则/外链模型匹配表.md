# 外链模型匹配表 v2.0

> 核心原则：内部 agent 是手脚，外链模型是大脑。小马拉大车。
> 每个内部 agent 固定绑定一个外链模型，根据双方优势互补。
> 最后更新：2026-02-27

---

## 一、外链入口

### 入口1：Perplexity Pro（浏览器，串行）
- 地址：https://www.perplexity.ai
- 规则：**每次只能用一个模型，用完关页面，下一个再开**
- 可用模型：GPT-5.3、Grok 4.2、Claude 4.6、Kimi K2.5、Sonar、Gemini 3.1 Pro

### 入口2：豆包（独立，可并行）
- 调用：`python3 ~/bin/doubao_client.py "问题"` 或浏览器 https://www.doubao.com
- 规则：**独立于 Perplexity，可与任何 Perplexity 任务并行**
- 任何 agent 都可以调用豆包

## 三、调度规则

### Perplexity 串行规则
1. 每次只开一个 Perplexity 页面，只用一个模型
2. 当前任务完成 → 关闭浏览器 → 下一个任务再开新页面选新模型
3. 不同 agent 的 Perplexity 任务必须排队，不能并行

### 频率控制
1. 两个 Perplexity 任务之间间隔 ≥2 分钟
2. 同一模型连续使用间隔 ≥30 秒
3. 思考模式任务合计 ≤15 次/天
4. 单个任务内多轮对话不限频率（同一个页面内追问不算新任务）

### 代理环境（厂长操作，非子 agent）
gateway 启动需要代理环境：
```bash
HTTPS_PROXY=http://127.0.0.1:7897 openclaw gateway --force --token "admin123"
```
这是厂长每次开终端时的操作，子 agent 不需要管代理。
浏览器工具（browser）走的是系统已配好的代理，子 agent 直接用即可。

### 豆包并行规则
1. 豆包任务可以和 Perplexity 任务同时进行
2. 豆包任务之间也可以并行（通过 doubao_client.py）

### 多轮对话规则（核心中的核心！）
1. 子 agent 在 Perplexity 窗口里**必须多轮对话**，把任务聊透
2. 第一轮拿到回答后，继续追问：
   - "这部分能展开说说吗？"
   - "给我具体的实施步骤"
   - "代码/模板能写出来吗？"
   - "还有什么遗漏的？"
   - "帮我优化一下这段"
3. 直到拿到**完整、详细、可直接使用**的结果才算完成
4. **绝对禁止一问一答就关窗口** — 那不叫用外链，那叫浪费外链
5. 一个任务在同一个窗口里聊 3-10 轮是正常的
6. 把外链模型当成一个专家顾问，深度讨论，不是搜索引擎

## 四、任务派发流程

### 步骤
```
1. jimmy 收到任务
2. 判断任务类型 → 确定用哪个 agent + 外链模型
3. 检查当前 Perplexity 是否空闲
   - 空闲 → 立即派发
   - 占用 → 排队等待（或先派豆包类任务）
4. 派发 task，写明：
   - 绑定的外链模型名称
   - Perplexity 操作步骤
   - 要问的核心问题
   - 追问方向（预设 2-3 个）
   - 输出格式要求
5. 子 agent 执行：开浏览器 → 选模型 → 多轮对话 → 提取整理 → 写文件 → 关浏览器
6. 完成后 jimmy 收到通知 → 派下一个排队任务
```

### 派发模板（Perplexity）
```
sessions_spawn(agentId="<agent>", task="
任务：<一句话描述>

⚠️ 你的外链大脑是 Perplexity 上的 <模型名>。你是搬运工+整理者，它是大脑。

操作步骤：
1. browser(action='start', profile='openclaw')
2. browser(action='open', targetUrl='https://www.perplexity.ai')
3. 用 snapshot 找到模型选择按钮 → 点击 → 选 '<模型名>'
4. 确认思考模式已开启
5. 在输入框输入第一个问题（见下方）
6. 等待回复完成，用 snapshot 或 evaluate 提取内容
7. 如果回答不够深入，继续追问（见追问方向）
8. 可以多轮对话，直到任务搞清楚
9. 最终结果整理成 markdown 写入文件
10. browser(action='stop') 释放资源

第一个问题：
<核心问题>

追问方向（按需使用）：
- <追问1>
- <追问2>
- <追问3>

输出：<格式要求>
完成后写入 memory/shared/<日期>_<agent>_<简述>.md
")
```

### 派发模板（豆包）
```
sessions_spawn(agentId="<agent>", task="
任务：<一句话描述>

⚠️ 用豆包完成中文润色/改写。豆包独立于 Perplexity，可以直接调用。

操作步骤：
1. 读取原始内容：read('<文件路径>')
2. 调用豆包：exec('python3 ~/bin/doubao_client.py \"<润色指令+内容摘要>\"')
3. 如果结果不满意，再调一次豆包修改
4. 整理输出写入文件

输出：<格式要求>
完成后写入 memory/shared/<日期>_<agent>_<简述>.md
")
```
