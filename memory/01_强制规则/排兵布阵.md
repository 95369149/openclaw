## 核心理念

**单入口，智能路由，成本优先**：
- 厂长只和 jimmy 对话
- jimmy 判断意图桶 → 派发对应 agent
- 免费模型优先，付费模型兜底
- 简单任务不派发，复杂任务才调度

## Agent 编制（5员）

> ⚠️ 以下必须与 `openclaw.json agents.list` 完全一致。
> 变更配置后必须同步更新本文件，反之亦然。
> v5.0: coder 已废弃（与 deep 职责重叠，agentStats total=0）

| Agent | 模型（实际配置） | 层级 | 定位 | 成本 |
|-------|-----------------|------|------|------|
| jimmy | metaapi/gpt-5.3-codex | L0 | 调度中枢 + 浏览器 + 碰撞 | 💰 |
| deep | metaapi/gpt-5.3-codex | L1 | 中文/代码/批量（主力）| 💰 |
| logic | mynewapi/claude-sonnet-4-6 | L1 | 数学/推理 | 💰 |
| main | google-gemini-cli/gemini-3-pro-preview | L1 | 多模态/长文档 | 🆓 |
| kitt | xjrouter/claude-opus-4-6-max | L2 | 架构/决策（慎用）| 🆓 |

### 各 Agent 职责边界

**jimmy（L0 调度）**：
- 接收所有厂长请求，3 秒内完成路由
- 自己处理条件（全部满足）：单轮完成、输出<1000 tokens、不涉及代码/推理/关键决策
- 浏览器操作 + 外部碰撞（Perplexity 等）
- 记忆管理、配置变更
- **铁律：能派就派，省 token**

**deep（L1 主力）**：
- 中文内容（>500字）、代码（全部代码任务）、批量任务
- 默认兜底：分不清派谁就给 deep
- 升级条件：架构级 → kitt，算法优化 → logic

**logic（L1 推理）**：
- 数学计算/证明、算法设计、多步推理（>3步）
- 数据建模、性能优化、指标计算

**main（L1 多模态）**：
- 图片/视频分析、超长文档（>100KB）
- Google 生态集成（NotebookLM/Gemini）
- 多语言翻译

**kitt（L2 决策）**：
- 架构设计、战略规划、重大决策、方案 PK
- **慎用**：成本高，只在关键决策时调用
- ⚠️ xjrouter 延迟高（5-6s），偶有超时

| DEV1 代码技术 | 写代码/脚本/API对接/bug修复 | deep | 架构级 → kitt，算法 → logic |

### 边界 Case
- **分不清桶**：默认 deep（成本最低）
- **跨桶任务**：拆子任务分别派发
- **厂长指定 agent**：无条件服从
- **agent 失败**：换 agent 重试一次，再失败报告厂长

### 子 agent 失败自动处理（v5.0 新增）
- **收到失败通知 → jimmy 当轮立即处理，不能拖到下一轮**
- **自动降级链**：
  - deep 失败 → main 重试 → jimmy 自己写
  - kitt 失败 → deep 重试 → main 重试
  - logic 失败 → deep 重试
  - main 失败 → deep 重试
- **同一任务最多重试 2 次**（含降级），仍失败则报告厂长
- **task-board 状态同步**：派发后 readyTasks → activeTasks，完成/失败后更新状态
- **禁止静默失败**：失败了不处理 = 失职

## Agent 执行监督

### 超时与降级规则
| 情况 | 处理 |
|------|------|
| agent 10min 超时 + tokens=0 | 模型连接问题，换 provider 重派 |
| agent 10min 超时 + tokens>0 | 任务太大，拆小重派 |
| 同一 agent 连续 2 次失败 | 降级到其他 agent |
| xjrouter 超时 | kitt 任务降级给 deep(sonnet) |
| mynewapi 超时 | 降级到 xjrouter 或 groq |

### 执行质量追踪
每次 spawn 完成后，jimmy 记录到 ops/state.json 的 agentStats：
```json
{
  "agentStats": {
    "deep": { "total": 10, "ok": 8, "timeout": 1, "error": 1, "avgDurationMs": 120000 },
    "kitt": { "total": 3, "ok": 1, "timeout": 2, "error": 0, "avgDurationMs": 300000 }
  }
}
```
