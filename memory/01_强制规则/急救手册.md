# Kitt 急救手册 v4.0（2026-03-11 更新）

## 🚨 失联急救

### 情况1：Kitt 不回复（Telegram/Discord）
```bash
# 1. 检查 Gateway
openclaw gateway status

# 2. 看日志
tail -50 ~/.openclaw/logs/gateway.log

# 3. 重启
openclaw gateway restart

# 4. 还不行？检查代理
curl -x http://127.0.0.1:7897 -s -o /dev/null -w "%{http_code}" https://www.google.com
# 代理端口是 7897（Surge mixed-port）
```

### 情况2：所有通道都不回复
```bash
# 回滚到安全配置
ls -lt ~/.openclaw/openclaw.json.bak.* | head -5
cp ~/.openclaw/openclaw.json.bak.YYYYMMDD-HHMM ~/.openclaw/openclaw.json
openclaw gateway restart

# 如果没有 .bak 文件，从 GitHub 恢复
cd /tmp && git clone https://github.com/95369149/openclaw.git openclaw-restore
```

### 情况3：Provider 全挂（今天刚发生过）
```bash
# 快速诊断：逐个测 provider
# mynewapi（opus/sonnet）
curl -s -o /dev/null -w "HTTP %{http_code}" \
  -x http://127.0.0.1:7897 \
  -H "Authorization: Bearer $MYNEWAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"claude-opus-4-6","messages":[{"role":"user","content":"hi"}],"max_tokens":10}' \
  https://api.penguinsaichat.dpdns.org/v1/chat/completions

# mygptapi（gpt-5.4）
curl -s -o /dev/null -w "HTTP %{http_code}" \
  -x http://127.0.0.1:7897 \
  -H "Authorization: Bearer $MYGPTAPI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5.4","messages":[{"role":"user","content":"hi"}],"max_tokens":10}' \
  https://nan.meta-api.vip/v1/chat/completions

# google-gemini（flash，免费兜底）
curl -s -o /dev/null -w "HTTP %{http_code}" \
  -H "Content-Type: application/json" \
  -d '{"contents":[{"parts":[{"text":"hi"}]}]}' \
  "https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=$GEMINI_API_KEY"

# 临时切到能用的 provider
openclaw config set 'agents.list[0].model' "google-gemini-cli/gemini-3-pro-preview"
openclaw gateway restart
```

### 情况4：失忆/记忆丢失
```bash
# 方案1：从 GitHub 恢复（首选）
cd /tmp && rm -rf kitt-brain-restore
git clone https://$(gh auth token)@github.com/95369149/kitt-brain.git kitt-brain-restore
cd kitt-brain-restore

for f in SOUL.md IDENTITY.md USER.md HEARTBEAT.md TOOLS.md AGENTS.md; do
    [ -f "$f" ] && cp "$f" ~/.openclaw/workspace/
done

rsync -av --update \
    --exclude='__pycache__' --exclude='.DS_Store' \
    ./memory/ ~/.openclaw/workspace/memory/

# 方案2：从 iCloud 恢复（手动备份）
rsync -av --update \
    ~/Library/Mobile\ Documents/com~apple~CloudDocs/OpenClaw_Memory/黄金备份/latest/memory/ \
    ~/.openclaw/workspace/memory/

# 方案3：只恢复配置
cp ~/Library/Mobile\ Documents/com~apple~CloudDocs/OpenClaw_Memory/黄金备份/openclaw.golden.json \
    ~/.openclaw/openclaw.json
openclaw gateway restart
```

```bash
launchctl list | grep watchdog
```


## 💾 备份策略

### 自动备份
- **GitHub**：sync.sh 每30分钟推送 memory
- **Git 全量**：每天22:30 cron 自动 commit + push
- **openclaw.json**：每次修改前自动备份 .bak.YYYYMMDD-HHMM

### 手动备份
- **iCloud**：`bash memory/scripts/sync.sh icloud`
- **黄金备份**：`bash memory/scripts/backup-rotate.sh`

### ⚠️ 注意
- iCloud 自动同步已停用（会产生大量重复文件）
- GitHub 是唯一自动备份源

## ⚠️ 注意事项
1. 改配置前先备份：`cp ~/.openclaw/openclaw.json ~/.openclaw/openclaw.json.bak.$(date +%Y%m%d%H%M%S)`
2. 只有 jimmy 有权改配置
3. 代理端口是 **7897**（Surge mixed-port）
4. gemini 经常限流，cron 定时任务不要用 gemini
5. 重启后必须主动检测失忆并汇报
6. 合盖不休眠：`sudo pmset -a sleep 0 && sudo pmset -a disablesleep 1`
