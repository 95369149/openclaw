# 强制规则：资料学习与分发流程 v3.0

## 触发条件
厂长通过 Telegram / Discord / WhatsApp 发送以下任何一种内容：
- 文档附件（PDF/TXT/MD/DOC/DOCX/PPTX 等）
- X/Twitter 链接
- 网页链接 / 文章链接
- 厂长说"学一下"/"看看这个"/"研究下"
- 转发的消息/文章

## 谁来干

| 任务类型 | 执行者 | 模型 |
|---|---|---|
| 接收 + 识别 + 派活 | 前台（DeepSeek V3.2） | 当前主力模型 |
| 抓取 + 学习 + 写入记忆 | Worker | sessions_spawn → flash 或 DeepSeek |
| 质检 + 汇报 | 前台 | 当前主力模型 |
| 复杂分析 / 厂长要深入讨论 | Opus | 手动切换或 spawn |

## 流程

### 第一步：前台接收
- 识别内容类型（链接/文档/转发）
- 构造学习任务描述
- **禁止**在主会话里展开全文（污染上下文）

### 第二步：派发 Worker
```
sessions_spawn(
  task: "学习任务描述 + 原始链接/文件路径",
  cleanup: "delete",
  label: "学习-[主题简称]",
  model: "flash"  // 优先免费模型
)
```

### 第三步：Worker 执行
1. 读取/抓取全文
2. 提取核心方法论（不是摘要，是可执行的知识）
3. 对比已有语义记忆（memory_search），找出增量
4. 只写增量到对应目录：
   - 方法论/知识 → `memory/03_语义记忆/`
   - 外部文档 → `memory/02_知识库/`
   - 收藏/推文 → `memory/80_收藏/`
5. 更新对应 `_INDEX.md`
6. 返回一句话总结

### 第四步：前台回传
- 收到 Worker 总结
- 转述给厂长（不超过 3 句话）
- 隔离会话自动销毁

## 写入标准
- 语义记忆单文件 < 3KB
- 只写方法论/可执行知识，不写原文摘抄
- 已有文件有相关内容 → 追加增量，不重复
- 新领域 → 新建文件

## 例外
- 厂长说"我们一起看看" → 在主会话展开讨论
- 厂长发完链接追问具体问题 → 前台先尝试回答，搞不定转 Opus
