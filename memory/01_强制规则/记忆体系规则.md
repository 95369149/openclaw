# 记忆体系规则（2026-02-24 合并版）

## 铁规：记忆优先
回答涉及以下话题时，**必须先 memory_search 查记忆，禁止凭上下文瞎答**：
- 兵团成员 / 模型配置 / Fallback 链
- 厂长个人信息 / 偏好 / 习惯
- 项目进度 / 历史决策
- 强制规则 / 系统架构
- 任何"之前做过什么"类的问题

查到了如实报告，没查到说"记忆里没找到"，不编造。

## 醒来自检（Context Reset 后必须执行）

触发条件：
- 系统提示 "Post-Compaction Audit"
- 厂长说"你怎么不记得了"
- 最后一条消息超过 30 分钟

执行步骤：
1. **`read memory/00_大脑中枢.md`**（第一步！总索引，一读全知）
2. `read memory/05_日常日志/YYYY-MM-DD.md`（今天或昨天）
3. `read memory/01_强制规则/_INDEX.md`（按需）
4. `session_status`
5. 主动向厂长汇报："我回来了，记忆已恢复，当前状态：..."

## 记忆断裂应急
1. **坦诚承认**（10秒内）："我刚经历了 context reset，正在恢复记忆"
2. **快速恢复**（1分钟内）：执行醒来自检
3. **汇报恢复**：告诉厂长恢复了什么、还缺什么

禁止：装作什么都知道、等厂长催 3 次、依赖 session 上下文

## 防遗忘
- 配置变更 → 立即写入日志
- 重要决策 → 立即写入强制规则
- 学到新知识 → 立即写入知识库
- **文件是唯一真相，session 上下文随时可能丢失**

## 备份（sync.sh v2.0）
- **自动备份**（launchd 每30分钟）：`bash memory/scripts/sync.sh auto`
  - Git 推送到 GitHub（版本历史）
  - iCloud tar 快照（追加写，保留90份）
  - iCloud latest 镜像（便于浏览）
  - 配置文件三份：rolling / weekly-YYYYWww / golden-YYYYMM
- **手动恢复**：`bash memory/scripts/sync.sh restore git:HEAD` 或 `restore icloud:<timestamp>`
  - 恢复前自动打本地安全快照到 ~/Downloads/
  - 需要手动确认才执行
- **核心原则**：auto 只备份永不自动恢复，restore 必须显式执行
- iCloud 目录：`~/Library/Mobile Documents/.../OpenClaw_Memory/{Snapshots,latest,Configs,agents}`

## 维护
- 单文件不超过 3KB，超过拆分
- 根目录只放 00_ 前缀文件
- 每日 23:00 写日志到 05_日常日志/
- 不在 workspace 里存备份（防套娃）
