# 强制规则：配置-文档一致性（2026-02-26）

## 根因
2026-02-25 发现：系统经历多次迭代（SiliconFlow→mynewapi），配置改了文档没同步，
导致排兵布阵.md 还在引用已不存在的 provider，Agent 模型描述与实际不符。

## 铁律

### 1. 唯一权威源
- Agent 编制、路由规则、Fallback 链 → `01_强制规则/排兵布阵.md`
- 其他文件（SOUL.md/大脑中枢.md/.abstract）只做速查摘要，标注"冲突时以排兵布阵为准"
- **禁止在多处重复定义同一规则**

### 2. 变更必须双写
任何涉及以下变更，必须同时更新配置文件和文档：
- Agent 模型变更 → openclaw.json + 排兵布阵.md + .abstract
- Provider 增删 → openclaw.json + 排兵布阵.md
- Fallback 链调整 → openclaw.json + 排兵布阵.md
- 意图桶/路由规则变更 → 排兵布阵.md + SOUL.md

### 3. 变更后必须校验
```bash
bash memory/scripts/config-consistency-check.sh
```
返回码非 0 → 不算完成，立即修复。

### 4. 每小时自动校验
ops_hourly_sweep cron 任务已包含一致性校验，发现不一致自动告警。

### 5. 废弃资源清理
- Provider 废弃后，从所有文档中删除引用（不留 ~~删除线~~，直接删干净）
- 过时的强制规则文件 → 移入 `90_归档/`，不留在 `01_强制规则/`
