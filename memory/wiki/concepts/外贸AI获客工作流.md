# 外贸AI获客工作流

> 外贸AI工具正从"批量找邮箱"升级为"可解释获客工作流"，再到"全链路代运营"。

## 核心要点

1. **演进阶段**：单点文案 → 可解释获客工作流 → 全流程agent化 → 全链路代运营
2. **核心价值**：把外贸经营动作标准化、连续化、24小时在线化
3. **代表产品**：B2Binsights（可解释线索）、阿里国际AI生意助手2.0（四段流程）、Accio Work（30分钟开跨境店）

## 对红太阳的启示

**优先落地三段：**
1. 询盘自动分级（ICP匹配+证据链）
2. 报价/邮件草拟
3. 老客户跟进与催单

**目标**：先把销售重复劳动砍掉30%，比追求一步到位更实际。
