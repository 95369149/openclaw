# AI Agent 生产级分层

> 2026年框架竞争已从"能不能跑Demo"转向"失效可控、可观测、成本可预测、可人工接管"。

## 核心要点

1. **框架选型标准变化**：LangGraph定位生产标准，CrewAI适合快速原型，AutoGen 2.0适合Azure高并发
2. **核心能力四要素**：可审计、可中断、可回放、成本护栏
3. **演进方向**：从"代码优先"转向"资产优先"——agents/skills/plans作为可复用资产独立管理

## 对红太阳的启示

- 内部AI体系优先走"可编排+可接工具+可审计"路线
- 销售、客服、售后、知识库按agent分工建设
- 重点不是再加模型，而是补observability、审批链、失败回滚和成本护栏
- 沉淀"销售跟进skill、询盘分级skill、设备选型plan、内容生成plan"形成组织复利
