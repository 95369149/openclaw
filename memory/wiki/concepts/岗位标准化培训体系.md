# 岗位标准化培训体系

> 通过岗位教材、检查清单和落地漏斗，把"经验传承"变成可复制的标准化作业流程。

## 核心要点

- 培训目标必须量化到"一次合格率"，而非停留在"提升意识"
- 每个岗位教材结构：上岗要求 → 开工前检查 → 标准作业流程 → 自检/互检/交检
- 电工岗位核心：穿线规范、屏蔽防干扰、上电前安全检查三道门禁
- 钳工岗位核心：按图纸顺序装配、紧固力矩达标、运动部件无干涉
- 培训落地漏斗：听懂(100%) → 形成动作(85%) → 执行检查(60%) → 固化机制(40%)
- 周培训节奏：周一统一认知 → 周二复盘案例 → 周三标准动作 → 周四拆解到人 → 周五复盘

## 对红太阳的启示

- 60人团队（30销售+23生产+7管理）中，生产岗位标准化直接影响设备交付质量和一次合格率
- 电工/钳工教材已有完整框架，下一步是做成可执行的"检查清单"而非仅靠记忆
- 培训落地漏斗的40%固化率是关键瓶颈——需要把培训结果沉淀为SOP和复盘模板
- 师徒制+积分制+红黑榜可与岗位标准化教材配合，形成"标准→执行→考核→激励"闭环
