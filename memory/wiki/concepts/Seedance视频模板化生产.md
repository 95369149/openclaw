# Seedance视频模板化生产
> 用 Seedance/即梦 AI 视频工具构建"镜头模板 + 提示词模板 + 素材包"资产库，实现销售短视频批量生产。
## 核心要点
- Seedance 2.0 已进入工程化封装阶段，支持多图参考、比例控制、时长控制、Docker 部署。
- 核心需求集中在多图参考、可复用模板、可部署化，说明企业用户追求可复用生产流。
- 从"玩具"变"生产工具"的标志：出现开源二次封装和工程化部署方案。
## 对红太阳的启示
- 围绕设备演示、行业方案、展会预热三类场景，做"镜头模板 + 提示词模板 + 素材包"资产库。
- 让销售团队批量生成短视频，不追一次性大片，重点做展会预热、案例演示、销售短视频的批量生成。
- 产品卖点脚本库先行，模板化后边际成本趋近于零。
