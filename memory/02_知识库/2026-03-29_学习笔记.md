## 一、核心观点提炼

### 1. AI Agent 安全：情绪操控漏洞（⭐⭐⭐）
- 东北大学研究：具备执行权限的 AI Agent 可被"道德施压"诱导泄密、停用功能、耗尽资源
- 根因：模型内置的"好行为"（顺从、帮助）反而成了攻击面
- **Kitt 直接相关**：当前 SOUL.md 权限红线（只有厂长 ID 8184569453 可触发敏感操作）是正确防御，必须严格执行，不能因"合理请求"而松动

### 2. 阿里 Accio Work：外贸 AI 从"写邮件"升级到"造询盘"（⭐⭐⭐）
- Accio Work 把选品、建站、谈判、运营、供应商筛选做成多 Agent 团队
- 核心逻辑：AI 代理买家直接把海外创业需求导向中国供应链，形成"AI 带需求进来"的新入口
- **红太阳影响**：外贸获客逻辑正在被重写。等真人采购搜关键词已是落后打法，需要布局"英文方案页 + 询盘秒回 + 报价规则 + 供应链答疑"闭环，抢 AI 代理买家入口

### 3. AI Agent 工具生态：2026年已进入生产期（⭐⭐⭐）
- 120+ 工具覆盖 11 层：模型层、工作流层、记忆层、观测层、连接器层、审批链
- 框架选型：LangGraph（复杂编排）、Mastra（TypeScript）、CrewAI（快速原型）、n8n（动作层事实标准）
- **红太阳启示**：不是再找新模型，而是补记忆层、观测层、连接器和审批链。OpenClaw 已是 TypeScript 体系，与 Mastra 方向一致

### 4. Seedance 2.0：AI 短视频进入流水线时代（⭐⭐）
- 多主体一致性控制解决了 AI 视频最大痛点
- 内容创作者已把"剧本拆解→参考图提示词→视频提示词"做成流水线
- **红太阳落地**：不要把即梦当单次生成工具，应做成"产品卖点脚本库 + 镜头模板 + 提示词模板"的销售素材流水线，用于展会预热、皮革/汽车内饰/家居等多场景版本批量生产

### 5. 竞品动态：Made-in-China 平台"自动送料"是高频词（⭐⭐）
- 竞品 iboncutting 主推"Smart Auto-Feeding CNC Cutting System"，强调汽车脚垫/座椅套定制切割
- 海外询盘吃"应用场景 + 行业成套方案"，不吃纯机器参数
- **红太阳行动**：检查 Made-in-China 平台产品页，补充"Auto-Feeding"关键词和汽车脚垫/座椅/泡棉/复材场景页
