# Seedance 2.0 提示词速查手册（2026-02-21 Scout 整理）

> 来源：Scout（豆包）深度搜索 + 15篇资料综合整理

## 万能公式

**主体 + 动作 + 场景 + 光线 + 镜头语言 + 风格 + 画质 + 约束**

### 万能 8 要素模板（全网疯传）
```
1. 基础参数: 时长, 比例, 分辨率, 画质
2. 角色/主体: 外貌, 服装, 表情
3. 动作链: 连续微动作, 速度/力度
4. 场景/光影: 地点, 光线方向, 色温, 氛围
5. 镜头/运镜: 景别, 运动方式, 缓动, 时长
6. 风格/质感: 电影感/复古/赛博, 胶片颗粒, 色调
7. 多模态参考: @图/@视频/@音频, 用途明确
8. 约束词: 无抖动, 无穿模, 角色一致, 音画同步
```

## 一、导演式提示词模板

### 案例1：电影感人物短片（最常用）
```
[基础参数] 18s, 9:16, 4K, 电影质感, 画面稳定无抖动, 60fps
[导演指令] 主观视角转客观中景, 手持跟拍(轻微晃动), 缓慢推进(easing=cubic-out, duration=3s), 浅景深, 逆光轮廓光, 柔焦虚化背景
[动作/叙事] 主角低头整理衣领, 抬头微笑, 转身走向镜头, 抬手打招呼(动作自然不僵硬)
[风格/约束] 复古胶片颗粒(强度20%), 色调偏暖(色温5200K), 皮肤磨皮不失真, 无穿模, 角色一致
```

### 案例2：国风治愈短片
```
[基础参数] 15s, 16:9, 2K, 国风意境, 画面丝滑, 30fps
[导演指令] 固定镜头转缓慢平移, 全景→特写(缓动过渡), 柔光, 侧光勾勒轮廓, 无镜头跳变
[动作/叙事] 古风少女坐于庭院石桌前, 抬手拨弄琴弦, 低头轻嗅茶香, 眼神柔和舒缓
[风格/约束] 水墨质感, 暖光灯笼氛围感, 汉服纹理清晰, 无穿模, 动作连贯, 画面干净无杂物
```

### 案例3：科技感产品短片
```
[基础参数] 12s, 1:1, 4K, 科技感, 高清细节, 画面锐利
[导演指令] 环绕运镜(速度均匀), 特写→中景, 硬光, 光影对比强烈, 镜头平滑无卡顿
[动作/叙事] 产品缓慢旋转, 镜头聚焦产品细节, 灯光随产品旋转变化, 结尾定格产品logo
[风格/约束] 金属质感, 冷色调(色温4000K), 轻微光晕, 无反光过曝, 无模糊, 产品无变形
```

### 运镜精细化写法
- 旧：`缓慢推镜`
- 新：`dolly in slowly (easing=cubic-out, duration=2.4s)`
- 关键：用现在时主动态（pans/tilts）+ 缓动函数 + 时长

### 多模态 @ 语法
```
@图1 保持角色面部与身形, @视频1 复刻运镜轨迹, @音频1 同步节奏
```

## 二、多镜头分镜模板

### 案例1：单人剧情短片（4镜头）
```
Shot 1: 全景, 森林入口, 女孩推门, 固定镜头, 3s
Shot 2: 特写, 脚步踩落叶, 缓慢推镜, 2s
Shot 3: 中景, 女孩抬头, 阳光穿叶, 跟拍, 4s
Shot 4: 全景, 镜头拉远, 唯美定格, 2s
@图1 保持女孩形象, 暖光柔光, 治愈氛围, 角色一致
```

### 一镜到底 + 多场景串联
```
一镜到底, 无切镜, 主观视角, 从客厅→走廊→阳台, 缓慢平移, 自然光
```

### 锚点生成 + 时序扩展（专业 workflow）
1. 第一步：生成 Anchor Shot（主镜头），锁定角色/场景/光影
2. 第二步：用 Video Extension 从 Anchor 最后一帧扩展新镜头，100% 保持环境一致

## 三、音视频联合提示模板

### 音频驱动镜头切换（卡点玩法）
```
@音频1 作为配乐, 画面节奏与节拍同步, 鼓点处自动切镜, 动作卡点精准
```

### 口型同步（多语言支持）
```
角色说中文台词, 口型精准同步, 表情自然, 无嘴型扭曲
```

### 多模态混合万能公式
```
素材参考(@图/@视频/@音频) + 文字提示(主体/动作/场景) + 镜头/光影 + 音画同步 + 约束词
```

## 四、角色一致性约束词库

### @图片锁定角色（基础方案）
```
@图1 保持角色面部、服装、身形全程一致, 无变脸, 无穿模
```

### 参考权重调节（进阶）
- 角色参考权重：高（1.0），强制锁定外观
- 动作参考权重：中（0.6），允许自然动作
- 场景参考权重：低（0.3），允许环境变化

### 时序一致性（长视频）
```
全程角色一致, 服装不变, 光影统一, 动作连贯, 无断层
```

### 人物稳定必加词
```
面部清晰稳定, 无变形, 正常人体结构, 自然比例, 动作不僵硬
同一角色, 服装一致, 发型不变
```

## 五、负面词/避坑词库

### 防翻车必备（每次必加）
```
无抖动, 无闪烁, 无穿模, 无变形
面部稳定不变形, 眼睛嘴型不扭曲
人体结构正常, 比例自然, 动作流畅
无多余杂物, 画面干净, 细节清晰
```

### 画质保底词（焊死在末尾）
```
4K超高清, 细节丰富, 画面锐利, 电影质感, 色彩自然, 柔和光线, 无模糊, 无鬼影, 无闪烁, 画面稳定
```

### 绝对避坑
- ❌ 多人复杂交互（打架、握手、拥抱）→ 穿模
- ❌ 模糊词（"好看""漂亮""酷"）→ 等于没描述
- ❌ 矛盾要求（"超高速奔跑"+"极致稳定无模糊"）
- ❌ 敏感内容

## 动作描写技巧

- 用：缓缓转身、轻轻抬手、微微低头、随风摇曳、轻步前行
- 避：剧烈打斗、高速运动、多人复杂交互、大幅度变形
- 核心原则：慢、连续、自然、流畅

## 演进总趋势

1. **从文字到多模态**：@图/@视频/@音频成为核心，素材 > 文字
2. **从描述到导演**：指令式、结构化、分镜化，AI 成为数字摄制组
3. **从单点到系统**：基础参数+镜头+动作+光影+参考+约束，完整 workflow
4. **从不可控到精准**：角色锁定、时序一致、音画同步，工业化生产成为可能

## 关键信息

- API 预计 2026-02-24 开放
- 支持最多12个参考文件（9图+3视频+3音频）
- 8种语言唇形同步
- 2K分辨率，24-60fps，单次最长15-20秒
- 可用率 90%+

## 六、摄影机模组（电影感加成器）

> 来源：@xpg0970 — 用真实摄影机参数替代空洞修饰词，禁止 beautiful/masterpiece/amazing

### 公式
```
主体与动作 + 场景与构图 + 摄影机模组 + 光影色彩 + 后缀参数
```

### Module A — ARRI（经典写实/细腻叙事/文艺冷峻）
```
Shot on ARRI ALEXA Mini, paired with Zeiss Master Prime lenses, 35mm wide angle, 3.2K ArriRaw sensor quality
```

### Module B — RED（史诗大片/废土科幻/宽银幕张力）
```
Shot on RED Weapon Dragon, paired with Panavision G series Anamorphic lenses, 35mm, Redcode RAW 6K, cinematic anamorphic look
```

### Module C — Sony（极致锐利/赛博惊悚/极高反差）
```
Shot on Sony CineAlta F65, paired with Panavision Primo Prime lenses, 35mm wide angle, Sony 16-bit Linear RAW, ultra-wide color gamut
```

### 光影色彩（通用，必加）
```
incredibly high fidelity, cinematic color grading, cinematic lighting, deep depth of field, hyper-realistic, low contrast, desolate atmosphere
```

### 选择逻辑
- 温暖人文/文艺片 → Module A
- 战争/科幻/史诗 → Module B
- 赛博朋克/惊悚/高反差 → Module C

> 来源：@john87445528 — 权游风格史诗短片实战

    {"姓名": "配角", "外观": "描述外貌"}
  ],

      "机位": "高空航拍俯瞰",
      "画面": "具体画面描述",

    },
    {
      "时间": "00:05-00:10",
      "机位": "慢镜头推进",
      "画面": "具体画面描述",
      "色彩": "冷蓝中透出金色微光",
