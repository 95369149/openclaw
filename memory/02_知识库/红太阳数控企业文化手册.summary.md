# 红太阳数控企业文化手册 摘要

> RED SUN CNC CULTURE CODE (2026)

## 序言
红太阳不只是制造冰冷机器的工厂，而是一群有情义、有梦想的人共同修行的道场。对外成就客户，对内成就奋斗者。

## 第一章：顶层设计

### 使命
以智慧精工，成就客户工业梦想。
- 核心逻辑：唯有帮客户把钱赚到了，我们的设备才有灵魂。利他，是红太阳生存的根本。

### 愿景
打造受人尊敬的智能裁切品牌，构建奋斗者幸福共享的家园。
- 对外：不追求盲目规模，追求极致信赖，做品质过硬、售后厚道的百年老店。
- 对内：企业是制造人才的地方，让员工在奋斗中获得财富，在共事中获得尊严。

## 第二章：核心价值观（四条铁律）

1. **敬畏托付**：交付即承诺，品质即良心。不发次品，说到做到，换位思考。
2. **唯真唯实**：做人要真，做事要实。直面问题，透明沟通，数据说话。
3. **日拱一卒**：不怕慢，就怕站。微创新，持续学习，精益求精。
4. **成人达己**：补台不拆台，共担赢未来。主动补位，利他思维（下道工序就是客户）。

## 第三章：做人理念
- 百善孝为先
- 自立立人，自达达人（先干好自己的活，再帮同事；先练精技术，再带徒弟）
- 知行合一

## 第四章：落地仪式
- 晨会宣誓（入脑）
- 师徒礼（入行）：正式拜师仪式，传承技术与匠心
- 感恩日（入心）
- 树立标杆：每月评选符合价值观的优秀员工
