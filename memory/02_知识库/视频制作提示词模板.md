## 模板 1：15秒产品展示脚本（抖音/TikTok）

### 场景说明
快节奏产品亮点展示，适合社交媒体信息流投放，强调视觉冲击和即时吸引力。

### 提示词结构

```
创建一个15秒的产品展示视频，用于抖音/TikTok平台。
目标受众：制造业采购决策者、工厂管理者
产品：[具体设备名称，如"红太阳CNC-5000五轴加工中心"]
核心卖点：[1-2个关键特性，如"精度±0.003mm，速度提升40%"]

视觉风格：工业现代风，深蓝色(#1E40AF)和橙色(#FF6B35)为主色调
纵向视频(9:16)，快节奏剪辑

场景1：钩子(0-3秒)
- 场景类型：B-roll (Motion Graphics)
- 视觉：设备特写镜头快速推进，火花四溅的加工画面
- 配音："这台机器每小时能为你省下3000块。"
- 文字叠加：大字标题"省钱神器"

场景2：问题痛点(3-8秒)
- 场景类型：B-roll (Stock Media)
- 视觉：传统设备慢速运转，工人等待的画面
- 配音："传统设备慢、误差大、人工成本高。"
- 文字叠加：划掉的"慢""贵""不准"

场景3：解决方案(8-13秒)
- 场景类型：B-roll (AI Generated + Motion Graphics)
- 视觉：红太阳设备高速运转，零件精准成型，数据可视化动画
- 配音："红太阳五轴加工中心，速度快40%，精度达0.003毫米。"
- 文字叠加：关键数据飞入"40%↑" "±0.003mm"

场景4：行动号召(13-15秒)
- 场景类型：Motion Graphics
- 视觉：品牌Logo + 联系方式 + 二维码
- 配音："立即咨询，免费打样。"
- 文字叠加："扫码领取技术方案"
```

| 时间轴 | 镜头类型 | 运镜 | 音效 |
|--------|---------|------|------|
| 0-1秒 | 特写 | 快速推进 | 机械启动音 |
| 1-3秒 | 中景 | 旋转环绕 | 金属切削声 |
| 3-5秒 | 远景 | 固定镜头 | 低沉背景音乐 |
| 5-8秒 | 特写 | 慢动作 | 节奏加快 |
| 8-11秒 | 中景 | 平移 | 电子音效 |
| 11-13秒 | 特写 | 快速切换 | 高潮音乐 |
| 13-15秒 | 全景 | 淡出 | 品牌音效 |

### 场景说明
通过真实客户成功案例建立信任，展示设备在实际生产中的价值，适合官网、展会播放。

### 提示词结构

```
创建一个60秒的客户案例视频。
目标受众：潜在客户、行业同行
客户：[公司名称，如"某汽车零部件制造商"]
挑战：[客户面临的问题，如"交付周期长、良品率低"]
解决方案：[使用的设备/服务]

视觉风格：专业纪实风，使用真实工厂场景
横向视频(16:9)，稳定镜头为主

场景1：客户介绍(0-10秒)
- 场景类型：B-roll (Stock Media)
- 视觉：客户工厂外景，生产线全景
- 配音："某汽车零部件厂，年产值2亿，面临交付压力。"

- 文字叠加：问题关键词"3小时" "85%良品率"

场景3：解决方案(20-35秒)

```

## 模板 3：技术科普视频脚本

### 场景说明
深入浅出讲解技术原理，建立专业形象，适合知识付费平台、B站、公众号。

### 提示词结构

```
创建一个90秒的技术科普视频。
主题：[技术概念，如"五轴联动加工原理"]
目标受众：技术人员、工程师、学生
难度：中级（假设观众有基础机械知识）

视觉风格：教育风格，简洁图解为主
横向视频(16:9)，配合动画演示

场景1：引入(0-10秒)
- 场景类型：A-roll + Motion Graphics
- 视觉：主讲人出镜，背景显示复杂零件3D模型
- 配音："为什么有些复杂零件，普通机床做不了？答案是：轴数不够。"
- 文字叠加：标题"五轴联动是什么？"

场景2：基础概念(10-30秒)
- 场景类型：B-roll (Motion Graphics)
- 视觉：三轴机床动画演示，标注X/Y/Z轴
- 配音："传统三轴机床，只能在X、Y、Z三个方向移动，加工角度受限。"
- 文字叠加：坐标轴标注，运动轨迹动画

场景3：五轴原理(30-55秒)
- 场景类型：B-roll (Motion Graphics + AI Generated)
- 视觉：五轴机床动画，增加A/B旋转轴演示
- 配音："五轴机床增加了两个旋转轴，刀具可以从任意角度接近工件，一次装夹完成复杂曲面加工。"
- 文字叠加：五轴运动分解动画，对比三轴vs五轴加工效果

场景4：应用场景(55-75秒)
- 场景类型：B-roll (Stock Media + 实拍)
- 视觉：航空叶片、医疗器械、汽车模具等实际案例
- 配音："航空发动机叶片、人工关节、汽车模具，这些都需要五轴加工。"
- 文字叠加：行业标签 + 产品特写

场景5：总结(75-85秒)
- 场景类型：A-roll
- 视觉：主讲人回归，背景显示关键要点
- 配音："五轴联动，让复杂零件加工变得简单高效。"
- 文字叠加：要点列表"更高精度""更少装夹""更短周期"

场景6：结尾(85-90秒)
- 场景类型：Motion Graphics
- 视觉：订阅提示 + 下期预告
- 配音："下期讲解五轴编程技巧，记得关注。"
```

### 分镜建议
- **动画风格**：使用工业蓝+白色配色，线条简洁
- **对比手法**：分屏展示三轴vs五轴加工过程
- **标注清晰**：所有轴向用不同颜色标注，配合箭头动画
- **实拍插入**：在讲解应用时插入真实加工画面增强说服力

### 配音文案（完整版）
```
"为什么有些复杂零件，普通机床做不了？<break time="0.5s"/>答案是：轴数不够。<break time="1s"/>
传统三轴机床，只能在X、Y、Z三个方向移动，加工角度受限。<break time="1s"/>
五轴机床增加了两个旋转轴，刀具可以从任意角度接近工件，<break time="0.5s"/>
一次装夹完成复杂曲面加工。<break time="1.5s"/>
航空发动机叶片、人工关节、汽车模具，这些都需要五轴加工。<break time="1s"/>
五轴联动，让复杂零件加工变得简单高效。<break time="1s"/>
下期讲解五轴编程技巧，记得关注。"

## 模板 4：设备操作教程脚本

### 场景说明
手把手教学视频，帮助客户快速上手设备，减少售后压力，适合客户培训、售后支持。

### 提示词结构

```
创建一个120秒的设备操作教程视频。
设备：[具体型号，如"红太阳CNC-5000"]
操作任务：[具体操作，如"首次开机与基础设置"]
目标受众：新购设备的操作工、技术员

视觉风格：实操演示风格，清晰标注每个步骤
横向视频(16:9)，固定机位+特写切换

场景1：开场(0-10秒)
- 场景类型：A-roll + Motion Graphics
- 视觉：讲师站在设备旁，设备全景
- 配音："大家好，今天教大家红太阳CNC-5000的首次开机流程。"
- 文字叠加：教程标题 + 讲师姓名

场景2：安全检查(10-30秒)
- 场景类型：B-roll (实拍) + Motion Graphics标注
- 视觉：讲师检查电源、气压、冷却液，特写镜头
- 配音："开机前，先检查三个关键点：电源接地、气压表读数、冷却液液位。"
- 文字叠加：检查清单动画，每项完成后打勾

场景3：开机步骤(30-60秒)
- 场景类型：B-roll (实拍) + Motion Graphics
- 视觉：手部特写操作控制面板，屏幕录制
- 配音："第一步，打开主电源开关。<break time="1s"/>
第二步，按下控制面板启动键。<break time="1s"/>
第三步，等待系统自检完成，大约需要30秒。"
- 文字叠加：步骤编号 + 操作提示箭头

场景4：基础设置(60-90秒)
- 场景类型：屏幕录制 + Motion Graphics
- 视觉：操作界面录屏，鼠标轨迹高亮
- 配音："进入系统后，先设置工作坐标系。点击'设置'菜单，选择'坐标系'，输入工件尺寸。"
- 文字叠加：菜单路径标注，参数输入示例

场景5：试运行(90-110秒)
- 场景类型：B-roll (实拍)
- 视觉：设备空载运行，各轴移动画面
- 配音："设置完成后，进行空载试运行，检查各轴运动是否正常。"
- 文字叠加：注意事项"确保工作区无障碍物"

场景6：总结(110-120秒)
- 场景类型：A-roll + Motion Graphics
- 视觉：讲师回归，背景显示操作流程图
- 配音："以上就是首次开机的完整流程，如有问题，联系售后团队。"
- 文字叠加：售后电话 + 微信二维码
```

### 分镜建议
- **多机位拍摄**：主机位拍全景，辅机位拍手部特写
- **屏幕录制**：使用高清录屏软件，鼠标轨迹用红色圆圈标注
- **字幕同步**：操作步骤与字幕严格同步，方便暂停查看
- **慢动作**：关键操作（如按键、旋钮）使用0.5倍速慢放

```

### 拍摄注意事项
1. **安全第一**：拍摄前清理现场，确保无安全隐患

5. **后期调色**：统一色调，增强工业质感（偏冷色调）

## 通用优化建议

### 1. 时长控制
- **抖音/TikTok**：15-30秒（前3秒必须抓住注意力）
- **YouTube Shorts**：30-60秒
- **B站/公众号**：1-3分钟
- **企业官网**：2-5分钟

### 2. 文案原则
- **简洁**：每句话不超过20个字
- **口语化**：避免书面语，多用"你""我们"
- **数据化**：用具体数字代替模糊描述
- **节奏感**：适当使用停顿标签 `<break time="Xs"/>`

### 3. 视觉元素
- **品牌色**：全片统一使用品牌主色调
- **字体**：标题用粗体，正文用常规体，确保可读性
- **动画**：数据出现用飞入效果，转场用淡入淡出
- **Logo**：片头片尾必须出现，时长不少于2秒

### 4. 音频处理
- **配音**：语速150字/分钟，吐字清晰
- **音乐**：音量低于配音20%，避免抢戏
- **音效**：机械音、电子音增强工业感
- **降噪**：工厂环境音需后期降噪处理

### 5. 平台适配
| 平台 | 比例 | 时长 | 封面 | 字幕 |
|------|------|------|------|------|
| 抖音 | 9:16 | 15-60秒 | 前3秒截图 | 必须 |
| 快手 | 9:16 | 15-60秒 | 前3秒截图 | 必须 |
| B站 | 16:9 | 1-10分钟 | 自定义 | 推荐 |
| YouTube | 16:9 | 不限 | 自定义 | 推荐 |
| 微信视频号 | 6:7 | 1-60分钟 | 自定义 | 推荐 |
