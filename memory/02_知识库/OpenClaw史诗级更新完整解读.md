## 🧠 王炸四：线程隔离与 Prompt 缓存（痛点终结者）

### 线程绑定（Thread-bound）
- 在 Discord 特定帖子里召唤特定的"打工 Agent"
- Agent 乖乖待在自己的帖子里干活
- 不会污染主聊天大群

### Prompt 缓存增强
- 精准区分"核心背景信息"和"单条闲聊噪音"
- 超长对话中依然智商在线
- 解决上下文漂移问题

## 💡 绝密干货：社区大神都在用的 5 个避坑法则

### 1. 调教 Agent：做错了别光生气，要让它长记性
**正确做法：**
- 告诉它："我不太喜欢这个，你应该这样做……并且把这个规则存到你的文件里。"

**高阶玩法：**
- 用 Obsidian 联动 GitHub 做 Agent 的"记忆库"
- 专门存放性格和指令集
- 让它们每天被动进化

### 2. 别拿高射炮打蚊子（省钱秘籍）
**错误做法：**
- 所有任务都扔给最贵的 Opus 4.6

**正确做法：**
- 例行检查、基础搜索用便宜模型
- Haiku、Gemini Flash、Claude Sonnet 4.5
- 速度快还省钱

### 3. "放养"是死路一条，它需要界限
**问题：**
- 开箱即用的 Openclaw 不是全知全能的神
- 没有明确的护栏（Guardrails）和工作流（Workflows）
- 容易陷入死循环

**解决方案：**
- 去 Cloudhub 给它装专业技能

### 4. 关了窗口它就不干活了？
**误区：**
- 以为吩咐一句，Agent 就会连夜帮你打工
- 普通会话关闭，进程就结束了

**正确做法：**
- 配合 VPS（云服务器）
- 使用 Cron 定时任务
- 或 Claw Deck 任务控制台

### 5. 别搞花架子，搞点能赚钱的工作流
**建议：**
- 不要做花里胡哨但毫无用处的机器人
- 做点真正能帮业务增长的

## 对 Kitt 的启发与行动计划

### ✅ 已实施
1. Gemini 3.1 Pro 已配置
2. 多模型协作机制
3. Cron 定时任务（每日迭代升级）
4. 记忆库系统（memory/）

### ⏳ 需要优化

#### 1. 成本控制策略
**当前问题：**
- 主力是 `mynewapi/claude-sonnet-4-6-thinking`（付费）
- 没有明确的成本控制机制

**优化方案：**
- 调整 Fallback 链：免费模型优先
- 建立任务分级机制：
  - 简单任务：DeepSeek, Gemini Flash
  - 中等任务：Gemini 3.1 Pro, Claude Sonnet
  - 复杂任务：Claude Opus

#### 2. Discord 集成
**当前状态：**
- 主要使用 Telegram 和 WhatsApp
- 没有 Discord 集成

**优化方案：**
- 评估 Discord 集成的必要性
- 如果需要团队协作，优先考虑 Discord

#### 3. 线程隔离
**当前问题：**
- 所有对话在同一个会话中
- 容易混乱

**优化方案：**
- 使用 sessions_spawn 创建隔离的子代理
- 每个任务独立线程

#### 4. Prompt 缓存优化
**当前问题：**
- 超长对话可能导致上下文漂移

**优化方案：**
- 定期总结核心信息到 memory/
- 清理无关噪音
- 保持上下文干净

#### 5. 记忆库进化
**当前状态：**
- 已有 memory/ 目录结构
- 手动维护

**优化方案：**
- 参考 Obsidian + GitHub 方案
- 自动化记忆库更新
- 建立性格和指令集版本控制

#### 6. 护栏和工作流
**当前问题：**
- 缺少明确的护栏机制
- 可能陷入死循环

**优化方案：**
- 建立任务超时机制
- 设置最大工具调用次数
- 明确任务边界
