# 总裁九大机制 — 摘要

## 九大机制全景

| # | 机制 | 解决什么 | 核心观点 |
|---|---|---|---|
| 01 | 文化机制 | 心 | 资源会枯竭，唯有文化生生不息。外化于形、内化于心、固化于制。 |
| 02 | 战略机制 | 路 | 战略不是看你想要什么，而是看你愿意放弃什么。聚焦 > 全面。 |
| 03 | 人才机制 | 人 | 先人后事。选拔大于培养，猪练不成爬树，要一开始就选猴子。 |
| 04 | 产品机制 | 物 | 一米宽，一万米深。不解决用户痛点的产品都是耍流氓。 |
| 05 | 培训机制 | 能 | 企业是最大的学校。师徒制 + 培训四化（实战化/多样化/严格化/应用化）。 |
| 06 | 薪酬机制 | 利 | 薪酬不是成本是投资。钱散人聚，钱聚人散。为价值付薪不为苦劳付薪。 |
| 07 | 绩效机制 | 效 | 绩效目的是改进不是扣钱。赛马不相马，结果论英雄。基层KPI，高层OKR。 |
| 08 | 晋升机制 | 位 | 双通道设计：管理通道（做官）+ 专业通道（专家），互不冲突。 |
| 09 | 营销机制 | 销 | 把销冠经验提炼成标准动作。全员营销，技术/服务/职能都要有营销意识。 |

## 落地精神
- 没有完美的个人，只有完美的团队
- 没有完美的制度，只有不断进化的机制
- 机制定江山，执行赢未来
