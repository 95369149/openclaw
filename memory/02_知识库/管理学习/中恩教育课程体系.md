## 课程关系（当前最可靠版本）
1. **《总裁九大机制》**：老板先建立经营全局框架
2. **《高管领导力》**：把老板思路翻译成高管干部系统
3. **《钢铁之师特训营》**：把高管思路压到团队执行、状态和凝聚力上
4. **《薪酬绩效机制方案班》**：把分钱、激励、绩效与晋升机制补齐
5. **《团队股权激励方案班》**：解决核心高管绑定、股权扩张和长期激励
6. **《演说统御》**：解决老板对内统御、对外成交、公众表达与影响力问题

也就是说，中恩公开能确认的主线已经形成：
**老板经营框架 → 高管干部系统 → 团队执行系统 → 薪酬绩效激励 → 股权扩张绑定 → 演说统御表达**
