## 一、设备基本参数

### 电源要求
| 项目 | 参数 |
|------|------|
| 输入电压 | 380V 三相 或 220V 三相 |
| 机器功率 | 2.2KW（机身） |
| 真空泵功率 | 9KW |
| 空压机功率 | 1.2KW（选配） |
| 总功率 | ≥12KW |
| 电缆截面 | ≥6mm² |
| 额定功率（不含铣刀） | 2500W |

### 安全配置
- 四角急停开关（暂停运动，不断电）
- 开盖保护功能
- 驱动器报警系统
- 脚踏开关（可选）

## 六、维护保养

### 日常维护要点
- 定期清洁工作台面和导轨
- 检查刀具磨损，及时更换
- 检查真空吸附系统气密性
- 检查各轴运动是否流畅
- 清理切割废料

### 刀具更换
- 振动刀：松开刀夹→取出旧刀→装入新刀→调整刀深→测试
- 刀深设置：面板上设置高点（不带料）和低点（切断材料）
