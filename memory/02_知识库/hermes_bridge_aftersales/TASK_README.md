# 售后知识库清洗任务说明

## 任务目标
对红太阳数控设备两年售后原始记录进行清洗、标记、归类，生成可检索的诊断型知识库。

## 原始数据位置
```
knowledge/aftersales/raw/batch_001.md ~ batch_037.md
```
共 3623 条原始售后记录，每批 100 条。

## 每条记录包含字段
- 客户：客户名称
- 材料：行业/材料类型
- 问题：原始问题描述（口语化，需归一化）
- 处理：原始处理方法
- 状态：是否解决

## 清洗要求

### 1. 问题归一化
将口语化、重复表达归并为标准故障名称。

示例：
- "刀头振动效果不好气压不稳" → `气动刀气压不稳`
- "切割圆不圆" / "切出来不圆" → `切圆不圆`
- "驱动器报警了" / "驱动报警" → `驱动器报警`
- "通信中断了" / "和通信中断" → `通信中断`

### 2. 故障主题标记
每条记录打上故障主题标签（可多标签）：

| 标签 | 关键词 |
|------|--------|
| 驱动器报警 | 驱动、报警、伺服 |
| 气动刀异常 | 气动刀、气压、振动、漏气 |
| 切割爆边 | 爆边 |
| 切割毛边/拉丝 | 毛边、拉丝 |
| 切圆不圆 | 圆不圆、图形变形 |
| 跑料/送料偏移 | 跑料、推料、拉料、送料 |
| 通信中断 | 通信中断、断线、网口 |
| 相机掉线/标定异常 | 相机、标定 |
| 刀头/刀座异常 | 刀头、刀座 |
| 电机/驱动丢步 | 丢步、电机 |
| 回原点异常 | 原点 |
| 风机吸附异常 | 风机、吸风、吸附 |
| 毛毡/台面耗材 | 毛毡、垫板、台面 |
| 刀片/耗材损坏 | 刀片、断刀 |
| 面板/电气故障 | 面板、断电、24V |
| 切不透 | 切不透、切不断 |
| 尺寸误差 | 尺寸、误差 |
| 未归类 | 其他 |

### 3. 处理方法标准化
将处理方法归并为标准动作：

- 远程指导
- 上门维修
- 返厂维修
- 更换配件（注明配件名）
- 调整参数
- 软件/文件问题
- 客户自行解决
- 待跟进

### 4. 输出格式
每个故障主题生成一个知识条目，格式如下：

```markdown
## [故障主题名称]

### 高频现象
- 现象1（出现N次）
- 现象2（出现N次）

### 常见原因
1. 原因A
2. 原因B
3. 原因C

### 排查顺序
1. 先检查...
2. 再检查...
3. 最后...

### 处理方法
- 方法A：适用场景
- 方法B：适用场景

### 升级条件
- 以下情况需上门或返厂：...

### 历史案例（3-5条）
| 日期 | 客户 | 机型 | 问题 | 处理 |
|------|------|------|------|------|
```

## 输出位置
处理完成后写入：
```
done/aftersales_knowledge_v1/[故障主题].md
```

每个故障主题一个文件，共约 15-20 个文件。

- 一个问题可能对应多个原因，全部列出
- 排查顺序按"从简单到复杂、从软件到硬件"排列
- 处理完成后 git add + commit + push
