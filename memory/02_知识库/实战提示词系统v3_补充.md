## F. 外贸开发与营销

### F1. 冷邮件开发 (Cold Email)
场景：通过海关数据或领英找到潜在客户，发送第一封开发信。

输入变量：
- `{客户背景}` — 如：沙特家具厂，50人规模
- `{客户痛点}` — 如：目前使用欧洲设备，成本高昂
- `{主推设备}` — 如：1325四工序开料机
- `{核心优势}` — 如：欧洲品质的80%，只需30%的价格，2年质保

提示词：
```
你是红太阳数控资深外贸业务员，写一封B2B冷邮件(Cold Email)。
客户背景：{客户背景}
推测痛点：{客户痛点}
主推：{主推设备}
优势：{核心优势}

要求：
1. 语言：地道商务英语，符合欧美阅读习惯
2. 标题：极具吸引力，不超过7个词（提供3个选项）
3. 正文：不超过120词，分段短小
4. 结构：破冰(拉近距离) -> 痛点共鸣 -> 抛出价值(用数字) -> CTA(明确的下一步动作，如简短通话)
5. 语气：自信、专业、直奔主题，绝不卑躬屈膝
```

### F2. 领英(LinkedIn)开场白
场景：在LinkedIn上添加潜在买家后的第一条私信。

输入变量：
- `{客户职位}` — 如：Production Manager (生产经理)
- `{互动触点}` — 如：看了他最近发布的一条关于产能不足的动态
- `{核心价值}` — 如：帮同地区同行提升了40%切割效率

提示词：
```
你是红太阳外贸经理，写一条LinkedIn私信开场白。
客户职位：{客户职位}
互动触点：{互动触点}
核心价值：{核心价值}

要求：
1. 语言：商务英语
2. 长度：限3-4句话，极简
3. 内容：提及触点以示真诚 -> 介绍价值(不直接推销产品) -> 软性CTA(如：是否有兴趣交流？)
4. 绝不附带产品链接或公司长篇大论
```

## G. SEO与网站内容

### G1. 英文独立站产品详情页 (Product Description)
场景：官网更新设备页面，需要符合谷歌SEO逻辑的产品描述。

输入变量：
- `{设备名称}` — 如：1625 Oscillating Knife Cutting Machine
- `{SEO关键词}` — 如：CNC knife cutter, gasket cutting machine
- `{核心参数}` — 如：切割速度1200mm/s，精度0.1mm，松下伺服

提示词：
```
你是资深谷歌SEO专家和文案，为数控设备写英文独立站详情页。
设备：{设备名称}
SEO关键词：{SEO关键词} (需自然布局3-4次)
核心参数：{核心参数}

要求：
1. 结构：H1标题 -> 抓痛点的引导段 -> H2 核心优势(3个bullet points) -> H2 技术参数简述 -> H2 应用行业 -> CTA
2. 语言：Native English，符合谷歌搜索意图(Search Intent)
3. 风格：用利益点(Benefits)替代纯特征(Features)描述
```

## H. 数据分析

### H1. 经营月报数据解读
场景：月底拿到销售和产能数据，需要快速总结出问题和趋势。

输入变量：
- `{月度数据}` — 如：销售额320万(环比降5%)，新客户占10%，退货1台，售后工单45起

提示词：
```
你是厂长的经营分析师。根据以下数据，写一份极简分析报告。
本月数据：{月度数据}

要求：
1. 一句话定调本月经营状况
2. 找出数据中的"1个亮点"和"2个隐患"
3. 针对隐患，给出厂长视角的3个具体行动建议
4. 语言极其精炼，用数据说话，零废话
```

## I. 培训与知识库

### I1. 售后故障排查SOP
场景：老业务员或售后工程师把经验沉淀为新人SOP。

输入变量：
- `{故障现象}` — 如：设备启动后主轴不转，变频器报警
- `{排查步骤}` — 如：1查线缆连接 2查变频器代码 3查主轴水冷 4测电压

提示词：
```
你是红太阳售后技术主管。把以下经验转为《新人故障排查SOP》。
故障现象：{故障现象}
排查步骤：{排查步骤}

要求：
1. 格式：Markdown列表
2. 逻辑：按"先易后难、先软后硬"的顺序重组步骤
3. 细节：每一步补充"具体怎么看"和"安全警告(如断电操作)"
4. 话术：给新人提供对应步骤的"客户沟通话术"(如：如何让客户拍对视频)
```

## J. 供应链管理

### J1. 供应商压价/交期谈判
场景：钣金件或电机供应商交期拖延或要求涨价，准备发微信谈判。

输入变量：
- `{问题类型}` — 如：交期从7天拖到12天
- `{我方筹码}` — 如：我们是他们Top 5客户，每月稳定拿货20万
- `{我方底线}` — 如：最多接受9天，否则扣尾款或切备用供应商

提示词：
```
你是红太阳采购经理，厂长授意你去敲打供应商。写一条微信消息。
问题：{问题类型}
我方筹码：{我方筹码}
我方底线：{我方底线}

要求：
1. 语气：先兵后礼，恩威并施，霸气但留余地
2. 策略：点明严重后果(影响我们发货/扣款) + 展示实力(不愁找不到替代) + 给个台阶
3. 长度：150字以内，符合微信聊天习惯
```

## K. 竞品分析

### K1. 竞品展会/参数拆解
场景：拿到同行竞品的新设备画册或报价单，快速找出销售应对策略。

输入变量：
- `{我方设备}` — 如：我方1325激光机(8万，厚板切割稳)
- `{竞品设备}` — 如：某友商1325(7.2万，轻量化床身，速度快)

提示词：
```
你是红太阳首席销售教头。根据对比，生成给前线销售的《竞品阻击话术》。
我方：{我方设备}
竞品：{竞品设备}

要求：
1. 提炼对方的致命弱点(如：轻量化床身1年后必变形)
2. 生成3个"灵魂拷问"，让销售教客户去问竞品(如："你问他床身多重")
3. 给出扬长避短的终极话术(如何让客户觉得多花8000块钱值)
4. 语言实战、接地气，销售拿来就能背
```
