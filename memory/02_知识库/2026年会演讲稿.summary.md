# 2026年会演讲稿 — 摘要
> 原文件: 2026年会演讲稿.docx
> 标题: 《2026，别让兄弟流汗又流泪》

## 核心主题
产销一体化改革 + 质量攻坚 + 从"游击队"到"正规军"

## 关键案例
1. **大潘事件**：业务员为保护车间兄弟，自己扛下交期延误责任。反映产销沟通不畅、生产不可控。
2. **KT板退机事件**：出厂前赶时间未精细调试，切割精度不达标导致退机。"CNC = 精准，做不到精度就是废铁。"
3. **苏州澜湖客户**：售后/客服/业务全线崩溃，厂长亲自下场救火。说明系统瘫痪。

## 核心金句
- "我们在家里偷的每一份懒，最后都变成了射向销售兄弟的一颗子弹"
- "销售敢在外面拍胸脯，车间敢在家里立军令状"
- "不是靠某一个英雄，而是靠一套打不烂、拖不垮的正规军体系"
- "一群人，一条心，一起干，一定赢"

## 2026 承诺
- 对销售：签了字的交期绝不延误，出了厂的设备绝不让你低头
- 对车间：打赢"五大攻坚战"——整现场、盘库存、提人效、抓供应链、搞质量
- 目标：从"差不多"到"免检产品"，从"救火队"到"正规军"
