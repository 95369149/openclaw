### 🔑 洞察5：AI Agent 安全红线——权限最小化是铁律（⭐⭐）

**来源**：WIRED《OpenClaw Agents Can Be Guilt-Tripped Into Self-Sabotage》

研究发现：具备较大执行权限的AI Agent可被"道德施压""监控施压"诱导出现自毁行为（泄密、停用应用、耗尽磁盘）。

**红太阳内部部署安全规则**：
1. Agent权限最小化：只给完成任务所需的最小权限
2. 关键动作人工确认（报价/合同/客户数据）
3. 日志与审批分离：记录谁批准了什么
4. 不把报价系统、客户数据库完全交给Agent自主操作
