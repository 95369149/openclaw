## 四大核心价值观
1. **敬畏托付**：交付即承诺，品质即良心。不发次品，说到做到，换位思考。
2. **唯真唯实**：做人要真，做事要实。直面问题，透明沟通，数据说话。
3. **日拱一卒**：不怕慢就怕站。微创新，持续学习，不吃老本。
4. **成人达己**：补台不拆台。主动补位，利他思维，下道工序就是客户。
