## 行业背景分析

**红太阳数控营销特点：**
- **客户类型**：B2B 企业采购（制造业工厂、加工中心、模具厂）
- **决策周期**：长（3-12个月），多人决策（技术总监、采购、财务）
- **关注重点**：技术参数、ROI、售后服务、成功案例
- **营销渠道**：搜索引擎、行业展会、朋友圈、短视频平台（抖音/快手）
- **痛点**：设备精度、稳定性、交货期、培训成本、维护成本

## 模板 1：产品落地页文案

### 场景说明
用于官网产品详情页、百度竞价落地页、阿里巴巴店铺详情页。目标是让访客快速理解产品价值，留下询盘线索。

### 提示词结构

```
你是一位专业的 B2B 工业设备文案撰写专家，擅长将技术参数转化为客户价值。

请为【产品名称】撰写产品落地页文案，包含以下模块：

1. **核心卖点标题**（20字内）
   - 突出核心技术优势或客户收益
   - 使用具体数字（精度、效率、成本节省）
   - 避免空洞词汇（"领先""创新"）

2. **副标题**（40字内）
   - 补充说明适用场景或解决的核心痛点
   - 包含目标客户群体（如"模具加工企业首选"）

3. **三大核心优势**（每条50字内）
   - 格式：【技术特点】→【客户收益】→【量化证明】
   - 示例："德国进口丝杠 → 定位精度±0.003mm → 废品率降低40%"

4. **应用场景**（3-5个）
   - 列举典型加工案例（如"汽车模具精加工""手机外壳批量生产"）

5. **客户见证**（1-2条）
   - 真实客户案例，包含公司名称、使用时长、具体收益数据

6. **行动号召（CTA）**
   - 提供2个选项：强意向（"预约上门演示"）+ 弱意向（"下载技术白皮书"）

**产品信息：**
- 产品名称：[填写]
- 核心技术参数：[填写]
- 目标客户：[填写]
- 主要竞品：[填写]
- 价格区间：[填写]
```

## 模板 3：客户咨询回复

### 场景说明
用于微信/电话咨询、阿里旺旺对话、展会现场沟通。目标是快速建立信任，推进到下一步（报价、演示、上门）。

### 提示词结构

```
你是一位经验丰富的工业设备销售顾问，擅长通过提问挖掘客户需求，并提供针对性解决方案。

请为以下客户咨询场景，设计一套标准回复话术：

**客户问题类型：**[填写，如"询问价格""对比竞品""担心售后"]

**回复要求：**
1. **先共情，再解答**（不要直接甩参数）
2. **反问2-3个问题**，了解客户真实需求
3. **提供具体案例**，而非泛泛而谈
4. **给出下一步行动建议**（如"发详细方案""预约视频演示"）

**客户背景：**
- 行业：[填写]
- 当前设备情况：[填写]
- 主要顾虑：[填写]
```

### 示例输出

**场景：客户问"你们设备比XX品牌贵2万，凭什么？"**

---

**回复话术：**

李总您好！我理解您的顾虑，买设备确实要算清楚账。

✅ 德国进口丝杠（XX用的是国产），精度高一个档次  
✅ 3年质保+终身技术支持（XX只保1年）

## 使用建议

1. **根据场景选择模板**：不同渠道使用不同风格（官网正式、朋友圈口语化）
2. **填充真实数据**：用具体数字替换模板中的占位符
3. **A/B 测试**：同一场景准备2-3个版本，测试后选最优
4. **定期更新**：每季度根据客户反馈和市场变化调整话术
5. **结合工具**：配合百度指数、5118、阿里指数挖掘关键词
