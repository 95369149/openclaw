## 浏览器工具问题

**错误**: `Blocked: resolves to private/internal/special-use IP address`  
**原因**: OpenClaw 安全策略认为 127.0.0.1 是私有 IP，拒绝连接浏览器控制服务  
**影响**: 无法自动操作浏览器，需要手动协作  
**待修复**: 查找 OpenClaw 配置选项或等待版本更新

## 注意事项
1. 三个标签页保持打开，浏览器会记住模型选择
2. 清除缓存会丢失配置，需要重新选择模型
3. 建议把三个标签页加入书签，方便恢复
4. 每个标签页独立记忆，不会互相干扰
