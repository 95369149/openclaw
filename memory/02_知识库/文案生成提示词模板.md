# 文案生成提示词模板

> 基于 baoyu-skills 项目研究，针对红太阳数控内容IP场景定制

## 项目背景

**红太阳数控内容IP场景**：
- 制造业知识分享（数控技术、加工工艺、设备维护）
- 产品展示（数控机床、刀具、配件）
- 客户案例（成功案例、应用场景、解决方案）

**核心价值**：
- 建立行业专业形象
- 吸引潜在客户
- 提升品牌信任度
- 促进销售转化

## 模板 1：X/Twitter 推文（技术干货型）

### 场景说明
适用于分享制造业技术知识、行业洞察、快速技巧。目标是建立专业形象，吸引同行关注和潜在客户。

### 提示词结构

```
你是一位资深的数控加工专家，正在为红太阳数控的 X/Twitter 账号撰写技术干货推文。

**内容主题**：[具体技术主题，如"数控铣床精度校准技巧"]

**目标受众**：制造业从业者、数控操作员、工厂技术负责人

**撰写要求**：
1. 开头用一个痛点或问题引入（1句话）
2. 提供3-5个具体可执行的技术要点
3. 每个要点用简洁的语言表达（不超过20字）
4. 结尾加一个行动号召或互动问题
5. 总字数控制在280字符以内（中文约140字）
6. 语气专业但不生硬，像老师傅传授经验
7. 可以使用1-2个相关emoji增强可读性

**输出格式**：
- 正文内容
- 建议配图说明（如"数控机床操作面板特写"）
- 推荐话题标签（3-5个）

**示例风格参考**：
"数控加工精度总是差0.02mm？老师傅教你3招：
✓ 刀具预热5分钟再开工
✓ 检查主轴轴承间隙
✓ 冷却液温度保持25°C
你还有什么独门秘籍？👇"
```

### 示例输出

**正文**：
```
铝合金加工总是粘刀？试试这4个方法：
✓ 转速提高到8000rpm以上
✓ 选用3刃或4刃铣刀
✓ 加大冷却液流量
✓ 进给速度降低20%
效果立竿见影！你们厂用什么方案？💬
```

**配图说明**：铝合金工件加工前后对比图，展示光洁表面

**话题标签**：#数控加工 #铝合金加工 #制造业技巧 #CNC #红太阳数控

## 模板 3：小红书图文卡片

### 场景说明
适用于产品种草、客户案例分享、行业知识科普。目标是建立信任感，吸引B端客户关注和咨询。

### 提示词结构

```
你是一位小红书内容策划师，正在为红太阳数控制作图文卡片内容。

**内容主题**：[具体主题，如"数控机床选购避坑指南"]

**目标受众**：制造业老板、工厂采购、技术负责人

**内容策略**：选择以下一种
- A. 故事驱动型（客户案例、使用体验）
- B. 信息密集型（知识清单、对比评测）
- C. 视觉优先型（产品展示、工艺美学）

**图文要求**：
1. 标题：15字以内，包含痛点或利益点，加emoji
2. 封面图：说明视觉重点（如"机床加工特写+大字标题"）
3. 内容结构：
   - P1：封面（痛点+解决方案）
   - P2-P4：核心内容（3-5个要点）
   - P5：总结+行动号召
4. 每页文字：标题10字内，正文30-50字
5. 视觉风格：专业但不冷冰冰，用"notion"或"minimal"风格
6. 语气：像行业前辈分享经验，不要硬广

**输出格式**：
- 标题
- 每页内容（页码、标题、正文、视觉说明）
- 结尾文案
- 话题标签
```

## 模板 4：信息图生成（数据可视化）

### 场景说明
适用于行业报告、技术对比、产品参数展示。目标是用视觉化方式呈现复杂信息，提升专业度和传播力。

### 提示词结构

```
你是一位信息图设计师，正在为红太阳数控制作数据可视化内容。

**信息图主题**：[具体主题，如"三轴vs五轴数控机床对比"]

**数据来源**：[提供具体数据、参数、对比项]

**目标受众**：制造业决策者、技术工程师

**设计要求**：
1. 选择合适的布局类型：
   - binary-comparison（A vs B对比）
   - hierarchical-layers（层级结构）
   - linear-progression（流程时间线）
   - bento-grid（多主题概览）
   - dashboard（数据仪表盘）
2. 选择视觉风格：
   - technical-schematic（工程图纸风格，适合技术参数）
   - corporate-memphis（扁平插画，适合产品对比）
   - craft-handmade（手绘风格，适合知识科普）
3. 内容结构：
   - 标题（核心结论）
   - 3-5个关键数据点
   - 每个数据点包含：数值、单位、说明
   - 视觉元素：图标、箭头、对比色块
4. 保持所有数据准确无误，不要编造
5. 使用制造业专业术语

**输出格式**：
- 信息图标题
- 布局类型 + 视觉风格
- 结构化内容（分区域描述）
- 设计说明（颜色、图标、排版）
```

### 示例输出

**信息图标题**：三轴 vs 五轴数控机床：性能对比一目了然

**结构化内容**：

**左侧：三轴数控机床**
- 图标：简化的三轴机床侧视图
- 加工轴数：X、Y、Z 三轴
- 加工效率：100%（基准）
- 装夹次数：3-5次（复杂工件）
- 精度范围：±0.01mm
- 适用场景：平面、简单曲面加工

**右侧：五轴数控机床**
- 图标：五轴机床带旋转轴示意图
- 加工轴数：X、Y、Z + A、C 五轴
- 加工效率：300%（一次装夹完成）

- 精度范围：±0.005mm
- 适用场景：复杂曲面、叶轮、模具
- 价格区间：80-300万元

**中间对比区域**：
- 箭头指向：效率提升3倍
- 精度提升：2倍

## 模板 5：客户案例故事

### 场景说明
适用于展示成功案例、建立信任背书、促进销售转化。目标是用真实故事打动潜在客户，展示产品价值。

### 提示词结构

```
你是一位B2B内容营销专家,正在为红太阳数控撰写客户案例故事。

**客户信息**：
- 公司名称：[客户公司]
- 所属行业：[如汽车零部件、航空配件]
- 企业规模：[员工数、年产值]
- 合作时间：[开始合作的时间]

**案例背景**：
- 客户面临的问题/痛点：[具体描述]
- 问题造成的影响：[成本、效率、质量等]

**解决方案**：
- 采购的产品/服务：[具体型号、配置]
- 实施过程：[关键节点、周期]

**实际效果**：
- 量化数据：[效率提升%、成本降低%、良品率提升%]
- 客户评价：[真实反馈]

**撰写要求**：
1. 采用"问题-方案-结果"三段式结构
2. 开头用一个具体场景或对话引入
3. 突出客户的真实困境和决策过程
4. 用数据说话，避免空洞形容词
5. 结尾加客户原话（引用格式）
6. 总字数800-1200字
7. 语气真诚、客观，不要过度吹捧

**输出格式**：
- 案例标题（包含行业+痛点+结果）
- 正文（分段清晰）
- 关键数据摘要（表格形式）
- 适用行业标签
```

## 使用建议

1. **根据平台特性调整**：
   - X/Twitter：简短、数据化、话题性强
   - 抖音/TikTok：视觉冲击、节奏快、情绪化
   - 小红书：故事性、真实感、干货价值
   - 信息图：数据可视化、专业权威
   - 客户案例：详实、可信、结果导向

2. **内容复用策略**：
   - 一个客户案例可以拆解为：X推文（数据亮点）+ 抖音视频（现场画面）+ 小红书图文（完整故事）+ 信息图（效果对比）

3. **持续优化**：
   - 追踪每种内容的数据表现（阅读量、互动率、转化率）
   - 根据反馈调整提示词参数（语气、长度、视觉风格）
   - 建立内容素材库（客户照片、加工视频、数据报告）

4. **品牌一致性**：
   - 所有内容保持"专业、可靠、务实"的品牌调性
   - 统一使用品牌色（建议：工业蓝#1E88E5 + 活力橙#FF6F00）
   - 每条内容都包含品牌标识和联系方式
