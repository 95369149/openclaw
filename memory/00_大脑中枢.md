## 🧠 三层大脑 + 7 Agent 编制

> 详见唯一权威源：`01_强制规则/排兵布阵.md` v2.0

| Agent   | 模型                                     | 层级 | 定位                       |
| ------- | ---------------------------------------- | ---- | -------------------------- |
| `jimmy` | `mynewapi/claude-sonnet-4-6`             | L0   | 总调度 + 对外统一出口      |
| `deep`  | `mygptapi/gpt-5.4`                       | L1   | 代码/脚本/自动化执行主力   |
| `main`  | `google-gemini-cli/gemini-3-pro-preview` | L1   | 多模态输入处理 + 长文档    |
| `kitt`  | `mynewapi/claude-opus-4-6`               | L2   | 终审 + 架构裁判 + 战略判断 |
| `sino`  | `kimi/kimi-for-coding`                   | L1   | 中文专家岗                 |
| `scout` | `google-gemini-cli/gemini-3-pro-preview` | L1   | 外部侦察 / GitHub 对标     |
| `guard` | `mynewapi/claude-sonnet-4-6`             | L1   | 配置守门 / 风险审计        |

### 路由总则

- 所有需求先到 `jimmy`。
- 路由依据：**任务类型 × agent 特质 × 当前稳定性**。
- 简单任务 `jimmy` 直做。
- 复杂任务按专岗派发。
- 高风险输出必须走 `kitt` 或 `guard` 审核链。

### 标准去向

- 中文内容 → `sino`
- 代码/脚本/自动化 → `deep`
- 多模态/长文档 → `main`
- 外链/GitHub/竞品/情报 → `scout`
- 架构/战略/终审 → `kitt`
- 配置/规则/回滚/供应链审计 → `guard`

### 协作闭环

1. `jimmy` 接任务
2. 选路由
3. 执行 agent 产出
4. 必要时 `kitt` / `guard` 审核
5. `jimmy` 汇总回复
6. 重要信息写入记忆
