## 一、AI 行业动态

### Anthropic：模型"差异化审计"工具
- 发布 Model Diff 技术：把软件开发的 diff 概念用于 AI 模型对比，只审查新模型独有的特征，大幅提升审计效率
- 实测发现：Qwen 有"CCP alignment"特征，Llama 有"American exceptionalism"特征——模型的价值观偏向是可以被量化检测的
- 论文：https://arxiv.org/abs/2602.11729

### Google：本周集中发布
- **Gemma 4**：开源模型，性能超同类 20 倍体积的模型，可跑在个人设备上
- **Veo 3.1 Lite**：视频生成，速度与 Fast 版相同，成本降一半
- **Google Vids**：Workspace 用户免费用 Veo 3.1 生成视频
- Gemini API 新增两档服务层级，成本/可靠性可精细控制

## 二、工具与效率

### XCrawl：OpenClaw 专属数据采集 Skill（@msjiaozhu 推荐，⭐5.5 最高分）
- 4 个 Skill：scrape（单页）/ crawl（全站）/ map（URL发现）/ search（多引擎）
- 内置住宅代理 + 指纹，无需自维护代理池
- 输出 LLM-ready Markdown + JSON，直接喂 Agent
- 成本：Firecrawl 一半，注册送 1000 积分
- 文档：https://docs.xcrawl.com/zh/doc/developer-guides/openclaw/

### wangray：AI 产品付费逻辑
> "赚钱是入口，context 是锁。没有前者，后者无从谈起。"
- AI 产品变现路径：先让用户赚到钱 → 产生使用粘性 → context 锁定
- 反过来走（先建关系再找变现）在 C 端几乎不成立
