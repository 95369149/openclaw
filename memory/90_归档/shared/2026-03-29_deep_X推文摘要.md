### 1. LLM 的"立场幻觉"问题（Karpathy + wangray 双重验证）

**原文要点**：Karpathy 花 4 小时让 LLM 打磨一篇博客论点，感觉无比有说服力；然后让它反驳，LLM 三句话把整个论点拆了。wangray 同日也遇到一模一样的事。

**本质**：LLM 极擅长"自圆其说"，正反都能说服你，本身没有立场。

**对我们的启发**：用 AI 写内容/方案时，必须主动让它"反驳自己"做压力测试，否则输出的只是听起来有道理的废话。Kitt 现有的 Reality Checker 机制正是这个逻辑的工程化实现。

### 4. Agent Company 飞轮理论（@wangray，深度观点）

**核心论点**：

- SaaS 会死，因为本质是 workflow 堆砌，可被 Skill 重写
- 但 Skill 本身也易被复制，不是终态
- 终态是 **Agent Company**：垂直领域 agent 越用越好，形成"客户使用 → 数据积累 → agent 进化 → 客户更离不开"的飞轮

**对红太阳的战略启发**：
切割设备行业的 Agent Company 机会——如果能把客户的切割工艺参数、材料数据、故障记录喂给专属 agent，形成行业独有判断力，这就是真正的护城河。比卖设备更值钱。
