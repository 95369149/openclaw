## 🔥 今日核心信号

### 1. OpenAI Model Spec 公开框架

- OpenAI 发布了模型行为规范（Model Spec）的公开讨论，明确 AI 该做什么、不该做什么
- 重点：用"指挥链"机制解决冲突指令，并随真实使用反馈持续进化
- 📌 **意义**：AI Agent 进入"可信赖自治"阶段的信号，企业级部署更可控

### 2. Anthropic Claude Code 自动模式

- Claude Code 推出 Auto Mode：用分类器代替手动授权提示，让 AI 自主决策权限
- 这是 AI 编程助手从"需要人确认每步"到"自主完成任务"的关键跃迁
- 📌 **意义**：AI 写代码已进入"全自动审批"阶段，监督成本降至极低

### 3. Google Lyria 3 Pro —— AI 音乐生成升级

- 理解音乐架构（intro/verse/chorus/bridge），可生成最长 3 分钟完整曲目（之前限 30 秒）
- 接入渠道：Gemini App、Google AI Studio、producer_ai、Vertex AI
- 📌 **短视频意义**：AI 配乐将进一步平民化，视频配乐成本趋近于零

### 4. Arena2API —— 300+ 模型免费代理

- 项目：`flay-o/arena2api`，将 arena.ai 的 300+ 模型通过 OpenAI 兼容 API 代理
- 📌 **工具价值**：可大幅降低 API 成本，适合批量测试/对比不同模型效果

### 5. Karpathy：AI 记忆系统的过拟合问题

- 所有大模型都有同一个问题：2个月前你问过某个话题，它会把这个当成你的"深度兴趣"反复提及
- 根本原因：训练时上下文往往高度相关，模型形成了"利用给定信息"的偏见
- 📌 **意义**：AI 个性化记忆的设计仍需改进，当前所有模型都有此缺陷

### 6. MiniMax 开源 Office Skill

- MiniMax 开源了 Office 操作能力（@wangray 推荐）
- 📌 **可落地**：文档处理自动化的新选择
