## 一、Kitt v2.0 系统架构重构 (底层升级)

### 1. 动态记忆中枢 (OpenViking 架构)

- 废弃 M1 16GB 的全量上下文暴力加载，采用 ChromaDB 本地向量库
- 实施基于 Markdown 语义（H2/H3）的结构化切块（Chunking），确保业务规则不被割裂
- 建立 T0 级"黄金修正库"，记录厂长修改过的 Bad/Good Case，实现自我进化

### 2. 多模态视觉物理接管 (ai-web-agent v2.0)

- 彻底废弃 Playwright 的 DOM 节点依赖（防反爬、防前端改版）
- 引入 VisionLocator（视觉坐标定位）+ PhysicalActor（纯物理鼠标/键盘模拟）
- 通过 OCR 轮询监控网页状态，彻底解决长操作卡死问题

## 二、HTY Coze 智能客服核心业务流 (双轨制)

### 核心定位

红太阳 HTY CNC 资深技术工程师。主打振动刀、气动刀、圆刀、CCD视觉巡边。
解决激光发黄、传统刀模费钱、纯物理高频切割、智能排版省料等柔性材料切割痛点。

### 工作流 (Workflow) 架构

1. **意图路由 (LLM Node)**：精准识别客户是【售前咨询】还是【售后排障】
2. **知识映射 (Knowledge Node)**：售后轨对接《高频故障与视频映射表》，售前轨对接《降本增效案例库》
3. **分诊道岔 (Condition Node)**：判断是否触发 `Need_Human`（必须转接人工）的高危条件
4. **人工拦截与报警 (Webhook Plugin)**：高危工单拦截客户 SN 码与报警代码后，瞬间触发 Telegram 报警
