# 大脑注入方案：如何把 Kitt 记忆发给其他 AI

## 目标

让 Grok/Gemini/千问/Kimi 等外部 AI 读取 Kitt 的核心记忆，以"外部顾问"身份提供改进建议。

## 方案 1：一键注入文本（手动）

把以下文件拼接成一个文本块，粘贴到任何 AI 的对话框：

```bash
cat SOUL.md USER.md MEMORY.md memory/00_大脑中枢.md TOOLS.md > /tmp/kitt-brain.md
```

然后加上提示词：
"你是 AI 架构顾问。以下是一个 AI 助手的核心配置，请从记忆架构/提示词/安全/迭代四个角度审视并给出改进建议。"

## 方案 2：自动化脚本（推荐）

创建 `~/bin/kitt-brain-export.sh`，一键生成注入包：

- 拼接核心文件
- 自动裁剪到 10K 字符（适配免费模型上下文）
- 输出到剪贴板（macOS: pbcopy）

## 方案 3：OpenClaw 子 Agent 路由（最佳但受限）

当前子 agent 只能走默认模型。要让不同模型审视：

- 方案 A：在 SiliconFlow 添加 Kimi-K2.5 / GLM-5 等模型到 provider
- 方案 B：用 Kilo CLI 调用（需要修复模型格式问题）
- 方案 C：手动粘贴到各 AI 网页版

## 适合发给不同 AI 的问题

### 发给 Grok（擅长直觉和创意）

"看看我这个 AI 助手的记忆架构，有没有什么反直觉的改进方向？不要常规建议。"

### 发给 Gemini（擅长长文分析）

"分析这个 AI 助手的提示词体系，找出所有信息重复和矛盾的地方，给出去重方案。"

### 发给千问/Kimi（擅长中文理解）

"这个 AI 助手服务一个中国制造业老板，审视它的交互模式和文化适配是否到位。"

### 发给 Claude（擅长系统思考）

"审视这个 AI 助手的自我迭代机制，设计一个更好的闭环学习系统。"
