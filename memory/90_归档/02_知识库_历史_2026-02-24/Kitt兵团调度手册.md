# Kitt 兵团调度手册

## 概述

Kitt 是调度中枢，不是执行者。所有外部操作都通过派兵完成。

## 兵团成员

### Scout-Perplexity

- **职能**：实时搜索 + 摘要
- **调用方式**：browser (perplexity.ai)
- **适用场景**：
  - 需要最新信息（新闻、趋势、技术更新）
  - 需要多源对比
  - 需要结构化摘要
- **限制**：2 个 API key 轮动（避免限流）

### Scout-豆包

- **职能**：中文内容审稿、润色
- **调用方式**：browser (豆包)
- **适用场景**：
  - 中文文案润色
  - 语气调整
  - 错别字检查
- **限制**：仅中文内容

### Scout-Grok

- **职能**：X 平台内容读取
- **调用方式**：browser (x.com/grok)
- **适用场景**：
  - X/Twitter 推文抓取
  - X 趋势分析
  - X 用户动态
- **限制**：需要 X 登录态

### Gemini

- **职能**：图片生成(Imagen)、视频生成(Veo)
- **调用方式**：gemini skill
- **适用场景**：
  - 产品图片生成
  - 视频脚本可视化
  - 多模态内容
- **限制**：免费额度有限

### Claude

- **职能**：深度分析、长文处理
- **调用方式**：sessions_spawn (model=opus)
- **适用场景**：
  - 复杂逻辑分析
  - 长文档总结
  - 代码审查
- **限制**：成本较高，优先用于关键任务

### ChatGPT

- **职能**：通用对话、代码辅助
- **调用方式**：备用
- **适用场景**：
  - 快速原型代码
  - 通用问答
- **限制**：备用方案

## 派兵决策树

```
收到任务
  ├─ 需要实时信息？
  │   └─ YES → Scout-Perplexity Pro
  ├─ X 平台内容？
  │   └─ YES → Scout-Grok
  ├─ 中文润色？
  │   └─ YES → Scout-豆包
  ├─ 图片/视频生成？
  │   └─ YES → Gemini 3.0 Pro
  ├─ 深度分析？
  │   └─ YES → Gemini 3.0 Pro
  ├─ 通用对话？
  │   └─ YES → DeepSeek-V3.2（硅基流动）
  └─ 简单操作？
      └─ YES → Kitt 本体
```

**注意：**

- Gemini 2.5 Flash 有 20次/天限制，仅用于定时任务（新闻汇报等）
- 通用对话优先用 DeepSeek-V3.2（硅基流动，免费）

## 工具调用计数

**每轮不超过 3 次**

### 示例 1：X 内容分析

```
任务：分析某条 X 推文并生成摘要
1. browser → Scout-Grok 读取推文（1次）
2. write → 写入 memory/（不计数）
3. sessions_spawn → Claude 生成摘要（2次）
总计：2次 ✅
```

### 示例 2：多源信息汇总

```
任务：汇总 AI 行业最新动态
1. browser → Scout-Perplexity 搜索（1次）
2. write → 写入 memory/（不计数）
3. memory_search → 查找历史记录（不计数）
总计：1次 ✅
```

### 示例 3：超限处理

```
任务：分析 5 个网页
1. web_fetch 网页1（1次）
2. web_fetch 网页2（2次）
3. web_fetch 网页3（3次）
→ 停止，汇总前 3 个结果
→ 告诉厂长："已分析 3 个网页，剩余 2 个需要下一轮"
```

## 出错处理

1. **第一次失败**：换 Scout 或换工具
2. **第二次失败**：报告厂长，给 2-3 个替代方案
3. **第三次失败**：停止，等厂长指令
