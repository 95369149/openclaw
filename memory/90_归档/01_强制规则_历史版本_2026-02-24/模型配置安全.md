# 强制规则：模型配置安全

## 底线（最高优先级）

- mynewapi/claude-opus-4-6 作为主力模型，**永远不能被替换或覆盖**
- **前台接待必须是 Jimmy（mynewapi/claude-sonnet-4-6）**——厂长令，不可更改
- 任何新模型只能以 **追加** 方式加入，不能动现有配置
- `openclaw configure` **禁止直接使用**——它会覆盖整个配置文件
- 新增 provider 只能通过直接编辑 JSON 文件实现

## 角色分工（代号表）

| 代号  | 模型                       | 职责                          |
| ----- | -------------------------- | ----------------------------- |
| Jimmy | mynewapi/claude-sonnet-4-6 | 前台接待（primary），日常对话 |
| Kitt  | mynewapi/claude-opus-4-6   | 核心大脑，深度任务，兜底      |
| 工兵  | Fallback 链各模型          | 降级执行、子任务              |

## 安全操作流程

1. 修改配置前，先备份：`cp openclaw.json openclaw.json.manual-bak`
2. 用 python3 脚本修改 JSON（只改目标字段，不动其他）
3. 修改后验证：`openclaw models list` 确认主力模型在线
4. 如果主力模型消失，立即从 `.bak.1` 恢复
