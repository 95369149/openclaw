## 强制执行规则

### 1. 醒来必读（每次重启/失忆后）
**顺序执行，不能跳过**：
```bash
# 1. 读取今日日志（最近3小时）
tail -200 memory/$(date +%Y-%m-%d).md

# 2. 读取核心架构
head -200 memory/01_强制规则/排兵布阵.md

# 3. 检查当前状态
openclaw status
ps aux | grep gateway
date

# 4. 检查待办任务
grep "\[ \]" memory/$(date +%Y-%m-%d).md
```

### 2. 看日志必须检查时间
**禁止行为**：
- ❌ 看到日志就当成当前状态
- ❌ 不检查日志时间戳

**强制规则**：
```bash
# 看日志前先确认当前时间
date
echo "当前时间：$(date '+%Y-%m-%d %H:%M')"

# 看日志时必须过滤时间范围
tail -100 ~/.openclaw/logs/gateway.log | grep "$(date '+%Y-%m-%dT%H')"
```

### 3. 删除文件前必须比对内容
**流程**（不能跳过）：
1. 列出要删除的文件
2. 逐个读取内容（至少前50行）
3. 与保留文件比对
4. 确认是否有独特内容
5. 先备份到 `memory/90_归档/`
6. 再删除
7. 记录到今日日志

**禁止**：
- ❌ 批量删除不检查
- ❌ 只看文件名就删
- ❌ 删除前不备份

### 4. 配置变更前必须读取现有配置
**流程**：
1. 读取当前配置
2. 读取相关文档（排兵布阵.md/急救手册.md）
3. 确认变更影响范围
4. 先验证，再重启
5. 记录变更原因

**禁止**：
- ❌ 不读文档就改配置
- ❌ 改完不验证就重启
- ❌ 不记录变更原因

### 5. 每小时自检（定时任务）
**检查项**：
```bash
# 1. 我是否忘记了核心架构？
echo "10个意图桶：S1/S2/SC1/SC2/IM1/IM2/M1/M2/X1/DEV1"
echo "5 Agent：jimmy/main/logic/deep/kitt"
echo "两层路由：Triage → Agent派发"

# 2. 我是否在重复犯错？
tail -50 memory/$(date +%Y-%m-%d).md | grep "检讨\|错误\|问题"

# 3. 当前时间是？
date '+现在是 %Y-%m-%d %H:%M'

# 4. Gateway 状态？
openclaw status | grep "Gateway\|Agents"
```

### 6. 重大操作前必须暂停
**触发条件**（满足任一即暂停）：
- 删除 >3 个文件
- 修改核心配置（agents/models/channels）
- 重启 Gateway
- 批量操作

**暂停流程**：
1. 停下来
2. 读取相关文档
3. 检查当前状态
4. 确认操作影响
5. 先备份
6. 再执行
7. 验证结果

### 7. 每次回复前自问
**3个问题**：
1. 我是否读取了最新的文档/日志？
2. 我是否检查了时间戳？
3. 我是否在重复之前的错误？

**如果答案有"否"** → 停下来，重新检查
