# 语义记忆：Seedance 2.0 提示词方法论

来源：@op7418 + 藏师傅 测评文章 2026-02

## 核心原则

Seedance 2.0 有知识、有智能、有导演思维。**写意图，不写细节。**
它自带世界知识，知道兰州拉面怎么做、无印良品什么调性、高位下拉练背阔肌。
不需要在提示词里写百科全书。

## 提示词写法要点

### 1. 简单场景：一句话搞定

- "生成一个精美高级的兰州拉面广告，注意分镜编排"
- "帮我生成一个高位下拉健身动作的讲解视频"
- "帮我生成一个讲述无印良品这个品牌的宣传片"
- 关键：写意图 + "注意分镜编排"，剩下交给模型

### 2. 参考素材用法（全模态）

支持上传：9张图片 + 3段视频 + 3段音频

- 完全保留素材：@图片1 / @视频1 / @音频1
- 只提取元素："面部非常像@视频1角色"、"动作与@视频1一致"
- 风格参考："画风动作打斗表现严格对齐@视频1的风格"

### 3. 多素材混搭模板

服装换装：
"让@图片4的男性分别换上@图片1 @图片2 @图片3的三套服装进行展示，每次展示一套，需要有不同景别的流畅运镜和转场切换，加上符合服装设计调性的广告音乐"

多图产品宣传：
"帮我将@图片6 @图片5 ... @图片1这几个UI展示图变成多分镜多角度的应用宣传片，并搭配合适的口播介绍，为其增加丰富的转场效果和细节展示，每个分镜的转换需要连贯顺畅。产品介绍为：[产品描述]"

### 4. 家装/户型图 → 参观视频

步骤1：户型图 → 大香蕉生成九宫格分镜
提示词："基于当前户型图，设计一套九宫格样板间参观视频分镜图。严格遵循以下顺序，从门口玄关进入...空间关系要跟户型图对应，风格温馨北欧风格"

步骤2：户型图+分镜图 → Seedance 2.0
提示词："参考@图片2设计稿分镜和@图片1户型图，生成一段沉浸式样板间参观视频，严格按照@图片2的分镜顺序，模拟真实看房行走路线，可以切镜头，注意自然光线变化和材质质感"

### 5. 照片 → Vlog（参考视频风格）

"参考@视频1的运镜、画面切换节奏、画面颜色风格、音乐和卡点，文字和特效，用剩下的图片变成一个日常Vlog。这种风格的主要特色是：[描述参考视频的核心特色]"
技巧：如果不描述参考视频特色，学得不太好。要把核心特色写出来。

### 6. 口播视频/视频播客

"使用@图片1的人物和环境，使用@音频1作为人物的声音内容，生成一个视频播客视频，需要加上字幕，适当给@音频1一些情感表现让他更真实和激动"

- 可以要求调整情感："表现得激动一些"，它能修改素材情绪

### 7. 音频 → MV/故事视频

"为@音频1生成符合氛围的[情绪描述]电影剧情，需要有情节，保持@音频1作为视频背景音乐，转场间画面风格及音乐节奏进行卡点"
技巧：不允许单独上传音频时，上传一张透明/纯白png图片

### 8. 动作迁移（真人→特效场景）

"一名面部非常像@视频1角色的[角色描述]在[场景]中[动作]，动作和运镜需要与@视频1完全一致"
关键词（人物相对镜头静止时）：CAMERA MOUNTED ON [角色], LOCKED-ON SHOT, FIXED-TO-ACTOR

### 9. 小说/文本 → 动画

直接粘贴小说原文 + 风格参考视频
"帮我根据下面的小说剧情要求生成动漫，将画风动作打斗表现严格对齐@视频1的风格。剧情要求为：[小说原文]"
续拍："将@视频1延长15s，具体信息为：[后续小说文本]"

### 10. UI截图 → 微软Fluent风宣传片

步骤1：截图 → 图像模型处理（加亚克力玻璃质感）
步骤2：处理后图片 → Seedance 2.0
单张："基于@图片1生成一个类似微软Fluent UI宣传片的亚克力和玻璃质感动效设计视频，用丝滑的动效设计和不同角度的运镜展示UI细节"
多张：列出所有图片 + 产品介绍 + "多分镜多角度应用宣传片"

## 避坑指南

- 有常识的领域不要写细节，写意图就够
- 需要分镜时只写"注意分镜编排"，不要自己编分镜（除非你是专业人员）
- 参考视频风格时，要描述参考视频的核心特色，否则学得不好
- 人物相对镜头静止的场景（如骑扫帚飞行），需要加LOCKED-ON SHOT等关键词
- logo和文字细节受分辨率限制，可能不准
- 单张图片视觉效果比多张好，可以单独抽卡后拼接
- 真人主体参考需要本人验证或授权

## Agent自动化方向（API春节后上线火山引擎）

- 产品宣传Agent：产品更新→截图→图像处理→Seedance生成视频
- 口播Agent：热点收集→文案→音频→场景图→视频→拼接长视频
- 电商Agent：商品图+模特图→换装展示视频
- 家装Agent：户型图→分镜→参观视频
- 小说转漫剧Agent：文本→分段→逐段生成→续拍拼接
