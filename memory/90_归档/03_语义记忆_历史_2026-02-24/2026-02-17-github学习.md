## 2. GitHub Agentic Workflows（技术预览）

来源: GitHub Blog 2026-02-13

### 是什么

用 Markdown 写自动化工作流（替代 YAML），AI Agent 在 GitHub Actions 里执行。

### 核心设计

- **Markdown 定义**: 用自然语言描述目标，AI 自己决定怎么做
- **安全第一**: 默认只读权限，写操作需通过预批准的 "safe outputs"
- **沙箱执行**: 网络隔离、SHA 固定依赖、输出消毒
- **多 Agent 引擎**: 支持 Copilot CLI / Claude Code / OpenAI Codex
- **触发方式**: issue/PR 事件、定时、手动、评论命令

### 典型用例

- Issue 自动分类
- CI 失败根因分析
- 文档漂移修复
- 测试覆盖率提升
- 合规监控

### 对我们的启示

- **Markdown 定义工作流** 的思路可以借鉴到我们的 cron 任务和频道工作流
- **safe outputs 模式** = 我们的 exec 审批机制的理论基础
- **Peli's Agent Factory**: 50+ 专用 Agent 工作流模板，值得研究
- 可以考虑给 Lyra 项目加一个 GitHub Actions 集成

### 关键链接

- 仓库: github.com/github/gh-aw
- 文档: github.github.com/gh-aw/
- 50+ 模板: Peli's Agent Factory

## 4. sindresorhus/awesome：精选 Awesome Lists 聚合器

来源: GitHub sindresorhus/awesome

### 核心功能

- 不是具体工具，而是**高质量 Awesome lists 的集合**。
- 每个子列表针对特定主题（如编程语言、框架、工具、领域知识）精选资源。

### 价值点

- **资源聚合**：提供高质量、精选的学习和发现资源入口，避免信息过载。
- **社区驱动**：列表由社区维护，持续更新，反映最新趋势。
- **覆盖广泛**：涵盖编程、AI、设计、效率等多样化主题。

### 对我们的启示

- **学习入口**：作为快速入门和深入研究新 Agent 框架、Prompt Engineering 或任何技术栈的起点。
- **工具发现**：高效发现特定任务或领域（如图像生成）的开源工具。
- **记忆管理启发**：其分类和策展方式可启发我们优化 `memory/语义记忆` 的组织结构。考虑构建内部的“Awesome lists”来管理常用工具和资源。
