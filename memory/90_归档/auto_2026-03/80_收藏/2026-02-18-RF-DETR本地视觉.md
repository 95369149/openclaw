# 2026-02-18 本地实时视觉模型：RF-DETR (@berryxia)

## 来源

- Author: @berryxia (推文误写为 Rf-def)
- Correct Project: **RF-DETR** (roboflow/rf-detr)
- Link: https://x.com/berryxia/status/2023811161918239096
- GitHub: https://github.com/roboflow/rf-detr

## 核心能力

ICLR 2026 接收的 SOTA 模型，专为实时目标检测和分割设计。

### 特性

- **轻量级**：核心权重仅约 300MB。
- **实时性**：Real-time object detection，适合视频流处理。
- **本地化**：完全开源，无需联网即可运行。
- **功能**：识别人物、动物、物品，并支持运动轨迹分析（作者二次开发的 UI 功能）。

## Kitt 思考

- **视觉边缘计算**：OpenClaw 目前的视觉能力（Gemini/GPT-4V）是基于 API 的“帧级”分析，成本高且非实时。RF-DETR 可以部署在本地（甚至树莓派/Jetson），作为**视觉触发器**。
- **监控场景**：例如，RF-DETR 24小时监控画面，发现“有人入侵”或“特定手势”时，再触发 OpenClaw 调用大模型进行深度分析或报警。这是一个完美的**云边协同**案例。
