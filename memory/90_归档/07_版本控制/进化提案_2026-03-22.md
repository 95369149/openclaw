## 外链学习收获

1. **AI Agent Memory / Workflow 方向**：外部资料显示 2026 年 Agent 工作流的关键竞争点已经从“能不能跑起来”转向“有没有长期记忆层、混合检索、上下文压缩和偏好持久化”。Mem0、Zep 这类框架强调把对话提炼成 facts、实体、偏好和可检索经验，而不是只堆历史聊天记录。对红太阳的启示是：客户信息、设备参数、故障历史、报价记录不能只留在聊天和零散文档里，应该沉淀为结构化记忆层，支撑销售、售后、远程诊断三个场景共用。
2. **制造业 AI 落地方向**：3 月 21 日学习笔记里的政策与行业资料已足够说明趋势——AI+制造正在从单点试验进入全面赋能，重点落点集中在质量检测、客户服务、供应链管理、远程诊断与预测性维护。对红太阳最直接的落点不是空谈“智能工厂”，而是先把“质量检测 + 远程诊断 + 客户服务”做成样板闭环。
3. **产品化启示**：相比继续堆更多概念任务，红太阳下一阶段更值得推进的是“设备+培训+远程支持”的服务包，以及“客户/设备知识图谱记忆层”。前者解决客户不会用、售后重的问题，后者解决 AI 员工没有长期上下文的问题。
