# 进化提案 2026-03-01

## 提案 1: 多 Agent 交互权限隔离与压力测试
- **背景**: 根据最新 Agentic AI Risk Management 研究，多 Agent 系统最大的风险不在于单个 Agent，而在于 Agent 之间以及与环境交互的网络效应（例如日前的代理配置乱码污染全局）。
- **方案**: 为 kitt、deep、main 等子 agent 建立更严格的读写权限边界（例如只读核心配置，写入沙盒），并在大规模上线自动化流水线前，加入环境模拟压测环节。
- **状态**: pending

## 提案 2: 探索 CNC 设备数字孪生服务方案
- **背景**: 制造业数智化转型已进入规模普及阶段，AI、数字孪生正全面嵌入制造全链条，第一梯队企业正发力“数据要素×”价值激活。
- **方案**: 结合 task-board 上的 T-005 项，针对红太阳核心柔性切割设备进行数字孪生可行性调研，探寻从“卖硬件”向“卖整体虚拟仿真与数据解决方案”的升级路径。
- **状态**: pending

## 提案 3: 落实 "Write-to-File" 绝对记忆法则
- **背景**: OpenClaw 的高级实践反复证明，由于会话上下文压缩机制，聊天窗口内的记忆极不可靠。唯一能穿透重启的只有三层记忆文件系统。
- **方案**: 在现有的 shared 记忆协议基础上，进一步加固所有 Agent 的“落笔”习惯，任何业务决策和中间态数据均不依赖对话框缓存，必须即时 write 进文件。
- **状态**: pending
