## 📊 本周外部发现摘要

### 1. AGENTS.md 文件价值重估（InfoQ/ETH Zurich）

**来源**：https://www.infoq.com/news/2026/03/agents-context-file-value-review/

**核心发现**：

- ETH Zurich 研究表明：LLM 自动生成的 AGENTS.md 文件会**降低 3% 成功率**，增加 20% 成本
- 人工编写的 AGENTS.md 仅提升 4% 成功率，但增加 19% 成本
- 原因：过度指令导致 Agent 执行不必要的测试、文件读取、代码检查
- 建议：**只保留模型无法推断的非显性知识**（特殊工具链、自定义构建命令、领域知识）

**对我们的启发**：

- 当前 AGENTS.md 2800+ 行，可能存在冗余指令
- 需要审计：哪些是"模型能推断的"（如通用 Git 操作），哪些是"必须明说的"（如 Surge 配置、红太阳业务规则）

### 2. AI Agent 记忆架构演进（Let's Data Science）

**来源**：https://www.letsdatascience.com/blog/ai-agent-memory-architecture

**核心趋势**：

- **分层记忆架构**成为主流：短期（会话）→ 中期（任务）→ 长期（知识库）
- **向量数据库 + HNSW 索引**处理十亿级向量（我们当前用 QMD 文本搜索，未用向量）
- **PlugMem 模块**：将原始交互转为结构化知识（类似我们的 shared/ 机制）
- **OS 式虚拟内存管理**：Letta 框架模仿操作系统，主上下文 = RAM，外部存储 = Disk

**对我们的启发**：

- 当前记忆系统是文本 + 手动结构化，缺少自动向量化检索
- QMD 搜索在 <1000 条记忆时够用，但扩展性存疑

### 3. OpenClaw 高级自动化实践（Medium）

**来源**：https://medium.com/@rentierdigital/21-openclaw-automations-nobody-talks-about...

**核心实践**：

## 🎯 进化提案（P0/P1/P2 分级）

### P0（立即执行，影响核心稳定性）

#### P0-1：AGENTS.md 瘦身审计

**问题**：当前 AGENTS.md 2800+ 行，可能包含大量"模型能推断"的冗余指令，导致：

- 子 Agent 执行不必要操作（如过度测试、过度文件读取）
- Token 消耗增加
- 决策链路变长

**行动**：

1. 人工审计 AGENTS.md，标记三类内容：
   - ✅ 必须保留（非推断知识）：Surge 配置、红太阳业务规则、特殊工具链
   - ⚠️ 可精简（通用知识）：Git 基础操作、通用编码规范
   - ❌ 可删除（LLM 已知）：Markdown 语法、基础 CLI 命令
2. 创建 AGENTS_LITE.md（<1000 行），只保留 ✅ 类内容
3. A/B 测试 1 周：对比 jimmy 使用完整版 vs 精简版的成功率、步数、成本

**预期收益**：

- 降低 10-15% Token 消耗
- 减少子 Agent"过度勤奋"导致的失败

### P1（重要但非紧急，提升能力上限）

#### P1-1：引入向量记忆检索（实验性）

**问题**：当前 QMD 文本搜索在记忆 <1000 条时够用，但：

- 无法处理语义相似但用词不同的查询（如"客户跑了" vs "客户流失"）
- 扩展到 10000+ 条记忆时性能未知

**行动**：

1. 调研轻量级向量数据库（Chroma/LanceDB/本地 FAISS）
2. 在 memory/shared/ 目录做小规模实验（100 条记忆）
3. 对比 QMD vs 向量检索的召回率、速度、成本
4. 若效果显著，逐步迁移核心记忆到混合检索（文本 + 向量）

**预期收益**：

- 提升记忆召回准确率 20-30%
- 为未来记忆扩展到万级做准备

#### P1-2：Manifest 落地机制优化

**问题**：当前子 Agent 写文件成功率 <30%，依赖 jimmy 兜底重写，效率低

**行动**：

1. 分析最近 20 次子 Agent 失败案例，提取共性问题：
   - JSON 格式错误（括号不闭合、引号转义）
   - Base64 编码错误
   - 路径错误
2. 在派发模板中增加"自检清单"：
   - 输出前验证 JSON 可解析
   - Base64 内容长度 >0
   - 路径以 /Users/apple/.openclaw/workspace/ 开头
3. 升级 apply_manifest.py，增加更详细的错误提示

**预期收益**：

- 子 Agent 写文件成功率提升到 60-70%
- 减少 jimmy 兜底工作量
