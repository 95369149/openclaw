# 强制规则：防休眠配置

## 问题

macOS 合盖后会休眠，导致 Gateway 暂停，失联。

## 解决方案

### 方案1：系统设置（推荐）

1. 打开"系统设置"
2. 进入"电池"
3. 点击"电源适配器"
4. 勾选"防止自动休眠"

### 方案2：caffeinate 命令

```bash
# 启动防休眠（后台运行）
caffeinate -s &

# 查看进程
ps aux | grep caffeinate

# 停止防休眠
killall caffeinate
```

### 方案3：pmset 命令（需要 sudo）

```bash
# 插电时不休眠
sudo pmset -c sleep 0
sudo pmset -c disablesleep 1

# 查看当前设置
pmset -g

# 恢复默认（休眠）
sudo pmset -c sleep 10
sudo pmset -c disablesleep 0
```

## 验证不断线

### 测试步骤

1. 启动 Gateway：`openclaw gateway start`
2. 关闭终端
3. 等待 1 分钟
4. 重新打开终端
5. 检查状态：`openclaw gateway status`
6. 应该显示 `running`

### 合盖测试

1. 设置防休眠（方案1或2或3）
2. 合盖
3. 等待 5 分钟
4. 打开盖子
5. 检查状态：`openclaw gateway status`
6. 发送测试消息验证
