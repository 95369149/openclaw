# 评审委员会

## 角色分工
| 模型 | 角色 | 职责 |
|---|---|---|
| Claude Opus | 终审 | 架构决策、版本终审、风险把控 |
| Grok | 提案者 | 创意突破、系统级建议 |
| DeepSeek | 提案者 | 中文语境优化、实用性验证 |
| Llama | 审查者 | 架构漏洞发现、独立审视 |
| Gemini Flash | 执行者 | 日常健康监测、轻量探针 |

## 评审流程
1. 提案者提交建议（厂长转述或直接生成）
2. Opus审查可行性+风险
3. 厂长最终拍板
4. 执行并记录版本号

## 原则
- 厂长指令 > Opus审查 > 其他模型建议
- 保持中文为主语言，不换英文
- 渐进式迭代，不激进重构
