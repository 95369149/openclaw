# 强制规则：频道工作流协议

## 1. #收藏 (Bookmarks) - 认知进化引擎

**触发机制**:

- **被动触发**: 用户发布内容并 @Kitt
- **主动扫描**: 每 2 小时自动扫描 `#收藏` (channel: 1472885436149010443) 的最新消息。
  **核心指令**: **批判性吸收**
- **禁止**: 照单全收、盲目复制。
- **必须**:
  1. **判别**: 这对红太阳数控/OpenClaw 有用吗？是短期战术还是长期战略？
  2. **过滤**: 剔除营销废话，只留干货。
  3. **转化**: 将其转化为 `memory/` 中的具体条目（如 `强制规则`、`技巧` 或 `黑名单`）。
  4. **反馈**: 回复一条简短的分析报告：“已阅。提取了 [X] 点，认为 [Y] 点不适用，已存入 [Z]。”（仅针对新扫描到的未处理内容）

## 2. #日报 (Daily Report) - 自我迭代公示

**触发机制**: 每日定时 (22:00)
**核心内容**: **Kitt 的进化日志**

- **必须包含**:
  - 今日新增的 Skill/Capability。
  - 今日优化的 Memory/Rule。
  - 遇到的错误及修复方案 (Post-mortem)。
  - 明日重点计划。
- **禁止**: 流水账（"今天回复了 10 条消息"）。要写增量（"今天学会了如何抓取 X 视频"）。

## 3. #营销 (Marketing) - 出海战备

**触发机制**: 每日主动探测 (09:00)
**目标**: 为红太阳数控设备出海储备 TikTok 素材/脚本。
**源头**: X (Twitter)
**关键词**: `CNC machining`, `Machinery export`, `B2B marketing`, `TikTok viral industrial`
**执行动作**:

- 搜索高热度内容。
- 提炼其“爆点”逻辑。
- **编写**: 根据该逻辑，结合红太阳产品，写 1 个 TikTok 短视频脚本。
- **发布**: 发送到 `#营销` 频道供厂长审核。

## 4. #画画 (Drawing) - 儿童 AI 绘画
