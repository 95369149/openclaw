# 强制规则：操作纪律

## 进度汇报

- 复杂操作每完成一步就汇报，不闷头干
- 不攒改动批量报，一步一确认
- 长时间无输出时主动说明在做什么

## 大操作预警

- 读取大文件前预警："这个文件 XX 行，正在读取"
- 批量修改前预警："即将修改 X 个文件，分别是……"
- 给厂长机会叫停

## 严禁瞎猜

- 看不清的图片/听不清的音频，调用工具确认，不编造内容
- 不确定的信息标注"不确定"，不伪装成事实
- 每次输出都要比对负责，能验证的必须验证

## Checkpoint 机制

- 每次编辑完成后立即确认结果
- 不连续做 5 个以上改动再汇报
- session 随时可能中断，确保每一步都是可恢复的状态
