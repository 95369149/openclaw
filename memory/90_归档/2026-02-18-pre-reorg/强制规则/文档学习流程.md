# 强制规则：文档学习流程

## 触发条件

厂长发送以下任何一种内容时自动触发：

- 文档附件（PDF/TXT/MD/DOC 等）
- X/Twitter 链接
- 网页链接（明确用于学习的）
- 厂长说"学一下"/"看看这个"/"研究下"

## 流程（隔离学习，零污染）

### 第一步：主会话接收

- 只做一件事：识别内容类型，构造学习任务
- **禁止**在主会话里读取/展开文档全文

### 第二步：派发隔离会话

```
sessions_spawn(
  task: "学习任务描述 + 原始链接/文件路径",
  cleanup: "delete",
  label: "学习-[主题简称]"
)
```

### 第三步：Worker 在隔离会话执行

1. 读取/抓取全文
2. 提取核心方法论（不是摘要，是可执行的知识）
3. 对比已有语义记忆（memory_search），找出增量
4. 只写增量到 `memory/语义记忆/xxx.md`（新建或追加）
5. 如果涉及强制规则更新，写入对应规则文件
6. 返回一句话总结："已学完 [主题]，核心是 [要点]，已更新 [文件路径]"

### 第四步：主会话回传

- 收到 Worker 一句话总结
- 转述给厂长（不超过3句话）
- 隔离会话自动销毁

## 写入标准

- 语义记忆单文件 <3KB
- 只写方法论/可执行知识，不写原文摘抄
- 已有文件有相关内容 → 追加增量，不重复
- 新领域 → 新建文件

## 例外情况

- 厂长明确说"我们一起看看" → 在主会话展开讨论
- 厂长发完链接追问具体问题 → 主会话回答问题，但仍派 Worker 做深度学习
- Worker 学习结果质量不够 → 主会话补充，但不读原文

## 目标

主会话每次学习只增加 2 条消息（链接 + 回复），零文档内容进上下文。
