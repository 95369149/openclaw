# 画画频道处理规则

## 触发条件

当收到来自 Discord #画画 频道 (ID: 1473185796046721159) 的消息且 @Kitt 时自动触发

## 处理流程

### Step 1: 理解 + 优化 Prompt

用户（三年级小朋友）发送想画的内容，可能是中文、简短、模糊的描述。
AI 需要将其翻译/扩展为高质量英文 prompt：

- 基础风格词: `children's book illustration, colorful, cute, kawaii, soft colors, friendly`
- 保持童趣，不要写实风格
- 补充细节（背景、表情、动作）让画面更丰富
- 避免任何不适合儿童的内容

### Step 2: 调用生成脚本

```bash
python3 ~/bin/kitt-draw.py "用户原始描述" "优化后的英文prompt"
```

脚本会自动：

1. 先尝试 Gemini API 生图（真实图片文件）
2. 失败则 fallback 到 Pollinations.ai
3. 最后通过 Discord Webhook 发送图片到 #画画 频道

### Step 3: 回复用户

在频道里简短温暖地回复，比如「画好啦！🎨」

## 特殊指令

- 「再画一次」/ 「换一个」: 用相同 prompt 重新调用脚本（seed 随机）
- 「画大一点」: 暂不支持，回复说明
- 「画 XX 风格」: 替换风格关键词（如 watercolor, pixel art, 3D render）

## 安全规则

- 所有内容必须适合儿童（G-rated）
- 如果请求不当内容，温柔引导换个主题
