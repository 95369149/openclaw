# 强制规则：记忆管理

## 记忆分层架构 (Layered Architecture)

### L1: 战略记忆 (Strategic)
- **文件**: `MEMORY.md`
- **内容**: 身份、长期目标、用户偏好、核心教训、系统架构。
- **加载**: 每次启动/主会话必读。
- **更新**: 低频，仅在有重大变化或深刻教训时更新。

### L2: 操作记忆 (Operational)
- **文件**: `memory/active-context.md`
- **内容**: **当前正在做的事**。进行中的项目状态、阻塞点、承诺、下一步计划。
- **加载**: 每次启动/主会话必读（上下文补充）。
- **更新**: **高频**。每次重要任务推进、状态变更、会话结束前必须更新。
- **原则**: 它是"我刚才在干嘛"的直接答案。防止任务丢球。

### L3: 战术记忆 (Tactical)
- **文件**: `memory/YYYY-MM-DD.md`
- **内容**: 每日流水账、原始笔记、临时想法。
- **加载**: 按需检索。
- **更新**: 实时追加。
- **归档**: 定期清理，有价值的提炼到 L1/L2，无价值的留底或压缩。

### L4: 语义记忆 (Semantic)
- **文件**: `memory/语义记忆/*.md`
- **内容**: 知识、技能、方法论、分析报告。
- **加载**: 按需检索。

## 记忆维护规则
1. **启动时**: 读 MEMORY.md + active-context.md。
2. **任务切换**: 更新 active-context.md，记录当前进度。
3. **每日结束**: 整理 YYYY-MM-DD.md，更新 active-context.md。

## 记忆提炼时机
- 每次自我迭代时
- 发现重复模式时（≥3次）
- 完成重大项目后

## 提炼流程
情景记忆 → 识别模式 → 语义记忆
语义记忆 → 发现必须遵守的规则 → 强制规则

## 月记合并机制
- 触发：每月初合并上月日记
- 规则：所有日记合并为 YYYY-MM-月记.md
- 合并后删除原始日记，只保留月记

## Memory 过载防护
- 常驻层（自动加载）总量不超过 8KB，只放指针和索引
- 按需层：单文件不超过 3KB，超过必须拆分
- MEMORY.md 只做目录，不堆内容
- 每次写入记忆前检查目标文件大小，超限先归档再写新文件

## 命名规范
- 情景记忆：MMDD-简短描述.md
- 语义记忆：[主题]_[类型].md
- 强制规则：强制规则_[领域].md（或 行为约束.md 等）
