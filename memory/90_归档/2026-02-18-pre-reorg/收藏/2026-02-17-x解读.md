## 1. @cathrynlavery — OpenClaw 记忆系统搭建指南

- 来源：https://x.com/cathrynlavery/status/2023496245981982803
- 数据：478赞 / 1581收藏 / 43K浏览
- 作者：BestSelf Co 创始人（$55M+ bootstrapped）
- 价值：⭐⭐⭐⭐ 实操指南

### 核心框架：5 文件构建 AI 员工

| 文件        | 作用                                                   |
| ----------- | ------------------------------------------------------ |
| SOUL.md     | 人格/语气/边界，"NOT"清单比"IS"重要                    |
| IDENTITY.md | 名字+职位+角色，"Chief of Staff" > "Helpful assistant" |
| USER.md     | 用户画像/偏好/沟通风格                                 |
| TOOLS.md    | 工具清单+已知限制+失败处理方案                         |
| MEMORY.md   | 长期记忆，AI 自维护，每日笔记→定期蒸馏                 |

### 关键洞察

- "NOT" 清单迭代法：每次 AI 犯错就加一条，一个月后烦人行为基本消失
- Correction Loop：不只聊天纠正，写进 AGENTS.md 永久生效
- TOOLS.md 记"不能做什么"比"能做什么"更重要（省无数次重试）
- "说记住就写文件"：Agent 口头承诺无效，必须当场持久化
- 安全隔离：MEMORY.md 只在 1:1 加载
- 3 个月后 AI 运营上下文 > 人类员工第一年

### 对我们的差距

- ❌ 缺 TOOLS.md（工具能力+已知限制清单）
- ✅ 其余 4 个文件我们都有对应实现

### Eric Siu 的 4-Agent 架构

| Agent  | 职责                  |
| ------ | --------------------- |
| Oracle | SEO 关键词缺口扫描    |
| Flash  | 内容角度+风格匹配写作 |
| Alfred | CRM 扫描、战略简报    |
| Cyborg | 招聘候选人筛选+外联   |

### 关键数据

- 34 cron / 71 scripts，每天 5AM 开跑，8AM 推送 Telegram 审批
- 周成本 $63（月 $271），60% 花在基础设施（记忆/上下文/反遗忘层）
- 基础设施从 Opus→Sonnet 省 $30/周
- 6 个子 Agent 并行，8 分钟完成 6 个生产系统

### 踩坑实录（最有价值）

1. **静默失败** — 内容 Agent 48h 没跑，零报错。必须加健康检查
2. **编造数据** — Agent 自信编报告。修复：先跑脚本→读输出→再汇报，trust nothing
3. **重复推荐** — 同一客户连推 3 天。修复：14 天去重+反馈历史
4. **成本失控** — 简单脚本用最贵模型，两周没审计

### Leo 补充

- 建系统 20% 时间，修系统 80%
- 护城河不是 AI，是反馈循环（feedback loop）
- 共享大脑（symlinked directory）解决 Agent 间重复/矛盾

### 维护体系

- 月度：质疑每个系统，无情删除，简化幸存者
- 周度：自愈（auto-fix fails）+ 系统清洁工（prune files/track costs）
- 规则：Agent 建议被忽略 3 周 → 标记删除，no sacred cows
- 垃圾回收必须和建设一样自动化，否则 90 天淹死
