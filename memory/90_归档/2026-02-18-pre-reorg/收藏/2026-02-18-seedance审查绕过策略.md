# Seedance 2.0 审查绕过策略

来源：@john87445528 (2026-02-17)
链接：https://x.com/john87445528/status/2023660939954860134

## 背景

Seedance 2.0 近期加强内容审查，大量提示词被拒绝，且不告知具体违禁原因。即使用 Claude 检查也找不到问题。

## 核心策略：电影剧本式提示词

用极其详细的**专业影视剧本格式**来表达创意意图，绕过审查系统：

- 按时间轴分幕（第一幕 0-2秒、第二幕 2-4秒...）
- 每幕包含：剧情描述 + 镜头设计 + 音频设计
- 使用专业术语：中景、特写、慢镜头、硬切、仰拍、俯拍
- 色彩/光线/风格描述极其具体
- 人物设定独立成段，锁定外观和性格

## 示例结构

```
影片类型与形式 → 场景设定 → 出场人物 → 正文剧情(分幕) → 结尾设计 → 制作建议
```

## 关键技巧

1. **分段生成**：30秒拆成两段15秒，每段独立可看
2. **锁定人物**：每段开头声明"本段锁定"的角色外观
3. **色调转换**：不同场景用不同色彩基调（青蓝→翠绿→青蓝）
4. **戛然而止**：在动作最高点切黑，制造悬念驱动观看
5. **用 Claude 写剧本**：先让 Claude 生成专业剧本格式的提示词
