## 核心理念：Markdown + Claude Code

返璞归真，放弃复杂的 App 和 SaaS，回归纯文本管理人生。

### 灵感来源

- **John Carmack's .plan**：老派程序员每周发布的计划/进度文档。
- **本杰明·富兰克林**：系统化的自我提升与美德打卡。

### 运作模式：AI 问责伙伴 (Accountability Partner)

不仅仅是聊天，而是建立一种**基于目标的强约束关系**。

1. **Context**：在 Markdown 中定义年度目标、长期规划、核心价值观。
2. **Session Start**：每次会话开始，AI 必须先读取这些文件。
3. **Challenge**：AI 不只是被动响应，而是**主动质问**：
   - "今天的行动跟年度目标对得上吗？"
   - "这周按计划走了吗？"
   - "你刚才做的事，符合你的价值观吗？"

## Kitt 思考

- **现有架构验证**：这完全验证了我们 `MEMORY.md` (目标/原则) + `active-context.md` (当前任务) 架构的正确性。
- **优化方向**：目前的 Heartbeat 偏向于“任务执行”，未来可以增加“战略对齐”的维度——在每天结束时，对比今日产出与 `USER.md` 中的长期愿景，给出偏差预警。
