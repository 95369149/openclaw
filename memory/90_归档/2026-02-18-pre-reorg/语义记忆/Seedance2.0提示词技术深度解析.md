# 语义记忆：Seedance 2.0 提示词技术深度解析

## 核心架构：从"文本转视频"到"AI导演"

Seedance 2.0 不再只是简单的文本到视频转换，而是真正的**多模态导演系统**，能够理解复杂的故事结构、相机控制、音频集成和视觉一致性。

## 核心提示词公式

### 基础公式（单镜头）

```
主题 + 动作 + 相机运动 + 风格/环境
```

### 高级公式（多镜头）

```
主题 + 动作1 → 相机运动1 → 主题 + 动作2 → 相机运动2
```

## 8层技术体系

### Level 1: 基础提示技巧

- **主题+动作**："年轻女子穿着红裙行走" > "一个人"
- **相机运动**：轨道环绕、变焦、平移、跟随、无人机、手持、固定
- **环境风格**："日落时公园，金色时刻光线，电影级质量"

### Level 2: 连续动作

- **单主体多动作**："男人在公园慢跑 → 停下来看手机 → 继续跑"
- **多主体不同动作**："女人遛狗时骑自行车的人从背景经过"

### Level 3: 多镜头叙事（核心优势）

- **镜头类型**：特写、中景、全景、过肩、第一人称
- **一致性保持**：面部特征、服装细节、体型、光照色彩一致

### Level 4: 高级相机控制

- **复杂运动**："无人机从城市上空开始，缓慢下降同时绕摩天楼轨道飞行，过渡到手持POV进入建筑"
- **速度动态**：慢动作跟踪、快节奏跟随、平稳稳定器、动态动作相机

### Level 5: 专业光照氛围

- **时间光线**：金色时刻、正午强光、柔和晨光、蓝色时刻、夜间街灯
- **天气氛围**：雾蒙蒙早晨、暴雨风暴云、轻柔飘雪、阳光中尘埃粒子

### Level 6: 产品商业视频

- **产品演示**："奢侈品手表360度旋转，突出表盘细节和金属光泽，柔和影棚光线，以表冠调整特写结束"
- **生活方式**："现代咖啡店中使用笔记本电脑的女性，手部打字特写，微笑看屏幕中景，舒适氛围全景"

### Level 7: 风格美学控制

- **视觉风格**：照片级电影质量、动漫风格、黑色电影、水彩艺术、赛博朋克、复古70年代
- **色彩分级**：暖橙青色调、去饱和柔和色、鲜艳饱和调、单色蓝调

### Level 8: 音频集成

- **原生音频生成**："女性对镜头清晰说话，背景咖啡店环境音，柔和爵士乐"
- **音效音乐**：脚步声、汽车引擎、风声、城市交通、电子音乐、管弦乐

## 9大杀手级特性

1. **近乎完美的帧间一致性**：角色、服装、光照跨帧保持一致
2. **强大参考系统**：
   - 一张图像锁定视觉风格
   - 一个视频锁定相机运动和动作
   - 一个音频轨道锁定节奏和步调
3. **自动多镜头叙事**：单一描述生成完整故事
4. **原生音频+视频**：同步对话和音效
5. **强物理真实感**：布料、流体、重力、战斗

## 工作流程

1. **选择Seedance 2.0模型**
2. **编写导演式提示词**
3. **上传参考文件**（最多12个：图像、视频、音频）
4. **设置关键参数**：时长、宽高比、分辨率、音频生成、种子、创意度
5. **生成并迭代**

## 对我们的启示

### 对Lyra项目的借鉴

- **多镜头叙事**：可以应用到我们的多Agent工作流编排
- **一致性保持**：类似我们的记忆系统需要保持上下文一致性
- **参考系统**：类似我们的技能(SKILL.md)和模板机制

### 对HTYCNC视频制作的指导

- **产品演示公式**：直接适用于数控设备展示视频
- **多角度叙事**：从特写细节到全景展示的完整流程
- **专业光照氛围**：工业设备的专业感营造

## 常见错误避免

- 避免模糊描述（"酷"、"好光线"）
- 按时间顺序列出动作
- 具体化主题描述
- 利用参考系统提升一致性

Seedance 2.0 标志着AI视频从工具向导演的转变，其提示词技术代表了当前最高水平的AI视频生成能力。
