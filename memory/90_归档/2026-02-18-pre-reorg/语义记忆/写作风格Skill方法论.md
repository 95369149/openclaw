# 语义记忆：写作风格Skill方法论

来源：宝玉(@dotey) 2026-02-15

## 核心洞察

- "去AI味"提示词是错的方向——所有人用同一套去AI味提示词，产出又变成新的同质化（AI味2.0）
- AI味本质：AI用所有训练数据的平均风格写作，输出"最大公约数"
- 正确方向：不是去掉AI味，而是用你自己的味道盖过去

## 解法：写作风格Skill（持续迭代的菜谱）

提示词 = 口头跟厨子说"少盐少辣"，下次就忘
Skill = 写下来的菜谱，每次做菜前都翻一遍

## 四步建立法

1. 让AI尝你的菜：提供3-5篇自己最满意的原创文章，AI分析写作特点
2. 照菜谱做菜你来尝：AI按Skill写，你手动改到满意
3. 根据反馈更新菜谱：AI对比原文和修改版，提取规则更新Skill
4. 反复迭代：每篇文章都是迭代机会，~10次后AI比你自己更一致

## Skill文档结构（四部分）

1. 角色与读者 — 你是谁，读者是谁，语气基调
2. 风格要点 — 3-5条核心原则 + 正反面示例
3. 禁止清单 — 忌口表（废话开场白/商业黑话/公式化句式/AI味词汇）
4. 参考资料 — 术语表/范文/常见错误

## 组合用法

- 写作风格 + 润色（像你 + 够好）
- 写作风格 + 翻译（带风格的翻译）
- 写作风格 + 访谈整理（录音→你风格的文章）

## 对Kitt的启示

- 可以用skill-creator为厂长建立写作风格Skill
- 需要厂长提供原创文章样本
- Skill是活的，每次写作都是迭代机会
