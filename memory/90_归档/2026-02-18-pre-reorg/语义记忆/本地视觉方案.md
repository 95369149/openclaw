# 语义记忆：本地视觉与云边协同方案

## 核心理念：小模型吹哨，大模型干活

利用轻量级本地模型（如 RF-DETR）进行 7x24 小时低功耗监控，发现特定事件（Trigger）后，唤醒云端多模态大模型（Gemini/GPT-4V）进行深度分析。

## 架构设计

### Edge (本地/边缘端)

- **模型**：RF-DETR (roboflow/rf-detr) / YOLOv10
- **硬件**：MacBook Pro (本地), Raspberry Pi, Jetson Nano
- **任务**：
  - 实时视频流分析 (FPS > 30)
  - 目标检测 (人、车、宠物)
  - 运动侦测 (Motion Detection)
- **输出**：仅在检测到目标时截取关键帧 (Keyframe) 并上传。

### Cloud (云端/OpenClaw)

- **模型**：Gemini 2.5 Flash / GPT-4o
- **任务**：
  - 接收关键帧
  - 语义理解 ("这个人是谁？他在干什么？是否危险？")
  - 决策执行 (报警、发送 Telegram 通知、记录日志)

## 典型场景

1. **智能安防**：RF-DETR 发现有人进入 -> 截图 -> Gemini 分析是快递员还是陌生人 -> 通报厂长。
2. **工业质检**：本地检测产品位置 -> 截图 -> 大模型判断表面瑕疵。
3. **宠物看护**：检测到猫狗 -> 截图 -> 大模型生成"猫咪日记"。
