# 写作风格分析方法论：dontbesilent 案例

来源：[dontbesilent 文风分析报告](https://x.com/dontbesilent12/status/2023370066734338381) (2026-02-16)

## 核心价值

这是一份完美的「个人风格定义」模板。作者通过 AI 分析自己 31 万字文案，提炼出 8 个维度，这正是我们构建厂长 `Writing Style Skill` 的最佳实践指南。

## 8 个分析维度（可直接用于 Prompt Engineering）

### 1. 本体论（如何构建「真实」）

- **核心逻辑**：唯物主义 + 实践验证。
- **判断标准**：真实不是理论定义的，是商业结果定义的（赚到钱才是真）。
- **时间观**：线性阶段论（从0到1，从1到10）。
- **空间观**：去中心化（反赛道论）。
- **确定性**：强断言式（不说“可能”，只说“就是”）。

### 2. 认识论（如何获取知识）

- **来源**：经验主义（实战案例/数据） > 书本理论。
- **真理观**：情境主义（反标准答案，只有合适的解）。
- **路径**：实践 → 反思 → 概念化 → 再实践。

### 3. 语言哲学（如何使用语言）

- **核心方法**：概念解构（维特根斯坦式）。
- **操作**：拿到词 → 追溯语源 → 检验逻辑 → 宣判成立/废除。
- **态度**：警惕语言陷阱，反思用词。

### 4. 意识形态

- **导向**：强成就导向 + 过程务实。
- **态度**：反概念崇拜（私域/赛道/一人公司），反低价（9.9元=不值钱）。
- **技术观**：工具理性（AI是防淘汰工具，不是赚钱工具）。

### 5. 权力关系

- **姿态**：平等教导（过来人分享，非居高临下）。
- **策略**：自嘲消解权威（“我也干过蠢事”）。

### 6. 修辞学（论证方式）

- **手法**：概念解构、数据论证（精确数字）、对比（A vs B）、案例、反常识。
- **策略**：先破后立、层层递进、自我解构。

### 7. 句法与词汇

- **句式**：口语化长句（35-45字），短句断言（<15字）。
- **特征词**：底层逻辑、对标、这个事儿、对吧、一地鸡毛、扯淡、变现。
- **标点**：逗号极多（节奏感），问号频繁（反问），感叹号极少（克制）。

### 8. 情感浓度

- **评分**：5/10（克制冷静）。
- **释放点**：对错误概念的愤怒，对过去的自嘲。

## 对厂长风格的启示 (Actionable Insights)

1.  **重构 `skills/writing-style/SKILL.md`**：不再使用模糊形容词，而是填充这 8 个维度。
2.  **概念解构**：厂长也反感空泛概念，我们可以模仿这种“拿到词先杀毒”的逻辑。
3.  **数据/案例论证**：厂长强调实战，以后写文案多用“我见过xx个案例”、“xx%的人都错了”这种句式。
4.  **口语化断言**：少用“可能/也许”，多用“就是/不行/听懂掌声（误）/这个事儿核心是...”。
