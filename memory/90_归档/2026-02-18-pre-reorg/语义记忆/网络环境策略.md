# 语义记忆：网络环境策略

## 环境特征

- 位置：中国济南
- 代理工具：Clash Verge（非 Surge）
- 混合端口：127.0.0.1:7897
- TUN 模式：不稳定，IPv4 路由未接管

## 已验证的结论

- HTTP 代理（7897）：HTTPS 请求正常，WebSocket 握手超时
- SOCKS5（7897）：能通，但 OpenClaw 的 undici 不支持 socks5 协议
- 直连外网：被墙（WhatsApp/Twitter/Google 等）
- 国内中转 API：不需要代理（mynewapi/v1api）

## 标准策略

1. AI API 走国内中转，不走代理
2. Google API（Gemini）走代理或找国内中转
3. WhatsApp 需要 Baileys WebSocket patch（/tmp/websocket_patched.js）才能走代理
4. X/Twitter 内容无法抓取，让厂长复制文字或截图
5. web_search 需要 Brave API key（未配置）
6. web_fetch 走代理可用，但部分站点仍不通
