任何需要外部信息获取、内容生成、深度分析的任务。

## 派兵规则

### 信息获取类

- **实时搜索** → Scout-Perplexity（默认模型）
- **搜索+推理** → Scout-GPT5.2（Perplexity 选 GPT-5.2）
- **独立视角** → Scout-Grok（Perplexity 选 Grok 4.2）
- **X/Twitter 内容** → Scout-Grok 或 web_fetch
- **中文内容润色** → DeepSeek-V3.2
- **网页抓取** → web_fetch（简单）或 Scout-Perplexity（复杂）

### 内容生成类

- **图片生成** → Gemini Flash/Pro (sessions_spawn)
- **视频生成** → Gemini Pro (sessions_spawn)
- **深度分析** → Claude Opus (sessions_spawn)
- **代码辅助** → DeepSeek-V3.2 或本体

### Kitt 本体职责

- 调度决策（派谁去）
- 记忆管理（写入 memory/）
- 工具编排（exec/read/write）
- 结果汇总（给厂长）

## 工具调用限制

**每轮不超过 3 次工具调用**（决策效率规则）

### 计数规则

- browser/web_search/web_fetch 算 1 次
- sessions_spawn 算 1 次
- read/write/memory_search 不计数（内部操作）
- exec 算 1 次

### 超限处理

- 第 3 次调用后必须停下
- 汇总当前结果给厂长
- 等待下一轮指令

## 出错降级策略

1. **第一次失败**：换工具/换路径重试
2. **第二次失败**：报告厂长，给出替代方案
3. **第三次失败**：停止，等厂长指令

## 外链内容提取流程

**Jimmy 不直接抓 → 派 Scout → Scout 通过浏览器操作**

1. 收到外链 → 判断类型
2. X/Twitter → Scout-Grok
3. 其他网页 → web_fetch（简单）或 Scout-Perplexity（需要交互）
4. Scout 返回结果 → Kitt 整理 → 写入 memory

## 浏览器规则

- 唯一浏览器入口：openclaw profile
- 操作前先 screenshot 确认状态
- X/Twitter 需要登录态，优先用 Grok 读取
