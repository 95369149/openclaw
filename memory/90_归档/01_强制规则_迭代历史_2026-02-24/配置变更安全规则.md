# 配置变更安全规则

## 权限规则（最高优先级，厂长 2026-02-23 12:18 指令）

**只有 Kitt（agent jimmy）有权修改以下文件：**
- `~/.openclaw/openclaw.json`（Gateway 配置）
- `memory/` 下的大脑框架文件（scripts/、_meta/、_index.json）
- `SOUL.md`、`IDENTITY.md`、`HEARTBEAT.md`

**其他 Agent（main/logic/deep/kitt）：**
- ❌ 禁止直接修改配置文件和大脑框架
- ✅ 可以提出修改建议，通过 sessions_send 发给 Kitt
- ✅ Kitt 审查确认无误后才执行修改
- ✅ 修改后由 Kitt 负责验证和重启

**违反此规则 = 事故，必须写入反思日志。**

## 核心原则
**任何配置变更，必须先验证，再重启。绝不允许自己失联。**
**永远不能因为配置错误启动不起来。**

## 强制规则 1：醒来第一时间查记录
不管是重启、恢复备份、还是任何原因醒来，**第一时间**：
1. 读取 `memory/2026-MM-DD.md`（今天 + 昨天）
2. 读取 `memory/01_强制规则/` 下的关键规则
3. 检查 `openclaw config get agents.list` 和 `agents.defaults.model`
4. 确认当前状态后再开始工作

## 强制规则 2：配置变更由 Kitt 或质检检查
**改完配置后，不要自己检查！**
1. 改完配置 → 调用 `sessions_spawn(agentId="kitt")` 让 Kitt 检查
2. Kitt 验证通过 → 报告厂长
3. 厂长确认 → 才能重启
4. **自己改自己查 = 球员兼裁判 = 禁止**

## 强制流程

### 1. 变更前（Pre-Change）
- [ ] 备份当前配置：`cp ~/.openclaw/openclaw.json ~/.openclaw/openclaw.json.pre-change`
- [ ] 说明变更内容和预期效果
- [ ] 等待厂长确认

### 2. 变更中（Change）
- [ ] 执行配置修改
- [ ] **派 Kitt 或质检 Agent 验证配置**（不要自己查）
- [ ] 检查关键路径：`agents.list`、`agents.defaults.model`、`gateway.mode`
- [ ] 检查所有 providers 是否有废弃参数（如 streamOnly）
- [ ] **如果验证失败，立即回滚**

### 3. 变更后（Post-Change）
- [ ] **不要立即重启**
- [ ] 报告验证结果给厂长
- [ ] 等待厂长确认后再重启
- [ ] 重启后立即检查连接状态

### 4. 失联预防
- [ ] 重启前告知厂长："即将重启，可能短暂失联"
- [ ] 重启后主动报告："已重启，连接正常"
- [ ] **如果超过 2 分钟未恢复，视为失联事故**

## 禁止行为
❌ **绝不允许：**
1. 配置后直接重启（不验证）
2. 自己改配置自己验证（球员兼裁判）
3. 验证失败还继续重启
4. 重启后不主动报告状态
5. 配置变更不备份
6. 引入废弃参数（如 streamOnly）导致启动失败

## 失联应急
如果发生失联：
1. 厂长手动检查：`openclaw gateway status`
2. 查看日志：`tail -100 /tmp/openclaw/openclaw-$(date +%Y-%m-%d).log`
3. 回滚配置：`cp ~/.openclaw/openclaw.json.bak ~/.openclaw/openclaw.json`
4. 重启：`openclaw gateway restart`
