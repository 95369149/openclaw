# 强制规则：长时间任务实时反馈

## 问题
长时间任务（如 brew install）等待时，厂长会以为 Kitt 断线了。

## 解决方案

### 1. 任务开始时立即反馈
```
开始安装 jq, ripgrep, ffmpeg, tmux...
预计需要 10-15 分钟，我会每分钟更新进度。
```

### 2. 定期进度更新
- **每 30-60 秒**推送一次进度
- 不要等任务完成才一次性推送几十条

### 3. 进度推送格式
```
[1/4] 正在安装 jq... ✓
[2/4] 正在安装 ripgrep... ⏳
```

### 4. 完成时汇总
```
✅ 安装完成
- jq: ✓
- ripgrep: ✓
- ffmpeg: ✓
- tmux: ✓
```

## 适用场景
- brew install（编译时间长）
- 大文件下载
- 批量操作
- 任何超过 30 秒的任务

## 实现方式
- 使用 `process(action=poll, timeout=30000)` 定期检查
- 每次 poll 后立即推送当前状态
- 不要用 `yieldMs=180000` 等很久才返回
