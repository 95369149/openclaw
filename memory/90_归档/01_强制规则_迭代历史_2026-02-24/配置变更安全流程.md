# 强制规则：配置变更安全流程

## 核心原则
**配置变更前必须验证，避免因配置错误导致 Gateway 无法启动**

## 安全流程

### 1. 变更前检查
```bash
# 备份当前配置
cp ~/.openclaw/openclaw.json ~/.openclaw/openclaw.json.manual-backup

# 验证 JSON 格式
cat ~/.openclaw/openclaw.json | jq . > /dev/null
# 如果有错误会报错，无错误则继续
```

### 2. 配置变更
- 使用 `openclaw config set` 命令
- 每次变更后自动生成 `.bak` 备份

### 3. 变更后验证
```bash
# 验证 JSON 格式
jq . ~/.openclaw/openclaw.json > /dev/null

# 检查关键配置项
openclaw config get agents.defaults.model
openclaw config get models.providers | jq 'keys'
```

### 4. 重启前确认
- ✅ JSON 格式正确
- ✅ 关键配置项存在
- ✅ Fallback 链不为空
- ✅ 至少有 1 个免费模型

### 5. 安全重启
```bash
# 重启 Gateway
openclaw gateway restart

# 等待 5 秒
sleep 5

# 验证启动成功
openclaw gateway status
```

### 6. 启动失败回滚
```bash
# 恢复备份
cp ~/.openclaw/openclaw.json.bak ~/.openclaw/openclaw.json

# 或恢复手动备份
cp ~/.openclaw/openclaw.json.manual-backup ~/.openclaw/openclaw.json

# 重启
openclaw gateway restart
```

## 防止失联的配置要求

### 必须项
1. **Fallback 链不为空**（至少 3 个模型）
2. **至少 1 个免费模型**（Groq/Gemini/硅基流动）
3. **硅基流动 API key 轮动**（环境变量配置）

### 推荐项
1. 主力用免费模型（DeepSeek-V3.2）
2. 付费模型放在 Fallback 链末尾
3. 定期检查模型可用性

## 合盖/关终端不断线

### macOS 防休眠设置
```bash
# 方案1：系统设置
# 系统设置 → 电池 → 电源适配器 → 防止自动休眠（勾选）

# 方案2：caffeinate 命令
caffeinate -s &
# 保持系统不休眠（即使合盖）

# 方案3：pmset 命令
sudo pmset -c sleep 0
sudo pmset -c disablesleep 1
```

### Gateway 后台运行
- ✅ 已配置 LaunchAgent（自动后台运行）
- ✅ 不依赖终端（关闭终端不影响）
- ❌ 合盖会休眠（需要防休眠设置）

### 验证不断线
```bash
# 1. 启动 Gateway
openclaw gateway start

# 2. 关闭终端
# 3. 等待 1 分钟
# 4. 重新打开终端，检查状态
openclaw gateway status
# 应该显示 running

# 5. 合盖测试（需要先设置防休眠）
# 合盖 → 等待 5 分钟 → 打开盖子 → 检查状态
```

## 配置变更检查清单

### 变更前
- [ ] 备份当前配置
- [ ] 验证 JSON 格式
- [ ] 记录变更内容

### 变更后
- [ ] 验证 JSON 格式
- [ ] 检查 Fallback 链
- [ ] 检查免费模型
- [ ] 验证关键配置项

### 重启后
- [ ] Gateway 启动成功
- [ ] RPC probe ok
- [ ] 发送测试消息验证

## 紧急恢复

### Gateway 无法启动
```bash
# 1. 查看日志
tail -100 /tmp/openclaw/openclaw-$(date +%Y-%m-%d).log

# 2. 恢复备份
cp ~/.openclaw/openclaw.json.bak ~/.openclaw/openclaw.json

# 3. 重启
openclaw gateway restart

# 4. 如果还是失败，恢复黄金备份
cp ~/Library/Mobile\ Documents/com~apple~CloudDocs/OpenClaw_Memory/黄金备份/openclaw.golden.json ~/.openclaw/openclaw.json
openclaw gateway restart
```
