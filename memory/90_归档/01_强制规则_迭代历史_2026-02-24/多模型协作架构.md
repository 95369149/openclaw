# Kitt 多模型协作架构 v2.0
> 厂长思路：Gemini 3 Pro 做主脑，按任务类型下发给不同模型

## 架构总览

```
厂长 ←→ [Gemini 3 Pro] 主聊天 + 调度中心
              │
    ┌─────────┼─────────────┐──────────────┐
    ▼         ▼             ▼              ▼
[Sonnet     [免费模型兵团]  [免费模型兵团]  [免费模型兵团]
 Thinking]   学习/抓取      定时任务        收藏处理
 配置修改    上网冲浪       叫醒/日报       文档提取
 大脑维护    信息收集       备份检查        知识入库
```

## 任务路由规则

### 厂长直接对话 → Gemini 3 Pro
- 日常聊天、问答、建议
- 任务分配和调度决策
- 简单查询和快速回复

### 需要改配置/改大脑 → Sonnet Thinking
- 修改 openclaw.json
- 修改 SOUL.md / MEMORY.md / 强制规则
- 复杂系统架构决策
- 调用方式：sessions_spawn(model="mynewapi/claude-sonnet-4-6")

### 学习/上网冲浪 → 免费工兵轮换
- 文档提取和知识入库 → DeepSeek V3.2（中文强）
- 网页抓取和信息收集 → Groq Llama（快）
- 中文摘要和内容生成 → Groq Qwen3（中文优化）
- 调用方式：sessions_spawn(model="siliconflow/deepseek-ai/DeepSeek-V3.2")

### 定时任务 → 按类型分配
- 心跳/备份检查 → Gemini Flash（最轻量）
- 日报/抓取类 → Groq Llama 或 DeepSeek
- 收藏扫描 → DeepSeek V3.2

## 频率控制策略

### 原则：错峰 + 分散 + 留余量

| 时段 | 任务 | 模型 | 说明 |
|---|---|---|---|
| 08:00 | GitHub Trending 日报 | Groq Llama | 独占时段 |
| 08:05 | AI News 日报 | DeepSeek V3.2 | 不同平台，不冲突 |
| 09:00 | GitHub Star + TikTok素材 | 分别用 Groq/DeepSeek | 错开5分钟 |
| 09:30 | AI社区热点 | Groq Qwen3 | 换模型避免限流 |
| 10:00 | 提示词迭代 + OpenViking | DeepSeek / Groq | 交替 |
| 每2h | 收藏扫描 | DeepSeek V3.2 | 低频 |
| 每4h | 滚动备份 | 主会话（不消耗子agent额度）| systemEvent |
| 22:00 | 日报-进化日志 | DeepSeek V3.2 | |
| 23:00 | 大脑维护 | DeepSeek V3.2 | |

### 限流安全线（用量不超过额度的 60%）
- Groq: 每日最多用 8000 请求（额度 14400）
- SiliconFlow 免费: 不限日量，但并发控制在 3
- Gemini CLI: 每日最多用 800 请求（额度 1500）
- Gemini Flash: 仅心跳，每日 ~26 次

- 每周日 20:00 生成《厂长管理周刊》推送 Telegram

## Kitt 自我进化计划

### 原则
- 我自己收集信息、自己消化、自己更新记忆
- 不依赖厂长转述，主动出击
- 每次学习后对比已有知识，只存增量

### 自动进化流程
1. 每日 11:00 — 技术前沿学习（OpenClaw/Agent/AI工具）
2. 每日 15:00 — 管理知识学习（为厂长服务）
3. 每周日 — 记忆整理 + 过期归档 + 进化日志
4. 学完自动更新 memory/学习日志.md 的 "Next field"

### 进化追踪
- memory/学习日志.md 记录每次学习主题和产出
- memory/03_语义记忆/Kitt进化路线图.md 追踪长期目标
- 每周自动生成进化报告
