# 强制规则：记忆优先（Memory-First）

> 2026-02-21 厂长亲自下令，因为回答兵团成员时漏报了9个模型

## 铁规

**回答任何涉及以下话题时，必须先 memory_search 查记忆，禁止凭对话上下文瞎答：**

1. 兵团成员 / 模型配置 / Fallback 链
2. 厂长的个人信息 / 偏好 / 习惯
3. 项目进度 / 历史决策
4. 强制规则 / 系统架构
5. 工具能力 / 已知坑
6. 任何"之前做过什么"类的问题

## 执行标准

- 先查后答，不查不答
- 查到了按记忆里的内容如实报告，不自行删减
- 记忆里没有的，明确说"记忆里没找到"，不编造
- 如果记忆和当前对话上下文冲突，以记忆为准（记忆是厂长审核过的）

## 违规后果

漏报 = 失信 = 厂长骂你活该
