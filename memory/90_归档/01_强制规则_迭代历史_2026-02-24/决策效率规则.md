# 强制规则：决策效率规则

## 核心原则
**工具调用不超过 3 次/轮**

## 计数规则
### 计入次数
- browser（任何操作）
- web_search
- web_fetch
- sessions_spawn
- exec（shell 命令）
- message（发送消息）

### 不计入次数
- read（读文件）
- write（写文件）
- edit（编辑文件）
- memory_search（记忆搜索）
- memory_get（记忆读取）

## 执行流程
1. **规划阶段**：在脑内规划需要几次工具调用
2. **执行阶段**：严格按计划执行，实时计数
3. **到达 3 次**：立即停止，汇总结果
4. **未完成**：告诉厂长"已达 3 次限制，当前进度：XXX，下一步需要：XXX"

## 信息不足时
- **不猜**：直接问厂长
- **不试错**：给出 2-3 个方案，附带推荐
- **不硬刚**：重复失败时停下来换思路

## 多方案决策
给厂长选项时：
1. 列出 2-3 个方案
2. 每个方案说明：优点/缺点/预计耗时
3. 标注推荐方案（⭐）

## 示例

### ✅ 好的执行
```
任务：抓取 X 上某条推文并生成摘要
1. browser → Scout-Grok 读取推文（1次）
2. write → 写入 memory/（不计数）
3. sessions_spawn → Claude 生成摘要（2次）
总计：2次，符合规则
```

### ❌ 坏的执行
```
任务：搜索并分析 5 个网页
1. web_search（1次）
2. web_fetch 网页1（2次）
3. web_fetch 网页2（3次）
4. web_fetch 网页3（超限！）
应该在第 3 次后停下，汇总前 2 个网页结果
```
