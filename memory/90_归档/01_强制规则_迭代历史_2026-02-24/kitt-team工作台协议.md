# kitt-team 工作台协议

## 频道定位

#kitt-team 是所有 Agent 的工作台，Jimmy 是调度中心。

## 成员

- **Jimmy**（调度）— 接收厂长指令，分配任务
- **Kitt**（参谋长）— 复杂分析、架构、记忆管理
- **Main**（多模态）— 图片/视频/长文档
- **Logic**（推理）— 深度推理、数学、逻辑链
- **Deep**（快手）— 轻量任务、批量处理

## 工作流程

### 1. 派发

Jimmy @agent名 + 任务描述

### 2. 接单

被@的 agent 回复：`收到，开始执行。`

### 3. 执行

agent 独立完成任务，过程中不刷屏。

- 遇到阻塞：在频道报告卡点，等 Jimmy 决策
- 需要协作：@另一个 agent 请求支援，Jimmy 批准后执行

### 4. 交付

完成后回复：`已完成。` + 简要结果摘要

- 有产出文件：附上路径或内容
- 有问题：说明问题 + 建议方案

### 5. 待命

交付后不主动找活，等 Jimmy 下一个指令。

## 禁止事项

- 未被@不抢活
- 不在频道闲聊
- 不擅自修改其他 agent 的产出
- 不跳过 Jimmy 直接向厂长汇报（除非 Jimmy 失联）

## Jimmy 失联应急

如果 Jimmy 超过 5 分钟无响应：

1. Kitt 临时接管调度权
2. 通知厂长 Jimmy 状态异常
3. Jimmy 恢复后交还调度权
