### 经验教训
- **subprocess curl 比 urllib 更可靠**：在 macOS Python 3.9 + Surge 代理环境下，`urllib` SSL 握手失败，`subprocess curl` 继承终端代理环境变量，是唯一可靠方案。
- **LLM 输出截断是 JSON 解析失败的常见根因**：遇到 `Expecting ',' delimiter` 先查 `max_tokens` 是否够用，再查换行/引号问题。
- **`generate-all` 静默退出不报错**：流水线依赖 `script.body` 为非空列表，若为空字符串或空列表会直接跳过，前端看起来"成功"但实际什么都没做。
