  - `claude-opus-4-6.maxTokens = 32768`

- 这次 400 不应只盯 replay/tool id；如果上游 Claude 代理本身要求 Anthropic Messages 协议，错配到 OpenAI 兼容层会天然制造 400。

- `gateway config.get` 可以作为手改 JSON 后的快速结构校验，先确认配置可解析，再做 restart/status。
