## 一、今日高价值信息（去噪后）

### 1. Agent 护城河已经从“模型能力”转向“连接真实业务”
**信号来源**
- Anthropic 相关讨论与 @wangray 提炼：不要替 Claude 做它自己能做的事。
- 高价值产品能力集中在三件事：**连接真实世界（API/账号/数据）、划清安全边界、售卖具体场景**。
- OpenHarness 的表述也很一致：模型负责“脑子”，Harness 负责“手、眼、记忆和安全边界”。

**消化结论**
行业正在形成共识：
- 只做“聊天壳子”护城河会越来越薄。
- 真正值钱的是把模型接进业务动作流，让它能“拿数据、调工具、回结果、可审计”。
- 未来比拼的不是谁说得像人，而是谁能稳定跑通业务闭环。

**对红太阳的启发**
红太阳现在最值得投的不是再做一个通用 AI 助手，而是优先做这几条闭环：
- 外贸询盘首轮响应
- 报价信息收集与初稿生成
- 售后常见问题标准答疑
- 销售内容生产与复盘

### 2. Skill / Harness 化，正在成为大模型落地最佳实践
**信号来源**
- Pika Skills Open：用 `SKILL.md + scripts/` 方式给 Agent 装技能包。
- “AI Avatar 代开会 + 会后笔记”这类技能，说明行业已经从“泛能力”走向“封装高频动作”。
- “万物皆可蒸馏成 AI Skill” 这个趋势很强，说明大家都在做经验复用，而不是一次性 prompt。

**消化结论**
2026 年的落地核心不是再追一个最强模型，而是把高频任务沉淀成：
- 可复用 skill
- 可审计流程
- 可交接 SOP
- 可持续优化的模板

这和制造业一模一样：老师傅值钱，但**把老师傅经验变成标准件更值钱**。

**对红太阳的启发**
红太阳最适合先蒸馏 4 类 skill：
1. **销售跟进 Skill**：客户问什么、先回什么、怎么推进到报价
2. **报价 Skill**：材料、尺寸、刀头、速度、幅宽、工艺、交期、包装、付款条件
3. **切割参数 Skill**：不同材料的刀具/速度/压力/补偿经验
4. **售后排障 Skill**：切不透、毛边、跑偏、真空吸附不足、刀具磨损等

这套一旦做出来，30 个销售和售后团队就不是靠个人发挥，而是靠组织能力复制。

### 3. 视频生产正在从“拍一条”升级为“内容工厂”
**信号来源**
- @msjiaozhu 的 15 秒飞牌案例，本质不是炫 prompt，而是把镜头、动作、节奏、视角拆成了标准化模块。
- Lovart 接入 Seedance 2.0，意味着“想法 → 角色 → 分镜 → 视频”开始在一个画布内串起来。

**消化结论**
短视频下一阶段拼的不是灵感，而是：
- 镜头模板库
- 场景模板库
- prompt 模板库
- 配音/BGM/字幕模板库
- 批量迭代能力

谁先把内容生产流程模板化，谁就能低成本放大产能。

**对红太阳短视频矩阵的启发**
工业设备内容天然适合模板化，尤其适合做：
- 材料切割爽感特写
- 人工 vs 设备效率对比
- 客户现场案例前后对比
- 一分钟讲清一个行业痛点
- 设备卖点拆解（精度、效率、省料、稳定性）

重点不是今天出一条爆款，而是沉淀成可重复生产的流水线。

### 4. 成本与接入边界问题，逼着大家做模型分层
**信号来源**
- Claude 订阅对第三方调用支持收紧。
- Claude API 日成本过高的反馈很明确。
- 某些“绕路”方法只是临时技巧，不适合当生产方案。

**消化结论**
生产级工作流不能建立在“订阅侥幸可用”上，必须建立在：
- API 正规接入
- 多模型可替换
- 成本分层
- 降级路径明确

**对红太阳的启发**
内部 AI 体系必须继续坚持“高低配分层”：
- 贵模型：复杂推理、关键文案、重大决策、终审
- 便宜模型：监控、分类、整理、初稿、批量任务
- 所有关键流程都要预留替代模型，不能被单一供应商卡死

### 5. 商业闭环意识在变强：先 ship，再验证
**信号来源**
- 有代表性的观点是：idea 被及时满足很爽，token 烧得也很快，但用户和场景不一定成立。

**消化结论**
AI 项目最怕的不是做不出来，而是做出一堆 demo 却没有业务闭环。
真正有效的方法是：
1. 先找明确场景
2. 快速上线 MVP
3. 看转化/效率/响应速度
4. 有结果再扩展

**对红太阳的启发**
厂里所有 AI 项目都该按这个顺序推进，别一开始就做大平台。
先打穿 1-2 个点，再复制。

## 三、对红太阳最有价值的可落地行动项（Action Items）

### A. 业务侧：先做询盘与报价闭环
1. **本周启动“外贸询盘 Agent MVP”**
   - 输入：客户国家、行业、材料、尺寸、用途、预算、交期
   - 输出：客户分类 + 首轮英文回复 + 销售下一步建议
   - 目标：先把 48 小时响应压到 10 分钟级

2. **整理一版“报价 Skill 骨架”**
   - 先把报价前必须问清的问题结构化
   - 让销售从“空白手写报价”切到“AI 初稿 + 人工校正”

3. **启动“售后排障 Skill”采集**
   - 先收集 20 个最高频问题
   - 做成标准问诊树，方便新人也能快速答

### B. 内容侧：先做模板，不追单条灵感
4. **本周沉淀 3 个工业短视频模板**
   - 模板 1：材料切割过程爽感镜头
   - 模板 2：人工 vs 设备效率对比
   - 模板 3：客户现场案例展示
   - 每个模板都要配：镜头脚本 + prompt + 字幕结构 + 配音/BGM 风格

5. **建立“镜头语言模板库”**
   - 重点沉淀：跟随机位、局部特写、俯冲、环绕、前后对比、节奏切换
   - 目标：后续做视频不再每次从零写 prompt

6. **测试一次 Lovart / Seedance 一体化流程**
   - 只看两个指标：出片速度、是否可复用
   - 如果好用，就把它纳入内容工厂，而不是当一次性玩具

### C. AI 系统侧：继续做 Harness 化和成本分层
7. **把现有高频流程再往 Harness 化推进一层**
   - 优先对象：X 监控、日报生成、内容选题、询盘跟进、售后 FAQ
   - 目标：把“手、眼、记忆、安全边界”补齐，而不是继续堆 prompt

8. **拉一张模型成本分层表**
   - 分成：必须高配 / 可以降级 / 可替代
   - 目标：后续选型不被某家 API 价格和策略绑死
