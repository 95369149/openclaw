# T-131 外贸询盘秒回方案

时间戳：2026-04-10 10:12 GMT+8

## 红太阳数控设备「外贸 AI 询盘秒回闭环」落地方案

**1. 系统架构概述**
官网/表单/WhatsApp/邮箱/阿里国际站线索 → OpenClaw 统一接入 → AI 识别客户国家、行业、材料、厚度、幅面、应用场景、采购阶段与紧急度 → 调用 Coze 知识库+报价规则引擎生成 30 秒内英文首回 → 同步推送到 Telegram/Discord/微信销售群并自动分配销售 → 人工在 10 分钟内二次跟进，补充方案、视频、报价单、交期；全过程沉淀到客户档案，后续自动催跟进。

**2. 第一阶段落地清单（2 周 MVP）**
- 梳理 50 条高频询盘，整理成标准字段：产品、材料、厚度、幅面、用途、国家、预算。
- 搭建英文知识库：振动刀卖点、材料适配、典型行业（car mat/seat cover/leather/foam/composite/carton）。
- 官网询盘表单加 4 个必填项：material / thickness / cutting size / application。
- OpenClaw 接表单、邮箱、WhatsApp 线索；Coze 负责首轮问答与模板生成。
- 建 1 个销售响应群：AI 首回 + 客户摘要 + 建议归属销售。
- 建报价区间表与 FAQ，先输出区间价，不直接承诺最终成交价。
- 设 KPI：首响 <1 分钟、人工接管 <10 分钟、7 天内转化率提升。

**3. 英文方案页模板**
Subject: Solution for Your [Material] Cutting Project
Hi [Name], thanks for your inquiry. Based on your application in [Scenario], we recommend our [Machine Model] oscillating knife cutting solution. It is suitable for [Material], thickness [X mm], working size [W×L], and supports high-precision cutting without burning edge, especially for leather, foam, composites and car interior materials. Estimated price range is [USD X–Y] depending on tool configuration, table size and feeding option. If you send material type, thickness, and sample size, we can return a suitable model + video + quotation quickly.

**4. 报价规则引擎设计**
先按三层规则算区间：
- 材料层：皮革/布料/纸板=基础价；泡棉/EVA/复材=基础价+10%~25%；汽车脚垫多层复合=+20%~35%。
- 厚度层：0-5mm 不加价；5-15mm +8%~15%；15-30mm +15%~30%。
- 幅面层：小幅面（<1600×2500）基础价；中幅面 +10%~20%；自动送料线 +25%~40%。
再叠加刀头数量、CCD 定位、投影、自动上料等选配，最终输出“标准版/增强版/产线版”三区间报价。

**5. 技术选型建议**
第一阶段不建议新上重系统，直接用「OpenClaw + Coze + 现有沟通渠道」最快。OpenClaw 负责多入口接入、消息分发、销售提醒、日志留存；Coze 负责知识库问答与英文首回生成。若后续线索量变大，再补 CRM/自动化工具（如 n8n/HubSpot）做客户分层、自动催单和 BI 看板。当前关键不是工具多，而是先把“字段标准化 + 模板化首回 + 报价规则化”跑通。
