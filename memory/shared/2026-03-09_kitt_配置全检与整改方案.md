- **现象**：厂长在 3月1日 明确要求加入 `https://api.lingyaai.cn` (sk-Nd2Y...)，但当前 `openclaw.json` 中**完全没有** `lingyaai`。

- **jimmy/deep 实际模型**：`mygptapi/gpt-5.4`

- **kitt 实际模型**：`mynewapi/claude-opus-4-6`
- **文档规定**：`mynewapi/claude-sonnet-4-6`

- **问题**：如果厂长需要 Agent 主动发消息或做后台巡检，现在的配置会导致 Agent 永远不主动说话。
