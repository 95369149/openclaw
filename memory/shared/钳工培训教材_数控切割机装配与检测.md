## 适用对象

红太阳数控设备有限公司 · 生产部钳工

## 适用设备

振动刀切割机、气动刀切割机、多层裁床等柔性材料智能切割设备

---

## 第一章：工作台平面度检测

### 1.1 检测目的

工作台是切割设备的基准面，平面度直接影响：

- 材料吸附效果（真空吸附台）
- 切割深度一致性
- 成品质量

### 1.2 检测标准

**平面度要求：≤0.6mm**

### 1.3 检测工具

- 百分表（量程 0-10mm，精度 0.01mm）
- 磁力座（用于固定百分表）

### 1.4 检测步骤

1. 将磁力座吸附在龙门架或横梁上，固定百分表
2. 百分表测头垂直接触工作台表面
3. 将百分表归零
4. 沿工作台长度方向移动龙门架，每隔 500mm 记录一次读数
5. 沿宽度方向重复测量
6. 取所有测量点的最大差值，即为平面度误差

### 1.5 判定标准

- 最大差值 ≤0.6mm → ✅ 合格
- 最大差值 >0.6mm → ❌ 需调整

### 1.6 常见问题与处理

| 问题     | 可能原因           | 处理方法     |
| -------- | ------------------ | ------------ |
| 局部凸起 | 工作台下方支撑不均 | 调整支撑螺栓 |
| 整体倾斜 | 地面不平或机架变形 | 调整地脚螺栓 |
| 中间凹陷 | 工作台自重下垂     | 增加中间支撑 |

### 1.7 注意事项

- 测量前清洁工作台表面，去除碎屑和灰尘
- 百分表测头不可碰到吸附孔边缘
- 测量时龙门架移动速度要均匀
- 记录数据时标注测量点位置

## 第二章：导轨直线度检测

### 2.1 检测目的

直线导轨是切割头运动的基准，直线度直接影响：

- 切割轨迹精度
- 重复定位精度
- 运动平稳性
- 导轨和滑块寿命

### 2.2 检测标准

**直线度要求：≤0.1mm**
（注意：比工作台平面度要求高 6 倍）

### 2.3 检测工具

- 百分表（量程 0-10mm，精度 0.01mm）
- 磁力座 + 万向调节臂
- 记录表格

### 2.4 检测步骤

1. 将百分表通过万向臂固定在滑块上
2. 百分表测头接触导轨侧面（检测直线度）或上表面（检测水平度）
3. 归零
4. 沿导轨全长缓慢移动滑块
5. 每隔 500mm 记录一次读数
6. 取最大差值

### 2.5 判定标准

- 最大差值 ≤0.1mm → ✅ 合格
- 最大差值 >0.1mm → ❌ 需重新调整导轨安装

### 2.6 精度对比

| 检测对象     | 精度要求 | 测量难度 | 影响范围             |
| ------------ | -------- | -------- | -------------------- |
| 工作台平面度 | ≤0.6mm   | 低       | 材料吸附效果         |
| 导轨直线度   | ≤0.1mm   | 中       | 切割精度、运动平稳性 |

### 2.7 注意事项

- 万向臂必须锁紧，防止测量过程中松动
- 导轨表面需清洁，不可有油污或碎屑
- 测量时注意区分导轨本身误差和安装误差
- 两根平行导轨需分别测量

## 第三章：减速机与限位传感器安装

### 3.1 部件说明

#### 行星减速机

- 功能：降低电机转速、增大扭矩
- 输出轴连接齿轮，与齿条啮合驱动运动轴
- 安装在运动模组底板上

#### 限位传感器（接近开关）

- 功能：检测运动部件是否到达行程终点
- 起保护作用，防止撞机
- 安装在减速机底板上

### 3.2 安装步骤

#### 减速机安装

1. 将减速机放置在安装底板上，对准安装孔
2. 穿入螺栓，先手拧到位
3. 按对角线顺序逐步拧紧（防止受力不均）
4. 使用扭力扳手按规定力矩拧紧
5. 螺栓头部做防松标记（红色油漆划线）

#### 限位传感器安装

1. 将传感器安装在底板预留位置
2. 调整传感器位置，确保触发距离合适
3. 固定螺栓并做防松标记
4. 接线并测试触发是否正常

### 3.3 质量控制要点

- **螺栓防松标记**：所有紧固螺栓拧紧后必须做红色油漆标记
- **对中检查**：减速机输出轴必须与齿轮同轴
- **限位测试**：安装后必须手动测试限位是否正常触发

### 3.4 注意事项

- 安装前检查减速机型号是否正确
- 螺栓规格和力矩必须按图纸要求
- 限位传感器接线注意正负极
- 安装完成后做空载运行测试

## 第四章：齿轮齿条啮合调试

### 4.1 部件说明

- **斜齿轮**：安装在减速机输出轴上，比直齿轮传动更平稳、噪音更低
- **齿条**：固定在横梁/纵梁侧面，与齿轮啮合实现直线运动

### 4.2 啮合间隙的重要性

| 间隙状态 | 表现                     | 后果                                 |
| -------- | ------------------------ | ------------------------------------ |
| 间隙过大 | 齿轮与齿条之间有明显晃动 | 传动精度差、反向间隙大、切割出现波纹 |
| 间隙合适 | 齿轮转动顺畅，无明显晃动 | 传动精确、运动平稳                   |
| 间隙过小 | 齿轮转动发紧、有异响     | 运动卡滞、齿面磨损加剧、电机负载大   |

### 4.3 调试步骤

1. 将齿轮安装到减速机输出轴上
2. 调整减速机位置，使齿轮与齿条正确啮合
3. 手动转动齿轮，感受啮合松紧度
4. 沿齿条全长移动，检查各段啮合是否均匀
5. 在齿条侧面多点标记测量值（手写记录）
6. 调整至全长啮合均匀后，锁紧减速机固定螺栓
7. 做防松标记

### 4.4 检测方法

- **手感法**：手动转动齿轮，感受松紧
- **塞尺法**：用塞尺测量齿侧间隙
- **百分表法**：固定齿轮，用百分表测量齿条方向的间隙量
- **着色法**：在齿面涂色，观察啮合接触面积

### 4.5 质量标准

- 啮合间隙沿齿条全长应均匀
- 齿面接触面积 ≥60%
- 运动时无异响、无卡滞
- 反向间隙在允许范围内

### 4.6 注意事项

- 斜齿轮有方向性，安装时注意螺旋方向
- 齿条接头处的间隙需特别注意
- 调试完成后必须做空载运行测试
- 记录各测量点数据，存档备查
