- **@wangray** (⭐3.0): Managed Agents 的设计哲学是把 agent 拆成三个可独立替换的组件：

1. Brain（脑）— Claude + harness（调用循环）
2. Hands（手）— sandbox（执行环境，跑代码、改文件）
3. Session（记忆）— append-only事件日志

关键设计决策：

脑手分离：harness 不再住在容器里，而是像调用任何工具一样调用容器（execute(name, input) → string），容器挂了就换一个，不用抢救。

Pets vs Cattle 问题：一开始所有组件塞在一个容器里，容器挂了 session 就丢了，变成了"宠物"——不能死。拆分后所有组件都变成"牲口"——挂了就换，session日志在外面，什么都不会丢。

Harness 会过时：Sonnet 4.5有"context anxiety"（快到上下文限制就草草收尾），harness加了context reset来修。但到Opus 4.5这个问题消失了，reset变成了死代码。所以 harness 必须能随模型进化而替换。
