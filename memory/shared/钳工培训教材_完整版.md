# 数控切割机装配与检测 — 钳工培训教材（完整版）

## 适用对象

红太阳数控设备有限公司 · 生产部钳工

## 适用设备

振动刀切割机、气动刀切割机、多层裁床等柔性材料智能切割设备

---

## 第一章：工作台平面度检测

### 1.1 检测目的

工作台是切割设备的基准面，平面度直接影响：

- 材料吸附效果（真空吸附台）
- 切割深度一致性
- 成品质量

### 1.2 检测标准

**平面度要求：≤0.6mm**

### 1.3 检测工具

- 百分表（量程 0-10mm，精度 0.01mm）
- 磁力座（用于固定百分表）

### 1.4 检测步骤

1. 将磁力座吸附在龙门架或横梁上，固定百分表
2. 百分表测头垂直接触工作台表面
3. 将百分表归零
4. 沿工作台长度方向移动龙门架，每隔 500mm 记录一次读数
5. 沿宽度方向重复测量
6. 取所有测量点的最大差值，即为平面度误差

### 1.5 判定标准

- 最大差值 ≤0.6mm → ✅ 合格
- 最大差值 >0.6mm → ❌ 需调整

### 1.6 常见问题与处理

| 问题     | 可能原因           | 处理方法     |
| -------- | ------------------ | ------------ |
| 局部凸起 | 工作台下方支撑不均 | 调整支撑螺栓 |
| 整体倾斜 | 地面不平或机架变形 | 调整地脚螺栓 |
| 中间凹陷 | 工作台自重下垂     | 增加中间支撑 |

### 1.7 注意事项

- 测量前清洁工作台表面，去除碎屑和灰尘
- 百分表测头不可碰到吸附孔边缘
- 测量时龙门架移动速度要均匀
- 记录数据时标注测量点位置

## 第二章：导轨直线度检测

### 2.1 检测目的

直线导轨是切割头运动的基准，直线度直接影响：

- 切割轨迹精度
- 重复定位精度
- 运动平稳性
- 导轨和滑块寿命

### 2.2 检测标准

**直线度要求：≤0.1mm**

### 2.3 检测工具

- 百分表（量程 0-10mm，精度 0.01mm）
- 磁力座 + 万向调节臂
- 记录表格

### 2.4 检测步骤

1. 将百分表通过万向臂固定在滑块上
2. 百分表测头接触导轨侧面（检测直线度）或上表面（检测水平度）
3. 归零
4. 沿导轨全长缓慢移动滑块
5. 每隔 500mm 记录一次读数
6. 取最大差值

### 2.5 判定标准

- 最大差值 ≤0.1mm → ✅ 合格
- 最大差值 >0.1mm → ❌ 需重新调整导轨安装

### 2.6 精度对比

| 检测对象     | 精度要求 | 测量难度 | 影响范围             |
| ------------ | -------- | -------- | -------------------- |
| 工作台平面度 | ≤0.6mm   | 低       | 材料吸附效果         |
| 导轨直线度   | ≤0.1mm   | 中       | 切割精度、运动平稳性 |

### 2.7 注意事项

- 万向臂必须锁紧，防止测量过程中松动
- 导轨表面需清洁，不可有油污或碎屑
- 测量时注意区分导轨本身误差和安装误差
- 两根平行导轨需分别测量

## 第三章：减速机与限位传感器安装

### 3.1 部件说明

#### 行星减速机

- 功能：降低电机转速、增大扭矩
- 输出轴连接齿轮，与齿条啮合驱动运动轴
- 安装在运动模组底板上

#### 限位传感器（接近开关）

- 功能：检测运动部件是否到达行程终点
- 起保护作用，防止撞机
- 安装在减速机底板上

### 3.2 安装步骤

#### 减速机安装

1. 将减速机放置在安装底板上，对准安装孔
2. 穿入螺栓，先手拧到位
3. 按对角线顺序逐步拧紧（防止受力不均）
4. 使用扭力扳手按规定力矩拧紧
5. 螺栓头部做防松标记（红色油漆划线）

#### 限位传感器安装

1. 将传感器安装在底板预留位置
2. 调整传感器位置，确保触发距离合适
3. 固定螺栓并做防松标记
4. 接线并测试触发是否正常

### 3.3 质量控制要点

- **螺栓防松标记**：所有紧固螺栓拧紧后必须做红色油漆标记
- **对中检查**：减速机输出轴必须与齿轮同轴
- **限位测试**：安装后必须手动测试限位是否正常触发

### 3.4 注意事项

- 安装前检查减速机型号是否正确
- 螺栓规格和力矩必须按图纸要求
- 限位传感器接线注意正负极
- 安装完成后做空载运行测试

## 第四章：齿轮齿条啮合调试

### 4.1 部件说明

- **斜齿轮**：安装在减速机输出轴上，比直齿轮传动更平稳、噪音更低
- **齿条**：固定在横梁/纵梁侧面，与齿轮啮合实现直线运动

### 4.2 啮合间隙的重要性

| 间隙状态 | 表现                     | 后果                                 |
| -------- | ------------------------ | ------------------------------------ |
| 间隙过大 | 齿轮与齿条之间有明显晃动 | 传动精度差、反向间隙大、切割出现波纹 |
| 间隙合适 | 齿轮转动顺畅，无明显晃动 | 传动精确、运动平稳                   |
| 间隙过小 | 齿轮转动发紧、有异响     | 运动卡滞、齿面磨损加剧、电机负载大   |

### 4.3 调试步骤

1. 将齿轮安装到减速机输出轴上
2. 调整减速机位置，使齿轮与齿条正确啮合
3. 手动转动齿轮，感受啮合松紧度
4. 沿齿条全长移动，检查各段啮合是否均匀
5. 在齿条侧面多点标记测量值（手写记录）
6. 调整至全长啮合均匀后，锁紧减速机固定螺栓
7. 做防松标记

### 4.4 检测方法

- **手感法**：手动转动齿轮，感受松紧
- **塞尺法**：用塞尺测量齿侧间隙
- **百分表法**：固定齿轮，用百分表测量齿条方向的间隙量
- **着色法**：在齿面涂色，观察啮合接触面积

### 4.5 质量标准

- 啮合间隙沿齿条全长应均匀
- 齿面接触面积 ≥60%
- 运动时无异响、无卡滞
- 反向间隙在允许范围内

### 4.6 注意事项

- 斜齿轮有方向性，安装时注意螺旋方向
- 齿条接头处的间隙需特别注意
- 调试完成后必须做空载运行测试
- 记录各测量点数据，存档备查

## 第五章：装配流程与质量控制

### 5.1 目的

本章用于统一钳工装配动作、质量标准、检查节点和责任意识，防止出现漏装、松动、干涉、漏气、急停失效、行程不足、清洁不达标等问题，确保设备一次装配合格、一次调试通过、一次交付成功。

### 5.2 岗位要求

依据《钳工岗位职责》和《红太阳钳工岗位可视化作业指导书》，钳工必须做到：

- 看懂装配图、结构图、领料单和工艺文件
- 按订单配置领料并签字确认，尤其注意**电机型号、导轨品牌、齿条规格、气缸型号**
- 对装配质量负责，对关键尺寸、关键紧固点、关键功能点负责
- 执行 6S：现场整洁、工具归位、作业区无杂物、设备内部无铁屑铁锈
- 配合调试和验收，形成记录闭环

### 5.3 装配总原则

1. **先核对，后安装**：未经核对的物料不得上机。
2. **先清理，后定位**：安装面必须干净，无铁屑、油污、毛刺、铁锈。
3. **先粗装，后精调，最后锁紧**：防止返工和精度漂移。
4. **所有关键螺栓必须锁紧到位并做防松确认**。
5. **所有精度标准必须量化，不允许“凭感觉差不多”**。
6. **钣金件、板筋类部件不允许直接落地**，必须放在支架、木方、周转车或垫板上。
7. **装配完成不等于交付完成**，还必须完成功能检查、清洁检查、留痕检查。

### 5.4 完整装配流程（7步）

#### 第一步：接单核对

**作业内容：**

- 根据生产订单、领料单、配置清单逐项核对物料
- 重点核对：架子、导轨、齿条、齿轮、电机、气缸、分区、拖链、钣金件
- 对特殊配置、出口机、送料机、加装投影、二次覆膜等项目单独标记

**质量控制点：**

- 型号一致
- 数量一致
- 品牌一致
- 左右件、前后件不得混装

**常见风险：**

- 电机型号领错
- 导轨/齿条品牌混用
- 配件漏领、漏发

**预防措施：**

- 执行“领料人 + 发料人”双确认
- 关键件拍照留底
- 小件、拆下钣金、线槽、挂钩、附件统一入盒管理，防止后期找不到

---

#### 第二步：架子安装

**作业内容：**

- 清理架子安装面和连接面
- 按基准方向组装床身、架子、底脚、轮子板等
- 调整对角和整体方正度

**精度要求：**

- **架子对角线误差：2-5mm**

**质量控制点：**

- 安装面清洁
- 连接件齐全
- 架体无明显扭曲
- 底脚、轮子板安装正确

**检查方法：**

- 钢卷尺测两条对角线
- 复测 2 次以上，确认数据稳定

**预防措施：**

- 紧固前先点装定位，再整体复测
- 对角不合格时不得进入下一工序

---

#### 第三步：导轨安装

**作业内容：**

- 清洁导轨安装面
- 安装导轨及相关紧固件
- 调整两根导轨平行关系和直线度

**精度要求：**

- **导轨平行度：≤0.1mm**
- 导轨直线度检测标准参照第二章执行

**质量控制点：**

- 导轨表面无磕碰、无异物
- 螺丝齐全、锁紧到位
- 两侧导轨平行一致

**检查方法：**

- 百分表检测
- 沿全长移动复测
- 关键位置复紧并标记

**常见风险：**

- 导轨安装面未清洁导致精度超差
- 螺丝未锁紧，后期运行松动

**预防措施：**

- 安装前吹净、擦净安装面
- 关键螺丝锁紧后逐颗复检
- 检测记录留档

---

#### 第四步：横梁安装

**作业内容：**

- 吊装或配合安装横梁
- 调整横梁与架子关系
- 校正两边垂直度和运行基准

**精度要求：**

- **横梁两边必须垂直**
- **以架子打孔距离作为安装基准**

**质量控制点：**

- 横梁左右位置一致
- 与导轨、齿条配合顺畅
- 无偏斜、无卡阻

**检查方法：**

- 测量左右孔距基准
- 检查横梁运行是否顺畅
- 复核横梁相关导轨和支撑螺丝锁紧状态

**预防措施：**

- 严禁凭目测判断垂直
- 横梁导轨螺丝必须纳入复检清单

---

#### 第五步：送料架安装

**作业内容：**

- 安装送料架、气缸、相关接头及附件
- 整理气路方向和空间位置

**安装要求：**

- **气缸朝后**
- **气嘴朝后**

**质量控制点：**

- 气缸安装方向正确
- 接头无松动
- 气管布置顺畅，无折弯、无干涉

**检查方法：**

- 通气试验
- 检查接头、阀体、分区是否漏气

**预防措施：**

- 安装完成立即做漏气检查
- 送料相关部件方向错误必须当场返工，不得带入调试

---

#### 第六步：台面安装

**作业内容：**

- 安装分区、台面、支撑件及相关附件
- 调整整体平面度

**安装要求：**

- **先装分区**
- **2米以上设备必须安装手动分区**

**精度要求：**

- **台面平整度：≤0.6mm**

**质量控制点：**

- 分区安装位置正确
- 阀体、气路、气表齐全
- 台面平整，无翘曲、无高低差

**检查方法：**

- 百分表检测平整度
- 分区逐区通气测试
- 检查有无漏气、缺件、装反

**预防措施：**

- 分区装完先试气，再封装
- 台面合格前不得进入板筋和钣金总装

---

#### 第七步：板筋安装

**作业内容：**

- 安装板筋、钣金件、门板、附件、保护件
- 完成外观恢复和整机清洁

**强制要求：**

- **钣金件不允许直接落地**
- **螺丝必须紧固到位，不能打滑**
- **设备内部和表面必须干净整洁，无铁屑、无铁锈、无杂物**

**质量控制点：**

- 门缝均匀
- 挂钩、合页、门锁紧固可靠
- 钣金平整度达标
- 配电柜、线槽、腔体内清洁合格

**检查方法：**

- 逐件检查门板、侧板、后门、挂钩、螺丝
- 目视+手触检查平整度和毛刺
- 清洁检查后方可交调试

**预防措施：**

- 所有钣金件必须使用垫板、周转车或货架周转
- 紧固完毕逐件复查，不合格立即返工
- 打包前建议留存外观和平整度影像资料

### 5.5 装配过程辅助控制要求

#### 5.5.1 走线与防干涉要求

依据可视化作业指导书，装配过程中应同步关注以下内容：

- 穿线孔无毛刺，并安装防护胶套
- 线路要拉直摆齐，并做好标识
- 拖链每隔三节设一组卡片，每组三个隔离片
- 各转弯处保留最大转弯半径
- 拖链两头扎带捆扎牢固
- 屏蔽完整，不得漏铜丝
- 裸露电线必须加缠绕管或热缩保护
- 升降电机线路**不允许磨线**

#### 5.5.2 上电与复位前检查

- 急停开关短时测试（≤1s）
- 限位信号手动感应测试
- 首次复位优先采用**单驱复位模式**
- 两边单驱复位正常后，方可开启双驱复位
- 复位过程重点观察运行状态，异常立即停止
- 复位速度控制：**50mm/s**

### 5.6 真实质量事故案例分析

#### 案例一：005号订单设备质量问题整改通报

**订单信息：** 005号订单，6代1825型送料出口机  
**通报时间：** 2025年3月22日

**问题描述：**
培训环节共暴露 10 项问题，其中与钳工装配直接相关的主要问题为：

- 四角急停装置失效
- 刀座升降联轴器未紧固
- 钣金组件平整度不达标（两侧/前后门）
- 冲子安装松动
- 变频器安装遮挡主板，配电箱布局冲突
  此外还存在操作面板防护不到位、配件漏发、打包前未留平整度视频等问题。

**责任人：**

- 耿浩飞（调试员）：通报批评，扣除本台绩效
- 马杰（打包）：绩效减半
- 杨静、孙惠玲（仓管/计划）：扣除本单全部绩效
- 刘奥林、胡燕霞（管理人员）：连带责任，绩效减半
- 户志刚（钳工）：绩效减 50%

**处理结果：**
公司要求优化调试检查清单，新增配件完整性核验节点；刀座安装增加扭矩检测；四角急停增加测试要求；电气布局强制预留散热空间；打包前必须留存平整度视频证据。

**根本原因：**

1. 装配与调试未按标准逐项核验，存在“装完就算完”的思想
2. 联轴器、急停、冲子等关键点没有纳入必检、必签项目
3. 钣金装配缺少量化验收标准与影像留证
4. 配电箱布局审查不到位，存在空间干涉和散热隐患
5. 岗位之间责任边界不清，导致漏项无人兜底

**预防措施：**

- 联轴器、急停、冲子、门板挂钩列入装配后复检清单
- 关键螺栓执行“紧固 + 标记 + 复核”三步法
- 钣金安装完成后，必须检查平整度、门缝、开关顺畅度
- 配电柜和机械装配交接前，检查是否存在遮挡、干涉、散热不足
- 发货前必须拍摄钣金平整度和整机外观视频，形成证据链

#### 案例三：2023.11.18 质量事故通报

**订单信息：**

- 221号订单，6代2125送料
- 198号订单，6代1830送料  
  **通报时间：** 2023年11月18日

**问题描述：**

- 221号订单：横梁导轨螺丝未锁紧
- 198号订单：拖链支撑未安装、分区阀漏气、消音箱气表未安装

**责任人：**

- 户晓健（钳工）：考核 100 元，并通报批评
- 王文昌、户强、户鹏杰：各考核 50 元
- 王萌（调试人员）：连带责任考核 50 元
- 步国军（主管）：连带责任考核 100 元

**处理结果：**
公司进行了通报批评和经济考核，要求加强生产过程监管和培训，防止同类问题再次发生。

**根本原因：**

1. 横梁导轨关键螺丝未执行最终锁紧确认
2. 拖链支撑、气表、分区阀等附件安装缺少清单化管理
3. 气路系统装后未进行完整检漏和缺件检查
4. 调试、主管、钳工之间缺少交接闭环

**预防措施：**

- 横梁、导轨、支撑类螺丝全部纳入“关键锁紧点台账”
- 拖链支撑、气表、分区阀、消音箱等易漏项目设专门勾检项
- 气路安装后必须逐项试气、查漏、查缺件
- 调试前必须做一次整机“漏装、松动、漏气”联检

### 5.7 事故共性问题总结

从以上案例可以看出，装配质量问题主要集中在以下五类：

1. **漏装**：拖链支撑、气表、附件、配件漏装或漏发
2. **未紧固**：联轴器、导轨螺丝、挂钩、冲子等未锁紧
3. **精度不达标**：钣金平整度、门缝、行程、导轨精度超差
4. **功能未验证**：急停、限位、复位、行程、漏气未实测
5. **现场不整洁**：配电柜杂物、铁屑铁锈、包装前无留证

### 5.8 质量预防清单（钳工必检）

#### 5.8.1 装配前必检

- 订单、图纸、领料单一致
- 关键物料型号一致
- 安装面、导轨面、支撑面清洁无毛刺
- 拆下的钣金和线槽已分类放好

#### 5.8.2 装配中必检

- 架子对角线误差：**2-5mm**
- 导轨平行度：**≤0.1mm**
- 台面平整度：**≤0.6mm**
- 横梁两边垂直，以打孔距离为基准
- 送料架气缸朝后、气嘴朝后
- 板筋安装时钣金件**不允许直接落地**
- 螺丝紧固到位，不打滑，有防松确认

#### 5.8.3 装配后必检

- 四角急停有效
- 限位有效
- 联轴器无松动
- 门板、挂钩、门缝正常
- 拖链支撑、分区阀、气表、消音箱等无漏装
- 配电柜、机身内部干净整洁，无杂物、无铁屑、无铁锈
- 点动方向、复位动作、行程范围正常

### 5.9 章节结论

装配质量不是靠经验兜底，而是靠**流程、标准、复检、责任**四件事兜底。钳工在整机质量中处于第一责任环节，必须把“核对、精度、锁紧、清洁、功能验证”做到位。谁忽视细节，谁就把问题送到客户现场；谁把流程做扎实，谁就把质量做成公司的口碑。
