# T-116 外贸线索实时响应系统——第一步落地方案

## 1. 线索抓取操作手册

**推荐工具（免费优先）**：
1. Google/LinkedIn：搜索目标买家，筛选采购/生产/技术负责人
2. Apollo / Hunter / Snov：批量获取联系邮箱
3. Google Maps + 官网 Contact/About：补全 WhatsApp、LinkedIn
4. Excel/表格工具：整理、去重

**搜索关键词（英文）**：
- `automotive interior manufacturer`
- `car seat cover manufacturer`
- `leather goods manufacturer`
- `shoe upper manufacturer`
- `composite material cutting`
- `carbon fiber parts manufacturer`
- `technical textile manufacturer`
- `gasket manufacturer`
- `vibrating knife cutting`
- `CNC knife cutter`

**导出字段**：
Company / Website / Country / Industry / Contact / Title / Email / Phone / WhatsApp / LinkedIn / Source URL

## 2. 客户评分表模板（Excel）

字段清单：公司名、网站、国家、行业、联系人、职位、邮箱、电话、WhatsApp、LinkedIn、是否有采购记录、公司规模、行业匹配度、联系方式完整度、是否有 LinkedIn、是否有切割/皮革/复合材料关键词、是否有进口/采购/技术负责人

**评分规则（100分）**：
- 有采购记录：30分（海关数据/进口记录=30；无=0）
- 公司规模：25分（50人以上=25；10-49=15；10人以下=5）
- 行业匹配度：20分（Owner/采购/技术负责人=20）
- 网站质量：15分（50人以上=15；10-49=4；10以下=3）
- 联系方式完整度：10分（有切割/皮革/复合材料关键词=10）

A类 ≥75分；B类 50-74分；C类 <50分

## 4. 本周行动清单（7天）

- **Day1 准备**：建立3个系列模板+建 Excel 评分表
- **Day2 抓取**：Google/LinkedIn 搜索100条目标买家
- **Day3 抓取**：Apollo/Hunter 补全联系方式，整理到70条有效联系人
- **Day4 清洗**：评分打标，筛出 A类≥15条，B类≥35条
- **Day5 触达**：A类发首封邮件+LinkedIn 连接请求
- **Day6 跟进**：未读 A类发 WhatsApp；查看回复/接管
- **Day7 复盘/准备**：整理本周数据，准备下周扩量

**目标**：本周触达50条，A类首次响应100%，回复率目标10%（5条有效询盘）。
