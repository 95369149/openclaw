
## 第二章：减速机固定件安装

### 2.1 部件说明
#### 行星减速机
- 功能：降低电机转速、增大扭矩
- 输出轴连接齿轮，与齿条啮合驱动运动轴
- 安装在运动模组底板上

#### 限位传感器（接近开关）
- 功能：检测运动部件是否到达行程终点
- 起保护作用，防止撞机
- 安装在减速机底板上

### 2.2 安装步骤

#### 减速机安装
1. 将减速机放置在安装底板上，对准安装孔
2. 穿入螺栓，先手拧到位
3. 按对角线顺序逐步拧紧（防止受力不均）
4. 使用扭力扳手按规定力矩拧紧
5. 螺栓头部做防松标记（红色油漆划线）

#### 限位传感器安装
1. 将传感器安装在底板预留位置
2. 调整传感器位置，确保触发距离合适
3. 固定螺栓并做防松标记
4. 接线并测试触发是否正常

### 2.3 质量控制要点
- **螺栓防松标记**：所有紧固螺栓拧紧后必须做红色油漆标记
- **对中检查**：减速机输出轴必须与齿轮同轴
- **限位测试**：安装后必须手动测试限位是否正常触发

### 2.4 注意事项
- 安装前检查减速机型号是否正确
- 螺栓规格和力矩必须按图纸要求
- 限位传感器接线注意正负极
- 安装完成后做空载运行测试

## 第三章：质量事故案例分析

### 3.1 案例一：005号订单设备质量问题（2025年3月）
**订单信息：** 6代1825型送料出口机

**问题清单：**
1. 四角急停装置失效
2. 刀座升降联轴器未紧固
3. 钣金组件平整度不达标（两侧/前后门）
4. 冲子安装松动
5. 变频器安装遮挡主板（配电箱布局冲突）
6. 二次覆膜设备触发急停后无法复位
7. 操作面板未配置防护盒
8. 钣金组件打包未留存平整度视频证据
9. 关键配件漏发（投影仪遥控器、画笔筒）
10. 线材管理混乱（投影仪线材多发1根）

**根本原因：**
- 调试环节未按《设备调试规程》逐项核验
- 配件清单核对不严
- 功能测试不全
- 质检环节未发现问题

**预防措施：**
1. 装配完成后必须逐项功能测试（急停、联轴器、冲子、门板）
2. 配件清单必须双人核对
3. 配电箱布局必须预留主板操作空间
4. 钣金平整度必须在打包前拍照/录像留底
5. 操作面板必须配置防护盒

**责任人及处理：**
- 调试人员：未按规程核验，记过处理
- 质检人员：未发现问题，警告处理
- 厂长：监管失责，连带责任

### 3.2 案例二：004号订单质量问题（2025年7月）
**订单信息：** 售后培训订单（编号096）

**问题清单：**
1. 后门两挂钩未紧固到位，导致后门缝隙过大（钳工 秦新朝）
2. 配电柜未清理干净，存在杂物（打包员 马杰）
3. 设备行程不够，余地过大（调试人员 马通）

**根本原因：**
- 钳工装配时未复检挂钩紧固状态
- 打包前未清洁检查
- 调试时未核对行程标准

**预防措施：**
1. 门板挂钩必须纳入复检清单
2. 打包前必须清洁检查，不合格不得打包
3. 调试时必须核对行程标准，不合格不得交付

**责任人及处理：**
- 钳工 秦新朝：记质量考核2分
- 打包员 马杰：记质量考核1分
- 调试人员 马通：此订单绩效取消
- 厂长 步国军：连带责任扣1分

**订单信息：** 221号订单6代2125送料、198号订单6代1830送料

**问题清单：**

2. 拖链支撑、气表、分区阀必须纳入装配清单
3. 气路测试必须逐区逐阀测试，不得遗漏

**责任人及处理：**
- 钳工 户晓健：考核100元，通报批评
- 王文昌、户强、户鹏杰：各考核50元

### 3.4 质量控制总结

#### 高频问题 TOP 5
1. **螺丝未锁紧**（横梁导轨、联轴器、挂钩、冲子）
2. **配件漏装**（拖链支撑、气表、遥控器、防护盒）
3. **气路问题**（分区阀漏气、气缸方向错误）
4. **清洁不达标**（配电柜有杂物、内部有铁屑）
5. **功能测试不全**（急停失效、行程不够）

#### 预防措施总结
1. **建立复检清单**：关键螺丝、关键配件、关键功能
2. **执行双人核对**：领料、装配、打包
3. **强化功能测试**：急停、气路、行程、联轴器
4. **清洁检查前置**：打包前必须清洁检查
5. **留痕管理**：关键节点拍照/录像留底

#### 责任意识
- 装配质量是钳工的第一责任
- 不合格不得进入下一工序
- 不合格不得交付
- 质量问题必须追责到人
