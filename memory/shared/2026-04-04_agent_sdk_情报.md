# Agent SDK 情报 · 2026-04-04

## 1. open-agent-sdk

- **GitHub**: https://github.com/shipany-ai/open-agent-sdk
- **npm**: `@codeany/open-agent-sdk`
- **本质**: Claude Code 源码泄露后，有人把核心 agent loop 抽出来做成 SDK
- **亮点**:
  - 支持 OpenAI 兼容接口（可接中转站）
  - MIT 开源，无授权费
  - 支持自定义工具、多轮对话、子 Agent、Hooks
  - 20个生命周期事件
- **建议用途**: 新 Agent 项目的底座，不要从零写
- **对 dyproject**: 现在不动，下次新建项目直接用

## 2. claw-code fork (ultraworkers/claw-code)

- **GitHub**: https://github.com/ultraworkers/claw-code
- **本质**: Claude Code 源码泄露后的 Python 清洁室重写 + Rust 移植
- **状态**: Python 版可用，Rust 版开发中（dev/rust 分支）
- **亮点**:
  - 2小时 50K stars，史上最快
  - Rust 版目标：更快、内存安全
  - 完整 harness 架构（api-client/runtime/tools/commands/plugins）
- **建议**: 关注不接入，等 Rust 版稳定后再评估
- **价值**: 研究 harness engineering 架构的最佳样本
