## 二、场景落地指南

### 1. 批量下载 / 提取视频字幕（极客 & 自动化模式）

- **工具**: `yt-dlp`
- **安装**: `brew install yt-dlp` (Mac)
- **场景**:
  - 下载最高画质: `yt-dlp -f "bestvideo+bestaudio" <URL>`
  - 提取中英文字幕: `yt-dlp --write-subs --sub-langs "en,zh-Hans" <URL>`
  - 下载整个频道/播放列表。

### 2. 随手下推特 (X) 上的好视频

- **工具**: 访问 `https://cobalt.tools`
- **场景**: 看到推文视频，直接复制 URL 扔进去，秒下，干净无广告。

### 3. 搬运 TikTok/抖音 无水印素材

- **工具**: 访问 `https://tiktokio.bio`
- **场景**: 专门用于短视频矩阵号搬运，获取最干净的原视频。

### 4. 提取 YouTube 纯文字（不下载视频）

- **工具**: `https://downsub.com` 或直接用 `bibi` 插件总结。
- **场景**: 只需要看视频说了啥，不用下视频本体。
