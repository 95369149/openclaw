# T-116 红太阳振动刀精准线索渠道（升级版）

## 1）展会渠道（优先抓取）
1. **LINEAPELLE** (https://www.lineapelle-fair.it/) 获取：官网Exhibitors/Visitors注册名录；下载参展商名录，筛选皮革、箱包、皮草加工厂。目标：意大利、西班牙、土耳其、越南。
2. **APLF Leather & Materials+** (https://www.aplf.com/) 获取：Exhibitor List，买家预登记/会刊；重点找皮革、鞋材、包袋OEM。目标：香港、越南、印度、土耳其。
3. **ACLE中国国际皮革展** (https://www.aclechina.com/) 获取：展商名单、参观商手册；筛选海外采购商与驻华工厂。目标：印度、巴基斯坦、孟加拉、东南亚。
4. **Techtextil Frankfurt** (https://techtextil.messefrankfurt.com/) 获取：Exhibitor Search；筛technical textiles、automotive、composites。目标：德国、法国、捷克、美国。
5. **Techtextil North America** (https://techtextil-north-america.us.messefrankfurt.com/) 获取：2025 Exhibitor List；找汽车内饰、工业织物、复合材料加工商。目标：美国、墨西哥、加拿大。
6. **JEC World** (https://www.jec-world.events/) 获取：展商库/App目录；筛composites fabricator、interiors、cutting/converting。目标：法国、德国、美国、土耳其。

## 2）原材料/采购平台
1. **Material Exchange** (https://material-exchange.com/) 买家：鞋服、箱包、家居面料采购商。找法：搜发布面料需求、活跃品牌/工厂，再反查其生产设备。
2. **Texindex** (https://www.texindex.com/) 买家：纺织面料、家居、工业布采购商。找法：按buyer/importer筛，抓有裁切/复合需求企业。
3. **Fibre2Fashion Marketplace** (https://www.fibre2fashion.com/) 买家：服装、家居、技术纺织供应商。找法：搜buyer/company，优先有OEM/加工说明的企业。
4. **Alibaba RFQ** (https://rfq.alibaba.com/) 买家：主动发采购需求企业。找法：搜 leather fabric、composite sheet、car mat、upholstery 等RFQ，反向设定需求。
5. **Global Sources** (https://www.globalsources.com/) 买家：鞋包、汽车用品、家居用品采购商。找法：看买家供应库商目录，优先有cutting、lamination、CNC代工字样。
6. **Made-in-China Sourcing** (https://www.made-in-china.com/) 买家：材料加工厂、贸易商。找法：搜皮革/复合材料买家公司，再查官网判断是否有裁切产线。

## 3）行业协会/目录
1. **Leather Working Group** (https://www.leatherworkinggroup.com/) 方式：公开认证品牌/工厂名单，对口找皮革加工厂。
2. **Textile Exchange** (https://textileexchange.org/find-certified-company/) 方式：完整认证企业数据库，筛面料、家居、复合材料企业。
3. **Advanced Textiles Association** (https://www.textiles.org/) 方式：会员/理事公司页面，对口工业织物、汽车内饰。
4. **ACMA 美国复合材料制造商协会** (https://acmanet.org/) 方式：会员名录/理事名单，找复合材料切割与成型企业。

## 4）直接执行步骤
- **展会**：进官网展商库 → 按材料/应用筛选 → 导出公司名后补官网、邮箱、LinkedIn。
- **平台**：搜buyer/RFQ/认证公司 → 挑有加工场景描述的企业 → 看官网是否有裁切、打样、复合产线。
- **协会**：进会员目录 → 优先制造商会员 → 补联系人后按A/B/C评分。

## 5）优先级
**最快出精准线索：①展会名录 > ②协会目录 > ③采购平台。**
原因：展会参展/采购最接近近期采购动作；协会会员真实度高；平台线索量大但需二次筛选。
