## 内容分类判断规则

**不确定发哪个时，按以下顺序判断：**

1. 含"管理/经营/团队/九大机制/稻盛/德鲁克/华为/丰田"等关键词 → `管理充电`
2. 含"AI/模型/GPT/Claude/Gemini/OpenClaw/工具更新/X推文" → `ai热点`
3. 含"今日总结/运维报告/任务完成/进化提案/周报" → `每日日报`
4. 含"夜读/反思/洞见/睡前/长文摘录" → `晚间智慧`
5. 以上都不符合 → 默认 `每日日报`

## 各频道消息格式模板

### 管理充电

```
🔧 [工具名称] · [日期]

🎯 核心理念：一句话

🏭 红太阳落地：
具体怎么用（结合60人团队、数控设备行业、九大机制）

💬 经典语录：「...」—— 来源
```

### ai热点

```
🤖 AI 热点 · [日期]

## [标题1]
核心内容（2-3句）
🔗 来源

## [标题2]
核心内容（2-3句）
🔗 来源

💡 对红太阳的启示：...
```

### 每日日报

```
📊 每日日报 · [日期] [星期]

## 今日完成
- 任务1
- 任务2

## 阻塞/异常
- 问题1（原因/处理方向）

## 明日重点
1. 优先级最高的事
2. 次优先
```

### 晚间智慧

```
🌙 晚间智慧 · [日期]

[标题]

[正文内容]

💭 思考：...
```

## Discord 注意事项

1. 不用 Markdown 表格（Discord 不渲染）
2. 消息长度超过 1800 字符时拆成多条发
3. 不在 Telegram 重复推送同一内容
4. `silent: true` 可选，避免频繁 @通知
5. guildId: `1472845763007611044`
