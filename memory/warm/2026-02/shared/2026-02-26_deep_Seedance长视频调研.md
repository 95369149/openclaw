## 二、5-10分钟长视频工作流（通用方案）

### 方案A：分段生成 + 剪辑拼接
```
1. 脚本拆分：按场景/镜头切分成 10-20 个片段
2. 批量生成：每段 5-15s，保持风格一致性
3. 剪辑拼接：Premiere/Final Cut/剪映
4. 转场优化：AI 补帧 + 音效同步
```
**成本**: 20片段 × $0.5-2/片段 = $10-40  
**时间**: 2-4小时（含调整）

### 方案B：Runway Extend 链式生成
```
1. 生成首段 10s
2. 用末尾帧作为下一段起点
3. 循环 extend 30-60次
4. 自动拼接成长视频
```
**成本**: 约 $50-100（100+ credits）  
**时间**: 1-2小时（自动化程度高）

## 三、CNC/工业设备视频案例

**现状**: 未找到公开案例  
**原因**:
- 工业场景细节要求高（精度、运动轨迹）
- AI 生成易出现物理错误（刀具穿模、运动不连贯）
- 行业保守，多用实拍 + 3D 动画

**建议路径**:
1. 先用 Blender/C4D 建模 CNC 设备
2. 渲染关键帧序列
3. 用 AI 工具（如 Runway）做风格化/补帧
4. 混合实拍素材增强真实感
