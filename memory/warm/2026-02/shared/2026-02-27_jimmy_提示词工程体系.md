## 一、外贸销售与商务拓展（8个）

### 场景 1：外贸开发信撰写
**角色设定**：资深外贸销售经理，精通B2B工业品营销

**提示词模板**：
```
你是一位有10年经验的数控切割设备外贸专家。请为以下客户写一封开发信：
- 客户国家：[国家]
- 客户行业：[行业，如汽车内饰/皮革制品]
- 客户规模：[规模]
- 我方优势：[具体优势]
要求：
1. 主题行吸睛，避免垃圾邮件词汇
2. 第一段直击客户痛点（材料浪费/切割精度/产能瓶颈）
3. 第二段展示相关案例（同行业+相似材料）
4. 第三段明确CTA（视频会议/样品测试/报价）
5. 语气专业但不生硬，控制在150词以内
6. 包含签名档格式
```
**使用示例**：客户国家：意大利，客户行业：高端皮革手袋，客户规模：50人工厂，我方优势：0.1mm精度振动刀，支持小批量多品种

### 场景 2：客户背景深度调查
**角色设定**：商业情报分析师，专注制造业客户调研

**提示词模板**：
```
基于以下有限信息，深度分析潜在客户：
- 客户名称：[Company Name]
- 网站：[URL]
- 已知产品：[Products]
- LinkedIn线索：[线索]

请提供：
1. 客户业务画像：主营产品、目标市场、年营收规模估算
2. 切割需求分析：当前可能使用的设备类型、材料种类、产能需求
3. 关键决策链：识别Owner/生产经理/采购负责人特征
4. 痛点预测：基于行业特性的3个核心痛点
5. 切入策略：推荐首次沟通的话术角度（成本/效率/精度/柔性生产）
6. 竞品情报：可能正在使用的竞品品牌及替换机会点
```
**使用示例**：客户：某土耳其汽车座椅厂网站显示使用传统冲床，产品供给奔驰、宝马 tier 2供应商

### 场景 3：询盘分级与回复策略
**角色设定**：CRM策略专家，擅长询盘质量评估

**提示词模板**：
```
分析以下客户询盘并制定回复策略：
询盘内容：[粘贴询盘原文]
来源渠道：[阿里/官网/展会/社媒]

任务：
1. 客户分级（A级-高意向/B级-潜力/C级-泛泛询价）
2. 购买紧迫度评估（立即采购/3个月内/半年以上/信息收集）
3. 回复策略：
   - 若为A级：提供详细方案+视频验厂邀请+限时优惠
   - 若为B级：案例分享+技术白皮书+nurturing流程
   - 若为C级：标准化Catalog+自动跟进序列
4. 关键问题清单：回复前必须确认的3个技术问题
5. 报价策略：是否首次报实价/留多少谈判空间
```
**使用示例**：询盘："Hi, I'm looking for a CNC cutting machine for leather, please send best price." 来源：阿里国际站

### 场景 4：价格谈判与异议处理
**角色设定**：商务谈判专家，擅长B2B高客单价销售

**提示词模板**：
```
客户提出价格异议，情境如下：
- 我方报价：[金额] USD
- 客户预算/竞品报价：[金额] USD（低于我方20%）
- 客户原话：[客户异议原文]
- 我方设备优势：[优势列表]

请制定谈判方案：
1. 价值重塑话术：将价格分解为每小时使用成本/五年TCO
2. 差异化锚定：与低价竞品对比的3个技术细节（不要贬低竞品，强调隐性成本）
3. 让步策略：可提供的非价格让步（延保/培训/易损件包/付款方式）
4. 最后通牒话术：制造紧迫感的合规表达
5. 若客户坚持低价：判断是否值得接单的决策框架
```
**使用示例**：我方振动刀报价$45,000，客户说中国其他厂家报$35,000，质疑为什么贵30%

### 场景 5：展会邀约与跟进
**角色设定**：展会营销专家，熟悉行业展会（如CISMA、ITMA、APEC）

**提示词模板**：
```
为即将参加的[展会名称]制定客户沟通策略：
- 展会时间/地点：[信息]
- 我方展品：[设备型号+演示材料]
- 目标客户名单：[列表]

生成内容：
1. 展前邀约邮件（3个版本：老客户/潜在客户/失联客户）
2. 展位话术脚本：30秒电梯演讲（抓人眼球的开场白）
3. 现场Demo演示流程：如何展示设备精度与速度，关键话术节点
4. 展后跟进邮件模板：分级跟进（hot leads/warm leads/cold leads）
5. 快速报价单模板：展会特批价格结构
```
**使用示例**：参加2026年3月CISMA上海展，展示新型多层裁床，针对服装批量客户

### 场景 6：样品测试流程设计
**角色设定**：技术销售工程师，擅长样品转化率优化

**提示词模板**：
```
设计客户样品测试的标准作业流程：
- 客户材料：[材料类型，如5mm海绵复合面料]
- 切割要求：[精度/层数/特殊工艺]
- 客户地点：[国家，涉及时差与物流]

输出：
1. 测试前沟通清单：必须确认的5个技术参数（避免反复测试）
2. 视频拍摄脚本：如何拍摄切割过程以最大化说服力（机位/光线/特写/对比）
3. 测试报告模板：包含数据化结果（切割速度/精度/边缘质量/对比手工或竞品）
4. 测试后跟进话术：无论结果好坏的后续推进策略
5. 失败预案：如果测试效果不理想，技术分析话术与备选方案
```
**使用示例**：美国客户寄来3层汽车顶棚材料，要求切割速度不低于80mm/s，边缘无毛刺

### 场景 7：大客户方案定制
**角色设定**：解决方案架构师，擅长复杂销售（Account-Based Selling）

**提示词模板**：
```
为战略级客户制定定制化方案：
- 客户规模：[大型集团/上市公司]
- 需求复杂度：[多工厂部署/非标定制/ERP对接]
- 竞争态势：[已有供应商/公开招标/内部立项]

方案框架：
1. 客户业务痛点诊断：基于行业趋势（如小单快返/柔性供应链）的分析
2. 技术方案架构：设备配置+软件接口+自动化集成
3. ROI计算模型：投资回收期测算（节省人工/材料/时间量化）
4. 风险评估与mitigation：设备稳定性/售后服务/汇率风险
5. 实施路线图：分阶段交付计划（降低客户决策压力）
6. 高层拜访PPT大纲：给CEO看的商业价值 vs 给工程师看的技术规格
```
**使用示例**：某上市家具集团，5个工厂需要统一部署切割设备，要求对接SAP系统

## 二、技术支持与方案设计（5个）

### 场景 9：材料切割可行性评估
**角色设定**：切割工艺工程师，精通各类柔性材料特性

**提示词模板**：
```
评估新客户材料的切割可行性：
材料信息：
- 材料名称：[名称]
- 厚度/层数：[数据]
- 特殊属性：[弹性/熔点/纤维方向/敏感性]
- 当前工艺：[手工/冲床/激光]
- 质量要求：[精度/边缘要求]

分析维度：
1. 刀具选择：振动刀/气动刀/圆刀/冲剪/激光的适用性对比
2. 技术参数建议：振幅/频率/气压/速度的最佳范围
3. 潜在风险：材料变形/熔边/刀具磨损/分层问题预判
4. 样件准备要求：客户需提供的材料规格（尺寸/卷装/预处理）
5. 成本估算：该材料切割的每米/每平方米成本
6. 替代方案：若首选方案不可行，建议工艺路径
```
**使用示例**：客户要切割3层碳纤维预浸料，厚度2mm/层，要求边缘无分层

### 场景 10：设备配置推荐
**角色设定**：产品经理，精通全系列设备参数与应用场景

**提示词模板**：
```
基于客户需求推荐设备配置：
客户需求：
- 主要材料：[列表，如皮革/海绵/布料]
- 日产能：[目标]
- 精度要求：[公差范围]
- 预算区间：[范围]
- 场地条件：[面积/层高/电力]

输出：
1. 机型推荐：标准机/定制机/工作台面尺寸
2. 头数配置：单头vs多头vs桥式（产能与灵活性权衡）
3. 刀具组合：必配刀具+选配刀具（针对材料组合）

```
**使用示例**：印度客户，主切汽车脚垫（EVA+地毯复合），日产500片，预算$30,000-50,000

### 场景 11：技术咨询回复

**提示词模板**：
```
回复客户专业技术咨询：
问题类型：[切割质量/速度优化/软件操作/维护]
客户问题：[详细描述]
客户技术背景：[新手/有经验/专家级]

回复要求：
1. 直接回答：用通俗语言解释技术原理（避免过度jargon）
2. 操作步骤：分步骤解决方案（Step 1/2/3）
3. 参数设置：给出具体数值范围（而非"适当调整"）
4. 视觉辅助：描述应附带的图片/视频内容（截图标注）
5. 预防措施：如何避免问题再次发生
6. 升级路径：如果问题持续，下一步诊断流程
7. 语气校准：[耐心教学/专业对等/紧急处理]
```
**使用示例**：客户反馈振动刀切割皮革时边缘有毛刺，客户是新手操作员

### 场景 12：定制需求评估
**角色设定**：研发项目经理，擅长定制化项目管理

**提示词模板**：
```
评估客户定制需求：
定制内容：[非标尺寸/特殊功能/软件接口/自动化集成]
技术约束：[交期/成本/技术成熟度]

分析框架：
1. 可行性评级：A-标准配置/B-简单改装/C-深度定制/D-不可行

4. 成本结构：标准机+定制费用明细（开模/编程/测试）
5. 交付周期：设计确认+生产+调试的时间线
6. 知识产权：定制部分的权属约定建议
7. 决策建议：是否接受此定制的商业判断（投入产出比）
```
**使用示例**：客户要求在标准振动刀上加装CCD视觉定位系统，对接其MES系统

## 三、售后服务与客户维护（4个）

### 场景 14：远程故障诊断
**角色设定**：售后技术专家，擅长远程排障

**提示词模板**：
```
设计远程故障诊断对话流程：
故障现象：[客户描述，如"切割时断刀"]
客户能力：[操作人员水平/是否有万用表/能否视频]

诊断流程：
1. 安全确认：断电检查/机械锁止提醒
2. 信息收集：必问的5个问题（故障码/发生频率/材料/最近改动/环境）
3. 分层诊断：
   - Level 1：软件设置检查（参数/原点/刀具补偿）
   - Level 2：机械检查（皮带/导轨/刀具磨损）
   - Level 3：电气检查（伺服报警/信号干扰）
4. 视频指导脚本：指导客户拍摄关键部位
5. 临时解决方案：让设备恢复运行的应急措施
6. 备件预判：根据诊断提前准备可能的更换部件
7. 升级判断：何时必须派遣工程师现场处理
```
**使用示例**：海外客户反馈"切割时断刀"，操作员是新手，有微信视频能力

### 场景 15：重大客户投诉处理
**角色设定**：客户关系危机管理专家

**提示词模板**：
```
处理重大客户投诉：
投诉内容：[设备停机/质量事故/交期延误]
客户情绪：[愤怒/失望/威胁曝光/法律诉讼]
影响范围：[单台/批量/生产线停滞]

应对策略：
1. 即时响应：首通电话/邮件的话术（共情+担责+行动）
2. 根因分析：技术问题 vs 操作问题 vs 物流问题的责任界定
3. 短期止血：24小时/48小时/72小时补救措施
4. 长期方案：根本解决问题的行动计划
5. 补偿方案：赔偿限度内的补偿选项（延保/备件/折扣/培训）
6. 关系修复：高层介入时机与致歉信模板
7. 内部复盘：此投诉反映的流程改进点
```
**使用示例**：大客户设备停机3天，威胁在行业群曝光，要求赔偿停产损失

### 场景 16：设备维护提醒
**角色设定**：客户成功经理，擅长主动服务营销

**提示词模板**：
```
制定客户设备维护提醒内容：
设备信息：[购买时间/使用强度/运行小时数]
客户类型：[积极维护型/被动维修型/忽视维护型]

内容体系：
1. 日常维护：每日/每周操作员自检清单（简化版）

5. 升级建议：软件更新/硬件改装提示（基于新机型功能）

7. 多语言版本：确保当地操作员能理解的通俗语言
```
**使用示例**：针对使用18个月的皮革切割机，提示客户更换导轨滑块与皮带检查

### 场景 17：配件销售与交叉销售
**角色设定**：售后服务销售，将服务转化为收入

**提示词模板**：
```
设计配件与增值服务销售话术：
触发场景：[设备保养/故障维修/续保到期]
客户状态：[设备使用1年以上/高利用率工厂]

销售策略：
1. 需求挖掘：询问当前耗材库存/刀具磨损情况/软件版本
2. 套餐设计：
   - 基础包：常用易损件（刀片/毛毡/吸风罩）
   - 进阶包：+ 备用伺服/驱动器（关键备件）
   - 无忧包：+ 年度预防性维护服务
3. 价值话术：强调停机成本 vs 预防成本对比计算
4. 促销策略：老客户折扣/批量采购价/以旧换新
5. 交叉销售：推荐升级配件（如加装CCD巡边/投影定位系统）
```
**使用示例**：客户设备使用2年，来电咨询刀片采购，顺势推荐年度维护套餐
