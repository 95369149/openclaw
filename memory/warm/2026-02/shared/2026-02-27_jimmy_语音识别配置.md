# 语音识别（STT）配置记录
> 2026-02-27 20:16 by jimmy

## 当前配置

OpenClaw 已启用本地 whisper 语音转文字，配置在 `~/.openclaw/openclaw.json`：

```json
"tools": {
  "media": {
    "audio": {
      "enabled": true,
      "models": [
        {
          "type": "cli",
          "command": "/Users/apple/Library/Python/3.9/bin/whisper",
          "args": ["--model", "tiny", "--language", "zh", "--output_format", "txt", "--output_dir", "/tmp/whisper_out", "{{MediaPath}}"],
          "timeoutSeconds": 60
        }
      ]
    }
  }
}
```

## 关键信息

- whisper CLI 路径：`/Users/apple/Library/Python/3.9/bin/whisper`（不在 PATH 里，必须用全路径）
- 当前模型：base（139MB，中文识别比 tiny 好，已下载完成）
- Clash Verge 代理端口：7897（不是 7890！）
- 输出目录：`/tmp/whisper_out`（避免写入只读文件系统报错）
- 语言：zh（中文）
- 超时：60秒

## 已知问题

1. tiny 模型中文识别不够准（"识别"→"死别"），建议后续升级到 base 或 small 模型
2. base 模型（139MB）下载速度极慢（几 KB/s），需要挂代理下载
3. whisper 包版本：openai-whisper 20240930，安装在 Python 3.9 用户目录

## 升级路径

1. 挂代理下载 base 模型：`/Users/apple/Library/Python/3.9/bin/whisper --model base` 会自动下载
2. 或用 whisper-cpp（更快，支持 Apple Silicon 加速）
3. 或配置 OpenAI API 的 `gpt-4o-mini-transcribe`（需要 key）
