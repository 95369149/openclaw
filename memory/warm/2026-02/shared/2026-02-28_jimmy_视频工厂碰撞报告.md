## 一、Veo 3.1 提示词最佳实践

### 结构化提示词公式（来自 VidAU.ai + Oreate AI）
```
[主体] + [动作] + [环境] + [镜头运动] + [光线] + [风格] + [情绪] + [音效暗示]
```

### 关键技巧
1. **Subject Anchoring（主体锚定）**：明确描述主体特征，避免面部不一致
2. **JSON 提示词**：用 JSON 结构化提示词可以精确控制每个参数，把 Veo 从"创意玩具"变成"可控生产引擎"
3. **首尾帧控制**：提供首帧和尾帧图片，生成更连贯的过渡视频
4. **分辨率**：原生 1080p，可通过 Veo 3.1 升级到 4K
5. **每段最长 8 秒**：多段拼接成完整视频
6. **避免**：复杂文字渲染、极端写实人脸、多人场景

## 二、Nano Banana 2 官方提示词分析（来自 Google Blog）

### 核心能力
- Pro 级视觉智能 + Flash 级速度
- 支持多图一致性（14个角色保持一致）
- 支持多语言文字渲染（含中文、印地语）
- 支持风格迁移（合成立体主义等）

### 官方高质量提示词特征
1. **超长描述**：官方示例提示词平均 150-300 词，极其详细
2. **摄影术语**：35mm, soft blur, shallow depth of field, volumetric lighting
3. **情绪描述**：不只描述画面，还描述氛围和感受
4. **色彩指定**：具体到 "electric blue and shocking pink"
5. **材质描述**："tightly coiled hair", "recycled material", "graphite look"
6. **多步生成**：先生成角色，再用角色生成故事（保持一致性）

### 关键发现：6图故事法
```
Create a funny 6 part story with these 3 fluffy friends building a tree house.
The story is thrilling throughout with emotional highs and lows and is ending in a happy moment.
Keep the attire and identity consistent of all 3 characters.
Generate 6 images one at a time. Each image should be a separate output in 16:9 format.
```
→ 这个方法可以直接用于生成视频分镜！

## 三、TikTok/抖音算法 2026（来自 SyncStudio + MyKaraoke）

### 核心算法机制
1. **初始测试**：新视频先推给小群体测试
2. **80%完播率**：看完80%以上的视频获得显著推荐加成
3. **三阶段扩散**：粉丝验证 → 受众扩展 → 病毒传播
4. **零粉丝也能爆**：TikTok 基于内容发现，不是粉丝数

### 2026 爆款公式
1. **前3秒决定生死** — 必须有强钩子
2. **无脸内容（Faceless）最适合AI** — 旁白+字幕+画面，命中算法两个最高权重搜索信号
3. **完播率 > 点赞数** — 短视频（15-30秒）更容易高完播
4. **Brainrot 内容正在爆发** — 荒诞、混乱、高参与度的短片
5. **AI生成内容需要"人味"** — TikTok 2026 报告强调 "Irreplaceable Instinct"

### 对我们的策略影响
- **视频长度控制在 15-30 秒**（高完播率）
- **前3秒必须有视觉冲击**（钩子）
- **用旁白+字幕替代真人出镜**（AI最擅长）
- **加入情感元素**（不能纯AI感）
- **用热门音乐/音效**（算法加权）

## 四、优化后的完整流水线

### Phase 1: 智能选题（每天08:00）
- 搜索抖音/YouTube/小红书热门趋势
- 分析哪些内容类型完播率最高
- 生成3套方案，每套包含：标题钩子+30秒脚本+分镜提示词

### Phase 2: 高质量生图（每天10:00）
- 用 Nano Banana 2 的"6图故事法"生成分镜
- 提示词必须 150+ 词，包含摄影术语+情绪+色彩+材质
- 保持角色/风格一致性
- 生成 16:9 横版（YouTube）和 9:16 竖版（抖音）

### Phase 3: 视频生成（每天11:00）
- Veo 3.1 用结构化提示词
- 提供首尾帧图片控制连贯性
- 每段8秒，3段拼接成24秒视频
- 重点：前3秒必须是最震撼的画面

### Phase 4: 配乐+旁白（每天13:00）
- ProducerAI 生成匹配情绪的配乐
- Gemini TTS 生成中文旁白（知识科普类）
- 热门音效叠加（提升算法权重）

### Phase 5: 合成+质检（每天14:00）
- ffmpeg 合成：视频+配乐+旁白+字幕
- 竖屏适配（9:16）
- 质检清单：前3秒钩子、完播率预估、AI痕迹检查
- 导出两个版本：抖音版（竖屏+中文字幕）+ YouTube版（横屏+英文字幕）

## 五、10条核心优化建议

1. **提示词长度翻倍**：从50词提升到150-300词，加入摄影术语和情绪描述
2. **6图故事法**：先生成6张分镜图，再逐张生成视频段落
3. **前3秒法则**：每个视频的第一个镜头必须是最震撼的
4. **15-30秒黄金长度**：控制视频长度，追求高完播率
5. **无脸内容策略**：旁白+字幕+AI画面，最适合AI生产
6. **首尾帧控制**：给 Veo 提供参考图片，提升连贯性
7. **双版本输出**：每条视频同时出抖音版和YouTube版
8. **情感注入**：纯AI画面加人声旁白，增加"人味"
9. **热门音效叠加**：在配乐基础上加平台热门音效
10. **迭代优化**：每周分析播放数据，淘汰低效赛道，加码高效赛道
