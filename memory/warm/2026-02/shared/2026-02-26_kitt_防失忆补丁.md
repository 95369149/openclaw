# Kitt 防失忆补丁 v1.0

## 问题
kitt 压缩后不执行第零号铁律（先读记忆再说话），导致用过时信息回复。

## 根因
1. 压缩后 summary 不包含"先读文件"的强制指令
2. SOUL.md 的第零号铁律在压缩后被截断，不在 context 里
3. kitt 看到新消息就直接回复，跳过了恢复流程

## 修复
1. SOUL.md 第零号铁律已有（v2.2）
2. WORKFLOW_AUTO.md 恢复流程已有（v2.0）
3. **缺失的一环**：compaction summary 模板里没有强制恢复指令

## 建议
在 openclaw.json 的 compaction.memoryFlush 配置中，确保 systemPrompt 包含：
```
压缩后第一件事：读 memory/.abstract + memory/task-board.json + memory/2026-MM-DD.md，不读完不许回复任何消息。
```

或者在 AGENTS.md 的子 Agent 强制规则里加一条：
```
- **压缩后恢复**：任何 agent 压缩后，第一步必须读 memory/.abstract + task-board.json + 今日日志，不读完不回复
```
