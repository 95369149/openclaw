## 二、WhatsApp Business API 方案

**官方路径**：
- Meta Business Suite → 申请 API 访问权
- 需企业认证（营业执照+Facebook Business Manager）
- 集成方式：Twilio/MessageBird/360dialog（中间商）
- 成本：$0.005-0.02/条（按量计费）

**技术栈**：
- API 对接：Node.js/Python + Webhook
- 消息模板需预审（24h响应窗口外必须用模板）
- 自动化：Zapier/Make.com 或自建

##三、开源方案

**推荐组合**：
1. **Mautic**（开源营销自动化）+ **n8n**（工作流）
   - 免费，可接入 OpenAI/Claude API
   - 支持邮件/WhatsApp/Telegram 多渠道
   
2. **Chatwoot**（开源客服）+ **Botpress**（AI 对话）
   - 统一收件箱，AI 自动回复
   - 可接入 WhatsApp Business API

3. **Odoo CRM**（开源 ERP）
   - 自带邮件营销+线索管理
   - 可定制 AI 模块

## 四、CNC 行业线索渠道

**平台优先级**：
1. **LinkedIn**（核心）：搜索 "CNC machining" "manufacturing engineer" "procurement manager"
2. **Alibaba/Made-in-China**：反查竞品客户
3. **ThomasNet**（北美）：工业采购目录
4. **Europages**（欧洲）：B2B 黄页
5. **行业展会数据库**：IMTS/EMO/CIMT 参展商名单

**线索抓取**：
- Apollo.io 按职位+行业筛选
- Hunter.io 验证邮箱有效性
- LinkedIn Sales Navigator（$99/月）

## 五、WhatsApp+邮件+AI 案例

**典型流程**：
1. **线索获取**：Apollo.io 导出目标客户（职位+邮箱+LinkedIn）
2. **邮件触达**：Instantly.ai 发送个性化开发信（AI 生成内容）
3. **WhatsApp 跟进**：
   - 邮件打开但未回复 → 自动触发 WhatsApp 消息
   - 使用 Business API + 预设模板
4. **AI 客服**：Chatwoot 接入 GPT-4，自动回答技术问题
5. **CRM 同步**：所有互动记录自动进 HubSpot/Pipedrive

**成本估算**（月）：
- Apollo.io Pro：$149
- Instantly.ai：$97（5000 邮件/月）
- WhatsApp API（Twilio）：$50-200（按量）
- n8n 云版：$20（或自建免费）
- AI API（OpenAI/Claude）：$50-100
- **总计：$366-616/月**

## 六、推荐方案（红太阳数控）

**阶段一（低成本试水）**：
- Hunter.io（$49）+ Instantly.ai（$37）+ Chatwoot 开源版
- 手动 WhatsApp 跟进（个人号）
- **月成本：$86 + 人工**

**阶段二（规模化）**：
- Apollo.io（$149）+ Lemlist（$59）+ WhatsApp Business API（$100）
- n8n 自动化工作流 + AI 客服
- **月成本：$308 + AI API $50 = $358**

**关键建议**：
1. 先用 Apollo.io 免费版测试线索质量
2. WhatsApp 个人号先跑通流程，再上 Business API
3. AI 内容生成用豆包/Kimi（成本低）
4. 重点攻 LinkedIn + ThomasNet（CNC 行业精准度高）
