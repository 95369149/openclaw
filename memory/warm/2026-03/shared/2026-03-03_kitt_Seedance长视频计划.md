## 一、项目背景

### 1.1 需求分析

**传统视频制作痛点：**
- 拍摄成本高（设备、场地、人员）
- 周期长（脚本→拍摄→剪辑需 2-4 周）
- 难以快速迭代（修改需重新拍摄）

**AI 生成视频优势：**
- 成本低（仅需文本脚本）
- 速度快（24 小时内完成）
- 灵活性高（随时调整画面、节奏）

### 1.2 Seedance 2.0 能力

- **单次生成时长：** 5-10 秒
- **画面质量：** 1080p，工业级细节
- **运镜能力：** 推拉摇移、特写、全景
- **拼接能力：** 支持多片段无缝衔接

## 二、分镜脚本模板（工业设备展示）

## 三、Seedance 2.0 拼接工作流

### 3.1 短片段生成策略

**原则：** 每个片段 5-8 秒，确保画面连贯性

**步骤：**

1. **脚本拆解** — 将 10 分钟脚本拆成 80-120 个片段
2. **提示词生成** — 为每个片段编写详细的 Seedance 提示词
3. **批量生成** — 使用 Seedance API 批量提交任务
4. **质量筛选** — 人工审核，剔除不合格片段（重新生成）
5. **拼接合成** — 使用 FFmpeg 或 Premiere 拼接

### 3.2 提示词编写规范

**好的提示词示例：**
```
A high-tech CNC cutting machine in a modern factory, 
blue LED lights illuminating the workspace, 
vibrating knife cutting through black leather with precision, 
close-up shot, slow motion, 
industrial photography style, 8K resolution
```

**避免的错误：**
- 过于简单："cutting machine working"
- 信息冲突："daytime factory with night sky"
- 运镜过快："camera spinning 360 degrees in 2 seconds"

### 3.3 拼接技术方案

**方案 A：FFmpeg 命令行（推荐）**

```bash
# 1. 创建片段列表
cat > filelist.txt << EOF
file 'shot_001.mp4'
file 'shot_002.mp4'
file 'shot_003.mp4'
...
EOF

# 2. 无缝拼接
ffmpeg -f concat -safe 0 -i filelist.txt -c copy output.mp4

# 3. 添加转场效果（淡入淡出）
ffmpeg -i shot_001.mp4 -i shot_002.mp4 \
  -filter_complex "[0:v][1:v]xfade=transition=fade:duration=0.5:offset=7.5[v]" \
  -map "[v]" output_with_fade.mp4
```

**方案 B：Python 自动化脚本**

```python
import subprocess
import json

def generate_video_from_script(script_file, output_file):
    with open(script_file) as f:
        shots = json.load(f)
    
    # 1. 批量生成 Seedance 片段
    for shot in shots:
        prompt = shot['scene_description']
        duration = shot['duration']
        # 调用 Seedance API
        generate_seedance_clip(prompt, duration, f"shot_{shot['shot_id']}.mp4")
    
    # 2. 拼接所有片段
    concat_clips([f"shot_{s['shot_id']}.mp4" for s in shots], output_file)
    
    # 3. 添加字幕和配乐
    add_subtitles(output_file, shots)
    add_background_music(output_file, "bgm.mp3")
```

## 四、配乐、字幕、转场方案

### 4.1 配乐策略

**音乐分段：**
- **开场（0-30s）** — 震撼、大气（如 Epic Trailer Music）
- **技术讲解（30s-5min）** — 科技感电子乐（节奏稳定）
- **应用案例（5-8min）** — 轻快、现代（展示效率）
- **结尾（8-10min）** — 回归大气，品牌强化

**音乐来源：**
- Epidemic Sound（商用授权）
- Artlist（订阅制）
- AI 生成音乐（MusicFX / Suno）

**音量控制：**
- 背景音乐：-20dB
- 旁白/字幕音效：-10dB
- 避免音乐抢戏

### 4.2 字幕方案

**字幕类型：**
1. **硬字幕（烧录）** — 适合社交媒体（YouTube, 抖音）
2. **软字幕（SRT）** — 适合多语言版本

**字幕样式：**
- 字体：思源黑体 Bold / Arial Bold
- 大小：48px（1080p 视频）
- 颜色：白色，黑色描边（2px）
- 位置：底部居中，距离底边 10%

**自动生成工具：**
```bash
# 使用 Whisper 自动生成字幕
whisper video.mp4 --model large --language zh --output_format srt

# 烧录字幕到视频
ffmpeg -i video.mp4 -vf "subtitles=video.srt:force_style='FontSize=24'" output_with_subs.mp4
```

### 4.3 转场效果

**推荐转场类型：**
- **淡入淡出（Fade）** — 适合章节切换
- **交叉溶解（Dissolve）** — 适合同场景不同角度
- **擦除（Wipe）** — 适合技术参数展示
- **无转场（Cut）** — 适合快节奏片段

**转场时长：**
- 标准：0.5 秒
- 快速：0.3 秒
- 慢速：1.0 秒

**FFmpeg 转场示例：**
```bash
# 淡入淡出
xfade=transition=fade:duration=0.5:offset=7.5

# 左右擦除
xfade=transition=wipeleft:duration=0.8:offset=7.2

# 圆形扩散
xfade=transition=circleopen:duration=1.0:offset=7.0
```
