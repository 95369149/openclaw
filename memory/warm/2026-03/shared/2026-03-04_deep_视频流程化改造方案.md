## 一、现状分析

当前 video-content skill 采用"一次性生成"模式，输出包含脚本、画面、字幕、BGM、标题等全部要素，但缺乏：
- **过程控制**：无法在中间环节调整方向
- **质量把关**：没有分阶段验收标准
- **协作支持**：难以多人分工（选题、编剧、导演）
- **复用能力**：好的选题/脚本无法沉淀为模板

## 二、五步流程设计

### 步骤 1：选题策划
**输入：** 内容矩阵类型（A/B/C/D）、目标平台、近期热点  
**输出：**
```yaml
topic_id: "A-20260304-001"
category: "产品展示"
hook: "3秒切穿10mm钢板，这台国产CNC有多猛？"
target_audience: "小型加工厂老板、创业者"
pain_point: "进口设备贵、国产怕翻车"
platform: ["tiktok", "youtube_shorts"]
estimated_duration: "45-60秒"
```
**验收标准：**
- 钩子符合"3秒抓眼球"原则
- 痛点精准（目标客户会点头）
- 平台适配明确

---

### 步骤 2：脚本撰写
**输入：** 选题策划输出 + 产品资料  
**输出：**
```markdown
## 脚本全文（含时间轴）
[0-3秒] 钩子：3秒切穿10mm钢板，这台国产CNC有多猛？
[3-10秒] 痛点：进口设备30万起，国产又怕翻车？
[10-35秒] 方案：HTYCNC用航空铝+日本伺服，价格只要1/3
[35-50秒] 证据：已交付500+台，返修率<2%，看实测
[50-60秒] CTA：评论区留言你的需求，免费出方案

## 旁白文案（逐句）
1. "老板们注意了，这可能是今年性价比最高的CNC"
2. "很多人觉得国产不行，但数据会说话"
...
```
**验收标准：**
- 符合"钩子-痛点-方案-证据-CTA"结构
- 时间轴精确到秒
- 旁白口语化、有节奏感

---

### 步骤 3：分镜设计
**输入：** 脚本 + 素材库清单  
**输出：**
```markdown
## 镜头列表
| 时间 | 镜头号 | 画面内容 | 素材来源 | 备注 |
|------|--------|----------|----------|------|
| 0-3s | S01 | 钢板被激光切穿特写 | 库存/需补拍 | 慢动作，火花四溅 |
| 3-10s | S02 | 老板愁眉苦脸看报价单 | AI生成 | 情绪化表演 |
| 10-20s | S03 | HTYCNC设备全景+细节 | 产品库 | 突出日本伺服标识 |
| 20-35s | S04 | 加工过程实拍 | 需补拍 | 多角度剪辑 |
| 35-50s | S05 | 数据图表动画 | AE模板 | 500台+2%返修率 |
| 50-60s | S06 | 客服二维码+产品矩阵 | 固定素材 | 结尾标准版 |

## 素材需求
- 【缺失】钢板切割慢动作（需补拍，预计0.5天）
- 【缺失】加工过程多角度（需补拍，预计1天）
- 【可用】产品库存素材23条
```
**验收标准：**
- 每个镜头有明确素材来源
- 标注缺失素材及补拍成本
- 画面与旁白节奏匹配

---

### 步骤 4：内容生成
**输入：** 分镜 + 素材文件路径  
**输出：**
```yaml
video_draft:
  file: "/path/to/draft_A-20260304-001_v1.mp4"
  duration: "58秒"
  resolution: "1080x1920"
subtitle_file: "/path/to/subtitles.srt"
bgm: "Epic Tech Motivation - 库ID #4521"
thumbnail_options: 
  - "/path/to/thumb_option1.jpg"  # 火花特写
  - "/path/to/thumb_option2.jpg"  # 设备正面
metadata:
  title: "国产CNC终于能打了？实测对比进口设备"
  hashtags: ["#CNC加工", "#智能制造", "#创业设备"]
  description: "HTYCNC激光切割机实测..."
```
**验收标准：**
- 视频时长±5秒误差
- 字幕无错别字、时间轴同步
- BGM情绪匹配内容节奏

---

### 步骤 5：质量审核
**输入：** 生成的视频草稿 + 元数据  
**输出：**
```yaml
review_result:
  status: "approved" | "revision_needed"
  score:
    hook_effectiveness: 8/10  # 前3秒完播率预估
    information_density: 9/10  # 信息量/时长比
    cta_clarity: 7/10          # 行动指令明确度
    platform_compliance: 10/10 # 平台规范（时长、比例、内容）
  issues:
    - type: "minor"
      timestamp: "35-38秒"
      description: "数据图表停留时间过短，建议延长2秒"
    - type: "suggestion"
      description: "结尾CTA可加紧迫感，如'限时免费方案'"
  next_action: "修改后重新提交" | "批准发布"
```
**验收标准：**
- 四项评分均≥7分
- 无major级别问题
- 平台合规性100%

## 三、实现方案

### 3.1 文件结构调整
```
/Users/apple/.openclaw/skills/video-content/
├── SKILL.md                    # 主入口，调度5步流程
├── scripts/
│   ├── 01-topic-planner.js     # 选题策划脚本
│   ├── 02-script-writer.js     # 脚本撰写（调用LLM）
│   ├── 03-storyboard.js        # 分镜设计
│   ├── 04-video-generator.js   # 视频生成（调用剪辑工具）
│   └── 05-quality-reviewer.js  # 质量审核
├── templates/
│   ├── topic-template.yaml     # 选题模板
│   ├── script-template.md      # 脚本模板
│   └── storyboard-template.md  # 分镜模板
├── config/
│   ├── content-matrix.yaml     # 内容矩阵配置（A/B/C/D类）
│   ├── platform-specs.yaml     # 平台规格（时长、比例、标签）
│   └── quality-standards.yaml  # 质量标准阈值
└── assets/
    ├── bgm-library.json        # BGM库索引
    └── stock-footage.json      # 素材库索引
```

### 3.2 指令设计
```bash
# 完整流程（一键生成）
/video --type A --platform tiktok

# 分步执行
/video topic --type A              # 仅生成选题
/video script --topic-id A-001     # 基于选题写脚本
/video storyboard --script-id S-001 # 基于脚本做分镜
/video generate --storyboard-id SB-001 # 生成视频
/video review --video-id V-001     # 质量审核

# 快速迭代
/video revise --video-id V-001 --fix "延长数据图表2秒"
```

### 3.3 技术栈
- **LLM调用**：脚本撰写、质量评审（Claude/GPT-4）
- **视频生成**：FFmpeg（剪辑）+ Remotion（动画）
- **素材管理**：本地文件系统 + JSON索引
- **状态追踪**：SQLite轻量数据库（记录每步输出）

## 四、效率提升评估

### 改造前（当前模式）
- **单条视频耗时**：20-30分钟（一次性生成+手动调整）
- **返工率**：约40%（方向不对需重做）
- **复用率**：低（好的选题/脚本难以沉淀）
- **协作难度**：高（无法分工）

### 改造后（流程化）
- **单条视频耗时**：
  - 选题：3分钟
  - 脚本：5分钟
  - 分镜：5分钟
  - 生成：8分钟
  - 审核：2分钟
  - **总计：23分钟**（首次）
- **返工率**：预计降至15%（早期验收避免返工）
- **复用率**：高（选题/脚本可存为模板，二次生产仅需10分钟）
- **协作支持**：可多人并行（选题师、编剧、剪辑师）

### 量化收益
- **时间节省**：首次持平，二次生产节省50%
- **质量提升**：分阶段把关，预计完播率提升15-20%
- **规模化能力**：从日产2条→日产5-8条（复用模板）
- **知识沉淀**：3个月积累50+优质模板，形成内容资产
