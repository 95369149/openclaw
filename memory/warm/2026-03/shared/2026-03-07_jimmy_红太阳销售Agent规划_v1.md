# 红太阳业务侧 · 高价值 Agent 场景落地规划 (v1.0)
> 目标：将 AI 从“聊天工具”升级为“安全/审计/专业代理”，融入业务执行链。
> 原则：不追求炫技，只做能直接替企业省钱、避险、提效的垂直节点。

## 场景 1：【询盘分级与背调 Agent】（意图桶：S1 线索审查）
**痛点**：销售每天收到大量询盘，难以快速判断客户质量，导致精力分配不均，容易漏掉大客户或在羊毛党上浪费时间。
**Agent 核心职责**：
- **输入**：客户的公司名称、网站、询盘原话、地区。
- **动作**：自动调用外链搜索工具（如 agent-reach），爬取该公司的公开信息、注册地、主要产品线、近期动态。
- **输出**：
  1. **ABC 评级**：A(高优核心)、B(潜力意向)、C(低潜/同行探底)。
  2. **画像摘要**：该客户的真实体量与主营业务。
  3. **推荐切入点**：“对方主做汽车内饰，建议直接推多层裁床+内饰打样视频”。

## 场景 2：【报价风险检查与审计 Agent】（意图桶：S2 商机话术 / SC1 风险监控）
**痛点**：销售发出报价单前，人工审核容易忽略配置错配、运费计算遗漏、利润率触底等暗坑。
**Agent 核心职责（AI 审核节点）**：
- **输入**：待发出的报价单草稿（PDF/Excel/文本）+ 客户基础信息。
- **动作**：与红太阳标准价格库/配置底线进行交叉比对。
- **输出**：只出红灯/绿灯和修改建议。
  - 🚨 **红灯**：如“气动刀未配置专用空压机”“海运费未覆盖当前红海涨价幅度”“利润率低于底线”。
  - ✅ **绿灯**：配置合理，可以发送。
- **业务流**：所有对外报价单，必须过一遍此 Agent，通过后才允许发送。

## 场景 3：【跨时区 / 小语种客户跟进话术 Agent】（意图桶：S2 商机话术）
**痛点**：外贸业务员在处理非英语（如西语、阿语、俄语）客户时，沟通效率低，回复慢，且很难把握当地商商务文化节奏。
**Agent 核心职责**：
- **输入**：客户的上一步回复（原文）+ 我们期望达到的目的（例如：催定金、约视频看厂、解释交期）。
- **动作**：
  1. 准确翻译客户意图，并分析情绪（着急、犹豫、比价中）。
  2. 生成符合当地商务习惯的小语种回复话术。
- **输出**：
  1. **客户真实意图**（中文）
  2. **建议回复话术**（中文+目标小语种对照）
  3. **下一步行动建议**（如：“客户很关注精度，建议附带上一段特写视频”）
