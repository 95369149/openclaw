# Agent 职能与模型重组方案 v7.0 (待审批)

## 🎯 核心痛点与优化目标
当前系统存在职责重叠、模型配置未最优化（如缺乏专用的深度推理模型）等问题。
本次优化目标：**好钢用在刀刃上**，让各个 Agent 的能力边界与所配模型特性 100% 契合。

## 🤖 编制重组明细

### 1. Jimmy (大管家 & 路由中枢)
* **职能**：面对厂长、理解意图、分发任务、调用外部工具（浏览器/脚本）、跨渠道通知。
* **配置模型**：`mynewapi/claude-opus-4-6` (维持不变)
* **理由**：作为系统的大脑，需要最顶级的指令遵循、工具调用和零废话理解能力。

### 2. Deep (首席牛马：写手 & 码农)
* **职能**：自动化脚本编写、长文报告撰写、批量数据处理、爬虫解析摘要。
* **配置模型**：`v1api/deepseek-v3.2` 或 `metaapi/gpt-5.3-codex`
* **理由**：DeepSeek V3.2 中文语感极佳且编码能力极强，成本低、出活快；GPT-5.3-Codex 作为强力代码备用。彻底取代原来不上不下的 Sonnet 配置。

### 3. Logic (精算师：深度思考)
* **职能**：经营数据分析、商业逻辑推演、数学计算、复杂SOP/流程设计。
* **配置模型**：`v1api/deepseek-r1` (全新引入)
* **理由**：引入目前最强的深度推理（CoT）模型。凡是涉及算账、深度推演、战略博弈的任务，交给自带思考过程的 R1 处理。

### 4. Main (外包团队：长文本 & 多模态)
* **职能**：海量网页生肉消化、每日外网资讯巡逻、视频关键帧图片分析、长财报总结。
* **配置模型**：`google-gemini-cli/gemini-3-pro-preview` (维持不变)
* **理由**：拥有 100-200万 超大上下文窗口，支持视觉，且**调用免费**。适合做每天高频的资料摄取和短视频批量处理。

### 5. Kitt (架构师 & 审计员)
* **职能**：系统架构设计、Skill 指令链重构、重大方案（如设备数字孪生、供应链调整）PK与审核。
* **配置模型**：`v1api/grok-4` 或 `mynewapi/claude-opus-4-6`
* **理由**：作为 Jimmy 的影子大脑，专门处理“非标”和“高危”决策。引入 Grok-4 可以打破 Claude 系的思维定势，提供更尖锐的视角。

---
## 💡 方案收益
1. **引入 R1 推理**：彻底弥补了复杂商业推演时 AI 不懂深度思考的短板。
2. **术业有专攻**：V3写代码/文章，R1搞推理，Gemini吞长文，Opus控全局。
3. **成本极优**：重度吞吐的活交给免费的 Gemini 和廉价的 V3，昂贵的 Opus 只负责调度。
