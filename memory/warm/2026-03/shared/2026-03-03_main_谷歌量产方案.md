## 二、高质量视频提示词公式（从教程中提炼）

**Veo 3 的黄金公式**：
```
Subject（主体）+ Action（动作）+ Camera（镜头）+ Lighting（灯光）+ Style（风格）
```

### ❌ 低质量写法
> "A cutting machine cutting leather"

### ✅ 高质量写法
> "Close-up of a precision CNC oscillating knife blade slicing through premium Italian full-grain leather, slow motion tracking shot from left to right, warm workshop lighting with dramatic side light casting sharp shadows, shallow depth of field, cinematic industrial style, 4K, subtle dust particles visible in light beam"

### 关键技巧（来自 VidAU/MetricsMule 专业教程）

1. **描述镜头，不是想法**
   - ❌ "展示切割机很厉害" → ✅ "Macro close-up of blade edge meeting material surface"
   - Veo 理解的是摄影语言，不是营销语言

2. **主体要极度具体**
   - ❌ "a machine" → ✅ "a red industrial CNC oscillating knife cutter with digital control panel"
   - 属性越多，画面越稳定（减少帧间漂移）

3. **动作必须有明确动词**
   - ❌ "leather being cut" → ✅ "blade glides smoothly through 3mm leather, material separating cleanly"
   - 动作创造运动向量，没有动作 = 画面抖动

4. **摄影术语是质量分水岭**
   - 镜头运动：tracking shot, dolly-in, crane shot, slow pan, orbit shot
   - 景深：shallow depth of field, rack focus, bokeh
   - 帧率暗示：slow motion, time-lapse

5. **灯光决定质感**
   - 工业场景：dramatic side lighting, warm tungsten workshop light
   - 产品特写：studio rim lighting, soft diffused key light
   - 避免：flat lighting, overexposed

6. **负面提示词（去瑕疵）**
   - 加入：no text overlay, no watermark, no artificial look, no motion blur artifacts
   - 每次生成后检查：手部变形、刀头扭曲、材料穿模

## 三、每日 SOP（3 条视频，质量优先）

### 08:00 — 选题（5 分钟）
1. 打开 Gemini App，发送：
```
你是红太阳数控的内容策划。我们做柔性材料智能切割设备（振动刀、气动刀、多层裁床、激光切割机），应用于皮革、汽车内饰、家纺、复合材料等。

今天给我 3 个短视频选题，要求：
1. 每个选题一句话说清核心卖点
2. 目标受众：工厂采购决策者
3. 内容类型分配：1 个产品力展示 + 1 个应用场景 + 1 个客户痛点
4. 每个选题附带情绪钩子（开头 3 秒抓住注意力）
```
2. 确认 3 个选题（不满意就让 Gemini 重新生成，直到满意为止）

### 08:30 — 生成提示词（每条 10 分钟）
1. 对每个选题，在 Gemini 中发送：
```
基于这个选题：[粘贴选题]

帮我生成 Veo 3.1 视频提示词，要求：
1. 用英文写（Veo 英文效果最好）
2. 严格遵循公式：Subject + Action + Camera + Lighting + Style
3. 分 3-5 个镜头，每个镜头一段提示词
4. 每个镜头指定：镜头运动（tracking/dolly/pan）、景深、灯光
5. 加入负面提示词：no text, no watermark, no motion artifacts
6. 风格统一：cinematic industrial, 4K, shallow depth of field
```
2. **审核提示词**：检查是否有模糊词（beautiful/amazing/nice），有就改成具体描述
3. 同时生成 Imagen 3 的关键帧提示词（用于图生视频，效果更稳定）

### 09:30 — 生成素材（核心环节，不能赶）
**Imagen 3 关键帧**（每条视频 3-5 张）：
1. 打开 aistudio.google.com → 选择 Imagen 3
2. 粘贴关键帧提示词，生成 4 张，挑选最好的 1 张
3. **质量检查**：放大看细节，刀头是否变形？材料质感对不对？光影自然吗？
4. 不满意就调整提示词重新生成，**不要将就**

**Veo 3.1 视频**（每个镜头单独生成）：
1. aistudio.google.com → 选择 Veo 3.1
2. 可以选择：纯文本生成 或 图片+文本生成（后者更稳定）
3. 每个镜头生成 2-3 个版本，挑选最好的
4. **质量检查清单**：
   - [ ] 主体一致性（切割机外观没变形？）
   - [ ] 运动流畅性（没有抖动/跳帧？）
   - [ ] 灯光一致性（没有忽明忽暗？）
   - [ ] 材料真实感（皮革/布料看起来真实？）
   - [ ] 无 AI 痕迹（没有诡异的手指/文字？）
5. **不过关就重新生成，绝不凑合**

### 11:00 — 配乐（10 分钟）
1. 打开 musicfx.google.com
2. 输入风格描述：
```
Energetic industrial electronic music, steady precise mechanical beat, 
cinematic build-up, modern factory atmosphere, 30 seconds
```
3. 生成 3-4 个版本，试听选最佳
4. 下载 WAV 格式

### 11:30 — 合成（OpenClaw 自动化）
告诉我"合成视频"，我会用 ffmpeg 自动执行：
- 拼接多个镜头片段（带转场）
- 混入配乐（音量自动调节）
- 添加字幕（中英双语）
- 添加红太阳 Logo 水印
- 输出两个版本：9:16 竖屏（抖音）+ 16:9 横屏（YouTube）

### 12:00 — 终审（最重要的环节）
**逐帧检查**：
- [ ] 开头 3 秒是否有冲击力？（决定完播率）
- [ ] 画面质量是否达到"客户看了想下单"的水准？
- [ ] 转场是否自然？
- [ ] 配乐节奏是否匹配画面？
- [ ] 字幕是否准确？
- [ ] 整体是否有 AI 感？（有就打回重做）

**不过关就打回重做对应环节，不发布半成品。**

### 18:00-20:00 — 发布
- 抖音：18:00（晚高峰）
- YouTube：20:00（海外时区友好）

## 四、质量红线（不可逾越）

1. **每条视频至少生成 3 个版本，选最好的 1 个**
2. **AI 痕迹明显的素材直接废弃，不修不补**
3. **宁可当天只发 1 条高质量的，也不发 3 条凑数的**
4. **每周复盘：哪条视频数据最好？为什么？提炼规律迭代提示词**
