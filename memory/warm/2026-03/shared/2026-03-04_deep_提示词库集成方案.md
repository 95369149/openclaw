## 一、调研结果

### 1.1 opennana.com
- **定位**: Nano Banana Pro 提示词图库平台
- **内容**: 540+ AI 图片生成提示词案例
- **结构**: 图库展示 + prompt 复制功能
- **访问限制**: 网络层面无法直接访问（DNS/IP 解析被阻断）

### 1.2 youmind.com
- **定位**: AI 创作代理平台，提供多模态提示词库
- **内容覆盖**:
  - Nano Banana Pro Prompts（图片生成）
  - Seedance 2.0 Prompts（视频生成，数百条带在线预览）
  - Gemini 3 Pro Prompts（多模态内容生成）
- **特点**: 
  - 每日更新，AI 智能推荐
  - 多语言搜索支持
  - 已有 GitHub 开源 skill（nano-banana-pro-prompts-recommend-skill）
- **访问限制**: 同样无法直接访问

### 1.3 替代方案
由于两个平台均无法直接访问，建议采用以下策略：
1. **本地提示词库**: 从 CSDN、知乎等可访问平台收集短视频脚本提示词模板
2. **结构化模板**: 基于行业最佳实践构建标准化提示词框架
3. **动态扩展**: 预留接口，未来可接入 API 或爬虫同步外部库

## 二、集成方案设计

### 2.1 核心思路
将提示词库以 **JSON 配置文件** 形式嵌入 video-content skill，通过 **模板引擎** 动态生成脚本。

### 2.2 架构设计
```
/Users/apple/.openclaw/skills/video-content/
├── SKILL.md                    # 主 skill 文档
├── prompts/
│   ├── templates.json          # 提示词模板库
│   ├── hooks.json              # 钩子句式库
│   ├── structures.json         # 脚本结构模板
│   └── examples.json           # 优秀案例库
└── scripts/
    └── generate.js             # 脚本生成逻辑（可选）
```

## 三、实现步骤

### Step 1: 创建提示词库文件（30 分钟）
```bash
mkdir -p /Users/apple/.openclaw/skills/video-content/prompts
# 创建 templates.json、hooks.json、structures.json
```

### Step 2: 修改 SKILL.md，集成调用逻辑（20 分钟）
在 SKILL.md 中添加：
```markdown
## 使用提示词库

当用户请求生成脚本时：
1. 读取 prompts/templates.json
2. 根据内容类型（A/B/C/D）匹配对应模板
3. 填充产品参数（从 HTYCNC 产品库获取）
4. 生成完整脚本

示例调用：
/video 产品展示 HTYCNC-3000 激光切割
→ 自动匹配"产品展示"类钩子 + 解决方案模板
```

- 从 CSDN 文章提取 20+ 短视频脚本结构
- 整理 HTYCNC 产品特性（速度、精度、材料适配）
- 编写 50+ 钩子句式、30+ CTA 话术

### Step 4: 测试与优化（30 分钟）
```bash

```

### Step 5: 文档化与交付（20 分钟）

## 四、效果评估

### 4.1 生产效率提升
- **当前**: 厂长手动构思脚本，每条耗时 30-60 分钟
- **集成后**: 选择类型 + 填参数，5 分钟生成初稿
- **提升**: **生产效率提升 6-12 倍**

### 4.2 内容质量保障
- **结构化模板**: 确保每条脚本符合"钩子-痛点-方案-证据-CTA"黄金公式
- **行业案例库**: 避免从零开始，基于验证过的爆款结构
- **一致性**: 品牌调性统一，降低试错成本

### 4.3 可扩展性
- **模块化设计**: 新增类别只需编辑 JSON，无需改代码
- **未来接入**: 预留 API 接口，可对接 youmind.com 或自建爬虫
- **数据驱动**: 记录生成脚本的播放数据，反哺模板优化

### 4.4 降低门槛
- **零提示词经验**: 厂长无需学习 prompt 工程，选择即可用
- **快速迭代**: A/B 测试不同钩子，快速找到爆款公式
- **团队协作**: 其他成员也能快速上手生产内容
