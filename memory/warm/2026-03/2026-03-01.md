# 2026-03-01 工作日志

## 重大修复：xjrouter 代理乱码根因

### 问题
kitt 通过 xjrouter 调用 exec 等工具时，返回乱码/源码，导致整个会话上下文被污染，后续所有回复都变成工具调用源码。

### 根因
xjrouter_proxy.py（自写 Python 反向代理）有两个致命 bug：
1. **第 166 行删除了 tools/tool_choice/parallel_tool_calls** — 模型收不到工具定义，只能把工具调用意图以文本形式输出
2. **_aggregate_sse 只处理 content 和 reasoning_content** — 完全没处理 tool_calls 字段，工具调用响应被丢弃

### 修复
用 CLIProxyAPI v6.8.35（Go 二进制）替代自写 Python 代理：
- 原生支持 tools/function calling
- 原生支持 SSE 流式 tool_calls 聚合
- launchd plist 已更新指向 CLIProxyAPI
- 安装路径：~/cli-proxy/cli-proxy-api
- 配置：~/cli-proxy/config.yaml
- 端口不变：127.0.0.1:8444
- OpenClaw 配置无需改动

### 旧代理也修了（备用）
xjrouter_proxy.py 也做了修复（保留 tools 透传 + tool_calls 聚合），但不再使用。
