## 2026-03-12 周四 · 早间推送

### 第一部分：大明历史人物典故

**📜 戚继光练兵**

戚继光在浙江抗倭时，发现官兵战力不行，根源在于"吃空饷、混日子、临阵脱逃"。他重新招募矿工、农民组建戚家军，立下铁规：
1. 每日操练必须达标，不达标扣饷
2. 战场立功重赏，临阵脱逃斩首
3. 将领必须身先士卒，不能躲后方
4. 建立"鸳鸯阵"战法，11人一队，互相配合，责任到人

结果：戚家军从乌合之众变成精锐之师，13年间大小80余战全胜，倭寇闻风丧胆。

**📖 白话讲解**

戚继光看透了一个道理：队伍不行，不是人不行，是机制不行。他不靠喊口号，而是靠三招：
1. 标准清晰（操练达标线明确）
2. 奖惩分明（立功重赏，逃跑必斩）
3. 责任到人（11人小队，谁掉链子一目了然）

**💡 管理感悟**

红太阳60人团队，30个销售、23个生产、7个管理，最怕的就是"看着忙，实际乱"。戚继光的练兵法，直接对应红太阳的九大机制：

1. **【早启动】= 每日操练达标**  
   晨会不是走过场，而是当天目标必须清晰：销售今天跟进哪几个客户、生产今天交付哪几台设备、管理今天解决哪几个卡点。不达标不散会。

2. **【军令状】= 战场立功重赏**  
   接了订单就是接了军令状，交期、质量、回款，各自签字承诺。完成了上【红榜】重奖，完不成上【黑榜】扣绩效，不讲情面。

3. **【师徒制】= 将领身先士卒**  
   师傅不能只动嘴，必须带着徒弟干。销售师傅带徒弟跑客户，生产师傅带徒弟调设备，管理层带头加班攻坚。

4. **【PK制】= 鸳鸯阵责任到人**  
   销售组、生产组内部PK，不是比谁嗓门大，而是比谁签单多、谁交付快、谁质量好。小组内互相配合，谁掉链子全组受影响，逼着大家抱团。

戚继光用13年打出戚家军，红太阳用九大机制打造铁军团队，道理是一样的：**机制清晰、奖惩分明、责任到人，队伍自然就硬了。**
