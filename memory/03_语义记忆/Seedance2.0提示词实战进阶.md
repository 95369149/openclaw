# 语义记忆：Seedance 2.0 提示词实战进阶

## 核心认知升级：从"描述"到"导演"

Seedance 2.0 的提示词不再是简单的文本描述，而是**导演指令**。大神们已经总结出从基础到高级的完整方法论。

## 大神级提示词公式（万能公式）

### 九维结构
```
主题 + 动作 + 场景 + 光照 + 相机语言 + 风格 + 质量 + 约束
```

### 实战模板示例
```
年轻女孩在海边缓慢行走，海风轻拂头发，对镜头自然微笑，黄昏暖光，4K高清，电影感，稳定相机运动，画面流畅不抖动，细节清晰。
```

## 动作描述的核心技巧（Seedance 最爱）

### 黄金词汇
- **优先使用**：缓慢、轻柔、连续、自然、流畅、不僵硬
- **避免使用**：夸张、高速、复杂多人互动、大幅变形

### 动作组合范例
- 缓慢转身、轻轻抬手、轻盈步伐、微微低头、随风摇曳
- 相机缓慢推进、轻微轨道环绕、稳定跟随

## 相机与运动（瞬间提升电影感）

### 专业术语体系
- **镜头尺寸**：特写 / 中景 / 全景 / 极特写
- **运动术语**：推进 / 拉出 / 横移 / 轨道环绕
- **稳定性关键词**：固定镜头、手持稳定、无抖动、丝滑流畅

### 实战示例
```
中景，缓慢推进，稳定跟随，丝滑流畅画面不卡顿
```

## 人物稳定性（防脸变、防变形）

### 关键约束词
- 清晰五官、稳定脸部、不变形、不扭曲
- 正常人体结构、自然比例、动作不僵硬
- 同一人物、服装一致、发型不变

### 实战示例
```
人物脸部稳定不变形，正常人体结构，动作自然流畅
```

## 图像质量（必须添加，提升清晰度）

### 万能质量词（一键复制）
```
4K、超高清、细节丰富、清晰锐利、电影质感、自然色彩、柔和光线、不模糊、不重影、不闪烁、画面稳定
```

## 风格与氛围（快速出片）

### 主题风格词库
- **日常/Vlog**：治愈清新、文艺美学、日系清新、韩式氛围
- **科幻/大片**：赛博朋克、暗黑高级、复古胶片、梦幻柔光
- **极简主义**：简约干净、高级质感、写实摄影

## 多镜头/故事板写作（Seedance 2.0 强项）

### 叙事式描述
```
从脸部特写开始，缓慢拉出到全景，人物缓慢行走，相机稳定跟随，以定格微笑结束
```

## 坑点指南（永远不要写这些）

### 四大雷区
1. **复杂多人互动**：如打斗、握手、拥抱等，容易剪辑
2. **模糊词汇**：如"不错"、"漂亮"、"酷"，AI难以理解主观词
3. **矛盾要求**：如"超高速奔跑"同时要求"极其稳定不模糊"
4. **敏感内容**：成人、暴力、危险动作、版权人物

## 高级技巧：大神级经验总结

### 1. 动作连续性原则
- **每个镜头一个动词**：保持干净简洁
- **复合动作分解**："开始：缓慢推进。然后：最后2秒轻柔右摇"
- **时间顺序**：按时间顺序描述动作序列

### 2. 音频提示词技巧
- **触发原生音频引擎**：使用"混响"、"闷声"、"高音调"等词汇
- **具体音效描述**："硬币的金属叮当声"会生成特定尖锐声音

### 3. 参考系统高级用法
- **故事板上传**：创建简单故事板图像，上传为@image1
- **多文件组合**：最多9张图像+3个视频+3个音频文件
- **标签引用**：使用@Image1、@Video1、@Audio1精确控制

## 进阶：分镜脚本级提示词（2026-02-18 补充）

来源：@Adam也叫吉米 实战验证

### 核心认知
九维公式是"填表式"，分镜脚本级是"导演手记式"。后者更接近真实影视工业流程，Seedance 2.0 对这种结构的理解力极强。

### 五章节结构
提示词不再是一段话，而是分成5个独立章节，每个章节用 `### 标题` 分隔：

```
### 视觉风格
画幅比例 + 分辨率 + 光影风格 + 色调 + 对比度 + 质感定义

### 场景叙述
环境描述 + 主体外观 + 服装细节 + 动作概述 + 整体氛围关键词

### 摄影技术
摄影机运动（固定/跟随/手持）+ 镜头焦段+光圈 + 灯光方案（方向/硬软/投射区域）+ 情绪关键词

### 动作清单
- 动作1：具体肢体描述 + 配合的身体部位
- 动作2：流畅过渡描述
- 动作3：细节（头发/眼神/表情）
- 动作4：与节拍的关系（卡点/定格）

### 背景声音
音乐风格 + BPM/节奏特征 + 音效 + 混音方案（声场位置/频率重点/视听同步要求）
```

### 关键差异（vs 九维公式）
1. **动作清单独立成章**：不是笼统说"跳舞"，而是拆成4-6个具体动作序列，每个动作描述肢体+配合+过渡
2. **摄影技术写到焦段级**：50mm f/2.8 比"中景"精确10倍
3. **灯光方案写到方向级**：单侧硬光+投射区域，不是"柔和光线"
4. **音画同步显式声明**：在背景声音章节直接写"视觉动作与听觉节奏严格卡点同步"

```
16:9 横屏构图，4K 超清写实画质。工业纪录片光影风格，中性色调。

### 场景叙述

[型号] 数控切割机正在精密切割 [材料]，整体氛围展现专业与可靠。

### 摄影技术

### 动作清单
- 设备启动，控制面板指示灯依次亮起

- 拉远到全景，操作员检查成品，点头满意

### 背景声音
音乐：低沉有力的工业电子配乐，节奏稳定。
音效：设备启动声、切割金属声、火花声。
混音：音效声场靠前突出真实感，音乐作为底层氛围支撑。
```

## 核心总结

Seedance 2.0 提示词技术已形成三个层级：
1. **入门**：万能公式（主题+动作+场景+风格）— 快速出片
2. **进阶**：九维结构 — 系统化控制每个维度
3. **专业**：分镜脚本级（五章节结构）— 影视工业级精确控制

关键原则：Seedance 2.0 越像收到一份专业分镜脚本，输出质量越高。
