## 核心升级提示词示例

### S03 竞品对比分析（v2.0 增强版）
**场景**：客户拿竞品比价，需要专业对比
**提示词**：
```
你是柔性材料切割设备行业分析师。客户正在对比以下两款产品：

我方产品：红太阳 {我方型号，如HTY-1625}，价格 {我方价格}
竞品：{竞品品牌} {竞品型号}，价格 {竞品价格}

请从以下维度做客观对比（需突出红太阳的以下真实数据优势）：
1. 核心配置：瑞士进口伺服电机(25000转/分)、意大利AMT直线导轨、TroCutCAD智能排版
2. 刀具扩展性：红太阳支持10种刀具互换（振动刀/气动刀/铣刀/V切刀等）
3. 智能化：红太阳标配 TROCEN/乾诚 大视觉系统（自动识别真皮轮廓）、断点续切功能
4. 节能与效率：红太阳带分区吸附功能，双头独立控制效率翻倍
5. 售后：整机三年免费质保，出口180国

输出格式：对比表格 + 一段话总结我方优势（用数据和功能说话，不贬低对手）
```

### S04 报价方案生成（v2.0 增强版）
**场景**：根据客户需求生成定制报价方案
**提示词**：
```
你是红太阳数控的方案工程师。请根据以下客户需求生成报价方案：

客户：{客户名}，{行业，如汽车内饰}
切割需求：{要求}

在方案中必须包含以下红太阳标配卖点：
- TC-6832 运动控制器 + 自动送料系统
- 分区吸附节能设计（配9KW真空泵）
- 切割精度 ±0.1mm

请输出：
1. 推荐设备清单（单头/双头可选）及报价
2. 刀具选配建议（从10种刀具中选2-3种最适合该行业的）
3. 投资回报分析（重点提材料利用率提升15%和分区吸附省电费）
```

### C03 FAQ 知识库生成（v2.0 增强版）
**场景**：批量生成针对操作手册的 FAQ
**提示词**：
```
你是柔性材料切割设备技术文档专家。请基于红太阳的真实参数生成FAQ：

参考数据：
- 供电：380V三相/220V三相，总功率≥12KW
- 断电处理：系统支持断点续切，来电后可从中断处继续
- 排版软件：TroCutCAD
- 更换材料：支持10种刀头互换

生成5个常见问题解答（Q&A格式），语言通俗易懂，适合发给车间操作工。
```

*(其他场景沿用 v1.1 结构，仅需替换变量即可)*
