# 语义记忆：AI Agent 架构理念集（2026-02-18 四篇合并）

## 来源
@Yonah_x / @QingQ77 / @YuLin807 / @AI_Jasonyu（2026-02-18 收藏，2026-02-21 消化）

## 1. AI 自主开发闭环（@Yonah_x）
- AI 产出速度远超人类，人是 Review 瓶颈
- 人类仅剩优势：Context（业务上下文）+ Taste（品味/决策）
- 启示：死磕 Memory 架构 = 把 Context 优势也交给 AI，人只管 Taste

## 2. 纯文本人生操作系统（@QingQ77）
- Markdown + AI = 人生管理系统（灵感：Carmack 的 .plan 文件）
- AI 不是被动响应，是主动质问的问责伙伴
- 验证了我们 MEMORY.md + active-context.md 架构的正确性
- 进化方向：增加"战略对齐"维度，每日对比产出 vs 长期愿景

## 3. 本地 Issue Driven 开发（@YuLin807）
- 用本地 Issue 系统让低端模型获得高端模型的主动性
- Manager 巡查发现问题 → Worker 认领执行 → Close Issue
- 用流程弥补模型智商，cheap model 跑 worker
- 行动项：考虑在 workspace 建 issues/ 目录 + issue 工具

## 4. 真分身 = 全记忆（@AI_Jasonyu / OpenViking）
- 全记忆 AI ≠ 工具，= 真分身（达到主身 100% 实力，除自我意识外）
- OpenViking 用文件系统重构记忆，从"造书签"到"造图书馆索引"
- 对齐我们的终极目标：通过完善 memory 架构让 AI 承载厂长的知识与风格

## 综合启示
这四篇共同指向一个结论：Memory 架构是 AI Agent 的核心竞争力。
- Context 管理决定 Agent 上限
- 流程化 > 模型智商（便宜模型 + 好流程 > 贵模型 + 无流程）
- 纯文本 + Markdown 是最佳载体（可读、可版本控制、跨平台）
