# Claude Skill 幻灯片制作实战 — @wshuyi 踩坑总结

> 作者：王树义 @wshuyi（天津高校教师，2.3万粉）
> 日期：2026-02-18

## 核心方法论

### 1. 从已有 Skill 解耦新功能
- 原有：论文→幻灯片→配音→视频（完整 Skill）
- 解耦：只要幻灯片部分，独立成新 Skill
- 两轮对话就出第一版，端到端生成 12 页 Reveal.js 幻灯片
- 含 SVG 矢量图表、分步动画、演讲者备注、中文排版

### 2. 子 Agent 自动质检
- Claude Code 分派子 agent 审校产出
- 无显式提示下自动打分：7.6 → 9.0（多轮迭代）
- 踩坑教训自动总结写回 Skill = 可累积的知识资产

### 3. 金句：改规则，不改产出物
- 换主题时翻车：语言变英文、文字溢出、对比度不够、SVG 颜色一刀切
- 错误做法：直接改生成好的 HTML（刮焦层）
- 正确做法：改 Skill 规则（调烤箱温度）
- 本质：修上游规则，而非补下游产出

### 4. 踩坑清单（换主题时）
- 语言规则写太深，生成到一半就忘了 → 规则要放显眼位置
- 动画参数和主题耦合 → 需要主题无关的尺寸约束
- 对比度不够 → 需要 WCAG 对比度检查规则
- SVG 内文字颜色一刀切 → 需要"色块内文字保持白色"的例外规则

## 对 Kitt 的启发
- "改规则不改产出" = 我们自我迭代八步法的核心
- 子 agent 自动打分 = 我们可以在学习任务中加质检环节
- Reveal.js 方案可移植为 OpenClaw Skill（待实施）
- 适用场景：厂长培训材料自动化（九大机制之培训机制）
