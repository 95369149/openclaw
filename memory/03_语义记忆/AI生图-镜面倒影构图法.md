# 语义记忆：AI 生图 - 镜面倒影构图法

## 来源
VoxCat（2026-02-20 收藏消化）

## 核心公式
镜面倒影 = 镜面载体 + 分割线位置 + 反射级别(L1-L4) + 虚实差异

## 四级反射系统
- L1 完美镜面：`mirror-like reflection, perfect symmetry`
- L2 清晰倒影：`clear reflection, wet-look polished surface`
- L3 模糊倒影：`soft blurred reflection, subtle ripples`
- L4 碎片倒影：`fragmented reflection, broken surface`

## 进阶技巧提示词
- 色温分离：`reflection with cooler color temperature shift`
- 焦平面分离：`Sharp focus on real subject, reflection slightly soft-focus`
- 涟漪叙事：`a single water drop creating ripple rings in the reflection`
- 低机位：`Camera angle at ground level, nearly touching the reflective surface`

## 避坑
- 倒影面积至少占画面 30%
- 必须加虚实差异，否则 AI 当图片翻转
- 分割线保持干净连贯
- 必须指定 L1-L4，不写就随机
