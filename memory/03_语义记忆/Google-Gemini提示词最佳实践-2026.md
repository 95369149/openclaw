# Google Gemini 提示词最佳实践（2026）

> 学习日期：2026-02-19 | 来源：Google官方文档 + PromptBuilder Gemini 3 Playbook + 2026最佳实践汇总

## 一、Gemini 3 核心变化（vs 2.x）

Gemini 3（2025年11月发布）在指令遵循上大幅提升，直接影响提示词写法：

1. **短指令即可**：2.x 需要大量护栏防漂移，3.0 一句话就能锁定
2. **结构自推断**：给最小格式提示（如"Return as JSON"），模型自动推断 schema
3. **多轮记忆增强**：不需要每轮重复约束，模型能跨轮次保持上下文
4. **多模态原生**：图片/视频/音频直接处理，无需复杂预处理指令

## 二、Gemini 专属提示词模板

### 2.1 极简三行模板（Gemini 3 推荐）
```
TASK: {{一句话目标}}
INPUT: {{输入类型：文本/图片/视频}}
OUTPUT: {{格式 + 关键约束}}
```

### 2.2 对比：2.x 风格 vs 3.0 风格

| 场景 | 2.x 写法 | 3.0 写法 |
|------|----------|----------|
| 摘要 | "仔细阅读论文，提取3个要点，每个不超过20字，不加解释，只输出要点" | "总结关键发现，3条，每条≤20字" |
| 数据提取 | 详细列出字段+JSON schema示例+语法规则 | "从标签提取产品名、成分、营养值，返回JSON" |
| 代码生成 | 指定函数名+参数+返回值+docstring+类型提示+Python版本 | "写 calculate_discount(price, discount_percent) → float，含docstring和类型提示" |

### 2.3 多模态提示词技巧
- **图片**：直接说"the image"，多图时才编号；问具体问题比"分析这个"好
- **视频**：Gemini 3 Pro 支持最长2小时；用时间戳提问："总结5:30到8:00的事件"
- **音频**：适合会议/通话；"总结音频中提出的主要反对意见"

## 三、Gemini vs Claude vs ChatGPT 提示词差异

| 维度 | Gemini | Claude | ChatGPT |
|------|--------|--------|---------|
| 指令风格 | 清晰极简 | 契约式（角色+目标+约束） | 显式格式+约束 |
| 多模态 | 最强（视频+长上下文） | 文档+审查 | 图片+结构化 |
| 默认语气 | 中性、事实导向 | 深思、偏长 | 略口语化 |
| 最佳场景 | 分析、提取、多模态 | 长文推理、评审 | 代码、结构化任务 |

**Kitt 实操建议**：
- 给 Gemini 写提示词时，砍掉所有"显而易见"的规则
- Claude 需要 XML 标签和契约式结构
- 三者通用：成功标准 + 输出契约 + 自检清单

## 四、2026 通用提示词工程清单（适用所有模型）

来自 PromptBuilder 2026 最佳实践：

1. **成功标准**：定义"完成"长什么样（可测试的）
2. **输出契约**：格式、长度、语气、必含章节
3. **约束**：范围、假设、排除项、不确定时怎么办
4. **输入**：最小必要上下文 + 必须使用的数据
5. **示例**：格式/风格重要时给1-3个示例
6. **验证**：自检清单捕捉常见失败
7. **迭代**：置信度低时要求澄清或给备选方案

### 4.1 四区块布局（4-Block Layout）
```
## INSTRUCTIONS
{{做什么}}

## INPUTS
{{数据/文档/上下文}}

## CONSTRAINTS
{{范围、排除、不确定规则}}

## OUTPUT FORMAT
{{契约/schema}}
```

### 4.2 自检区块（所有模型通用）
```
完成前验证：
☐ 输出严格匹配请求格式
☐ 所有成功标准已满足
☐ 无输入支撑的声明标注 [不确定]
☐ 下一步具体可执行
```

## 五、反模式（2026年仍常见的坑）

1. **关键词堆砌**：一堆指令没有优先级
2. **隐藏约束**：期望特定长度/格式但不说
3. **上下文倾倒**：大量输入但不指明"什么最重要"
4. **一次性发布**：无自检、无评分、无迭代
5. **目标冲突**：同时要求"简短"和"全面"

## 六、Gemini 参数调优

- **Temperature**：推理任务设0.2，创意任务设1.0-1.5
- **输出长度**：按需设置，短输出=快响应+省token
- **上下文缓存**：重复前缀用 context caching 省钱
- **定价参考**：Pro $0.60/1M输入 | Flash $0.10/1M输入
