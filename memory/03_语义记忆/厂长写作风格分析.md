# 语义记忆：厂长写作风格分析

## 样本来源
1. 公司大会演讲稿（精心准备版）
2. 九大机制分享（语音转文字，即兴版）

## 核心风格特征

### 语言混搭（最大特色）
- 文言 + 白话自由切换："与有荣焉""寥若晨星" ↔ "不带脑子的坚持"
- 古典引用 + 流行文化：王阳明知行合一 + 李阳疯狂英语 + 陈平安（剑来）
- 不是掉书袋，是信手拈来，用得自然

### 结构方式
- 喜欢用"X字真言""X大机制"这种数字框架
- 每个点用一个关键词领起（选择、行动、坚持）
- 展开方式自由，不拘泥于格式

### 情感表达
- 真诚不装：敢说激动、紧张、怕
- 自嘲拉近距离："我怕讲不好""我怕举止不够优雅"
- 点名具体的人，不说空话
- 对团队有真感情，不是表演

### 句式偏好
- 金句收尾，短句有力："想都是问题，做才能有答案"
- 喜欢对仗/排比但不刻意
- 反问句推进节奏

### 禁忌（从样本反推）
- 不用企业咨询式废话（赋能、闭环、抓手）
- 不用学术腔
- 不用"首先其次最后"的死板结构
- 不说正确的废话

### 即兴 vs 准备
- 准备版：金句密度高，结构清晰，文言比例高
- 即兴版：更口语化，思维跳跃，但核心逻辑在
- 两种模式都有"江湖气"底色

## 风格标签
江湖气 + 书卷气 + 真诚 + 霸气 + 接地气
