## 背景
Seedance 2.0 加强审查，大量提示词被拒，不告知违禁原因。

## 核心策略：电影剧本式提示词
用专业影视剧本格式表达创意意图：
- 按时间轴分幕（0-2秒、2-4秒...）
- 每幕：剧情描述 + 镜头设计 + 音频设计
- 专业术语：中景、特写、慢镜头、硬切、仰拍、俯拍
- 色彩/光线/风格极其具体
- 人物设定独立成段，锁定外观

## 结构模板
```
影片类型与形式 → 场景设定 → 出场人物 → 正文剧情(分幕) → 结尾设计 → 制作建议
```

## 关键技巧
1. 30秒拆两段15秒，每段独立可看
2. 每段开头声明锁定角色外观
3. 不同场景用不同色彩基调
4. 动作最高点切黑，制造悬念
5. 用 Claude 写剧本 → Seedance 生成（可自动化）
