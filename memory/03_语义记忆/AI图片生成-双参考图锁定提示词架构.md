## 核心创新：双参考图机制

这是目前见过的最严格的AI图片生成提示词架构，核心思路是**两张参考图各司其职**：

| 参考图 | 职责 | 锁定内容 |
|--------|------|----------|
| 参考图1 | 人物锁定 | 脸型、五官、年龄、体型、肤色、发型（相似度>95%） |
| 参考图2 | 风格DNA锁定 | 构图、纹理、色彩、灯光、图形元素、氛围 |

**关键洞察**：把"人物还原"和"风格迁移"彻底分离，避免AI在风格化过程中丢失人脸特征。

## 15模块完整架构

这套提示词分15个模块，形成完整的创作指南：

### 模块清单
1. **风格概述** - 风格命名、编号、类型、核心美学定义
2. **核心特征** - 关键元素清单（✅必选）+ 氛围定位 + 色彩方案
3. **核心指令** - 四大核心要求（人物还原/气质转化/风格DNA/创意空间）
4. **人物样貌还原** - 绝对原则 + 绝对禁止 + 验证标准
5. **表情与气质** - 情绪关键词 + 眼神/嘴部/整体面部细节指令
6. **核心姿态** - 标志性姿态定义 + 头部位置 + 画面占比
7. **造型设计** - 服装/配饰/发型处理
8. **构图设计** - 拍摄角度/裁剪范围/人物位置/焦点控制/景深
9. **背景设计** - 颜色（含色号）+ 纹理 + 印刷质感
10. **核心技术处理** - 纹理技法详解（如点刻/半色调的密度-明暗映射）
11. **灯光设计** - 光源设定 + 照明效果 + 对比度参数
12. **色彩方案** - 主色调（含色号）+ 重点色 + 肤色处理 + 色彩心理
13. **图形元素** - 必选/可选图形元素详细规格
14. **质感与后期** - 纹理处理 + 材质质感 + 整体后期风格
15. **执行检查清单** - 拍摄阶段/后期处理/最终验收三段式checklist

## 可复用的提示词技巧

### 1. ✅/❌ 正负约束对
每个模块都用 ✅（必须做）和 ❌（绝对禁止）明确边界：
```
✅ 绝对原则：100%还原参考图1
❌ 绝对禁止：不得改变参考图1任何特征
```

### 2. 量化验证标准
不说"像"，给具体数字：
- 面部相似度 > 95%
- 阴影占比 90% + 高光占比 10%
- 饱和度 5-20%
- 对比度 90-98%

### 3. 色号精确锁定
不说"米白色"，给色号范围：
- 米白：#F5F5DC - #FFFACD
- 纯黑：#000000 - #1A1A1A
- 红色：#DC143C - #FF0000

### 4. 密度-效果映射表
用物理量描述视觉效果：
- 点密集 = 深色/阴影
- 点稀疏 = 浅色/高光
- 点大小：0.5-2mm
- 阴影区：点几乎重叠 → 纯黑
- 高光区：点间隔明显 → 露出底色

### 5. 情绪关键词矩阵
不说"看起来悲伤"，用具体的情绪词组：
```
"身份碎片化" / "记忆创伤" / "心理破碎" / "幽闭恐惧" / "复仇的执念"
```

### 6. 功能性注释
每个图形元素都标注"作用"，告诉AI为什么要这样做：
```
竖排文本柱 → 作用：增加层次感、形成视觉包围、幽闭感、象征"记忆碎片"
红色"O" → 作用：代表"OLDBOY"、红色视觉锚点、暴力象征
```

### 7. 对比表收尾
用表格做最终整合，让AI一目了然：
```
| 维度 | 参考图1 | 参考图2 | 整合策略 |
| 样貌 | 完全保留 | 不适用 | 100%还原 |
| 构图 | 原始 | 极端特写 | 极端面部特写 |
```
