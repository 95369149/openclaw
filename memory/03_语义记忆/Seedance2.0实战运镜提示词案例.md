1. 先用图片提示词生成电影级剧照（起始帧）
2. 再用 Seedance 运镜词从静态图驱动视频生成

## 实战案例：末日追逃 + 变形金刚

### 图片提示词（生成起始帧）
```
电影剧照，一辆布满尘土与划痕的野马车，在旧金山金门大桥上极速狂飙。
黄昏时分的橙紫色天空与旧金山湾海面在背景铺展，远处是旧金山市区的天际线。
轮胎摩擦地面迸溅火星，车身在狂风中剧烈颤，碎片与尘土在车尾翻涌。
驾驶位上的男人眼神坚毅，脸上布满伤痕，紧握方向盘在车流中穿梭。
镜头采用手持摄影风格，动态模糊与强烈的临场感交织，暖橙与冷蓝的色调碰撞，极具压迫感。
画面充满好莱坞动作大片的紧张与刺激，每一帧都充满震撼的视觉冲击力，完美还原了末日追逃的磅礴与绝望。
```

### 运镜词（驱动视频）
```
一镜到底，镜头拉远点，一辆汽车在桥面极速狂飙，轮胎摩擦地面迸溅火星，车身在狂风中剧烈震颤。
突然，高冷峻的巨型变形金刚，金属骨骼在余晖下泛着冷冽光泽，面部由破碎的挡风玻璃凝合而成，眼神如淬火的钢铁般锐利。
它单膝跪地稳住身形，背部装甲展开，露出一门能量炮，凝聚出幽蓝的等离子能量。
变形金刚变形行走，同时能量炮迸发出一道毁灭性的蓝色光束，精准击穿大桥，
瞬间引发剧烈爆炸，火光与金属碎片炸开，周围车辆在烈焰中扭曲解体。
手持摄影风格，镜头紧贴变形金刚，冷暗色调与金属质感交织，极具震撼视觉冲击力。
```

## 可复用技巧提炼

### 1. 图片prompt定位"电影剧照"
- 不说"照片"或"图片"，说"电影剧照" → 直接拉高画面质感和构图水准

### 2. 运镜词开头锁镜头语言
- "一镜到底" → 连贯不切
- "镜头拉远点" → 给AI明确的景别指令

### 3. 叙事层层递进
- 汽车狂飙（建立场景）→ 变形金刚出场（引入冲突）→ 能量炮发射（高潮）→ 大桥爆炸（结局）
- 每一步都有动作描写，不是静态描述

### 4. 收尾锁风格
- "手持摄影风格 + 冷暗色调 + 金属质感" → 确保AI不跑偏

### 5. 色调碰撞技巧
- 暖橙 vs 冷蓝（图片prompt）
- 冷暗色调 + 金属质感（运镜词）
- 用色彩对比制造视觉张力
