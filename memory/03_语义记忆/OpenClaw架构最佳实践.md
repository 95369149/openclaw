# 语义记忆：OpenClaw Agent 架构最佳实践

来源：3篇文章综合（Paolo Perazzo / Skywork / Shawn Harris，2026-02）

## 四层架构（Paolo）
1. 通信层（Gateway）— 多渠道消息标准化
2. 推理层 — LLM + mega prompt 动态融合指令/数据/状态
3. 记忆系统 — 文件式持久化
4. 技能执行层 — Markdown 定义 Skill，执行脚本/API

## 规划器-执行器模式（Skywork）
- 规划器：生成可验证步骤
- 执行器：单步执行 + 持久化证据
- 每步工具调用前先记录输入/输出（证据优先）
- JSONL 日志实现会话确定性回放

## 三层认知记忆（Shawn Harris，最有价值）
| 层级 | 文件 | 内容 | 更新频率 |
|------|------|------|----------|
| 战略 | MEMORY.md | 身份、长期策略、经验教训 | 低频 |
| 操作 | active-context.md | 当前项目、截止日期、承诺 | 每次重要会话 |
| 战术 | YYYY-MM-DD.md | 每日事件、原始笔记 | 每天 |

## 门控机制（省 token 关键）
- 不是全部加载，而是按相关性选择性检索
- 只存储与当前任务高度相关的信息
- 减少上下文膨胀

## 意图路由（省钱关键）
- 根据意图/复杂度选模型：复杂→Opus，简单→轻量模型
- 安全相关任务强制用最强模型

## Runbook 概念
- 将多步骤操作封装成操作手册
- 模型切换/重置后仍能执行复杂任务
- 相当于"程序记忆"

## 记忆优先级与自动化（Jason Zuo 实战II，2026-02-17）

### P0/P1/P2 优先级标签
| 级别 | 含义 | 过期策略 |
|------|------|----------|
| P0 | 核心身份/偏好/重大教训 | 永不过期 |
| P1 | 活跃项目/近期决策 | 90天后归档 |
| P2 | 临时信息/试验记录 | 30天后归档 |

### memory-janitor 自动清理
- 每天凌晨跑一次，扫描 MEMORY.md
- P1 超 90 天 → `memory/archive/`
- P2 超 30 天 → `memory/archive/`
- P0 永不动
- MEMORY.md 自动保持精简

### 知识复利自动化
- 每天检查昨天日志，自动提炼核心洞察（决策/成功方案/失败教训）
- 提炼完标记 `<!-- compounded -->`
- 重要的同步到 MEMORY.md
- 日志是原始素材，insights 是蒸馏后的精华

### 安全隔离
- MEMORY.md 只在主 session（1:1 对话）加载
- 群聊不加载（防泄露个人信息/项目细节）

### Skill = 程序性记忆
- 重复工作流写成 Skill 文件
- 下次匹配到任务自动加载，不用每次解释

### 金句
> AI 的本质是根据已知内容输出概率分布，完善的记忆管理决定了输出的范围和准度。

## TOOLS.md 模式（Cathryn Lavery，2026-02-17）
- 独立文件记录所有工具能力 + 已知限制 + 失败处理方案
- **记"不能做什么"比"能做什么"更重要** — 省无数次重试
- 顶部规则："先查 TOOLS.md 再说不行"
- 每次踩坑写一条规则 = 省 100 次未来纠正

## 纠错循环系统化（Cathryn Lavery）
- "NOT" 清单迭代法：每次 AI 犯错加一条，一个月后行为收敛
- Correction Loop：不只聊天纠正，写进持久化文件永久生效
- "说记住就写文件"：口头承诺无效，必须当场持久化

## 多 Agent 生产系统实战（Eric Siu，2026-02-17）
- 4 专业 Agent + 共享大脑（symlinked directory）
- 34 cron / 71 scripts，$271/月替代 $15K/月团队
- 60% 成本在基础设施（记忆/上下文/反遗忘层），不是 Agent 本身
- 基础设施任务用便宜模型（Opus→Sonnet 省 $30/周）

### 必须防范的 4 类故障
1. **静默失败** — Agent 挂了零告警，必须加健康检查
2. **编造数据** — 先跑脚本→读输出→再汇报，trust nothing
3. **重复推荐** — 14 天去重 + 反馈历史检查
4. **成本失控** — 定期审计，简单任务别用贵模型

### 维护体系（"Elon Algorithm"）
- 月度：质疑每个系统，无情删除，简化幸存者
- 周度：自愈 + 系统清洁工（prune/cost/dedup）
- 规则：建议被忽略 3 周 → 标记删除
- 垃圾回收必须和建设一样自动化
