# Seedance 2.0 提示词方法论 v2（2026-02-21 升级）

来源：全网最新教程整合（CSDN 80+提示词指南、官方59套提示词拆解、redreamality完整Playbook、Multi-Shot教程）

## 核心原则（不变）
Seedance 2.0 有知识、有智能、有导演思维。**写意图，不写细节。**

## 提示词四层体系

### 第1层：一句话出片（简单场景）
直接写意图 + "注意分镜编排"
```
生成一个精美高级的兰州拉面广告，注意分镜编排
```

### 第2层：黄金公式（标准场景）
```
[主体] + [动作] + [场景] + [风格] + [情绪]
```
示例：
```
一个浑身缠绕金色雷电的少年剑士，与恶鬼对峙、拔刀瞬间化作闪电，
夜间古宅、暴雨中、血雾弥漫，日式热血动漫、电影级色彩，紧张刺激高燃
```

### 第3层：模板卡片式（专业场景）
```
Subject: [角色/物体，年龄或材质]
Camera: [景别] + [运动方式] + [角度]，[焦段]
Style: [视觉锚点：胶片/工艺/导演风格]，[灯光]，[色彩处理]
Constraints: [禁止项]，[帧率/节奏]，[时长或节拍]，[一致性要求]
```

### 第4层：分镜脚本级（影视级场景）
五章节结构：视觉风格 → 场景叙述 → 摄影技术 → 动作清单 → 背景声音

## 🆕 六大升级技巧（2026-02 最新）

### 1. 微动作链（最关键升级）
不写概括动作，拆成3-5个微动作序列：
- ❌ "女孩晒衣服"
- ✅ "晒完→从桶里拿出另一件→用力抖一抖衣服"
- ❌ "角色很伤心"
- ✅ "走到镜子前，看着镜子里的自己，沉思了一会突然开始崩溃大叫，抓镜子的动作"
- ❌ "氛围很紧张"
- ✅ "咬牙切齿，眼珠左右滴溜溜乱转，面色窘迫至极"

原理：AI不理解抽象情绪词，但理解可被画面化的动作描写。

### 2. 时间轴写法（秒级精确控制）
按秒数分段描述，模型对每一秒该发生什么都有明确指令：
```
0-3秒：兵马俑面部特写，尘土缓缓飘落
3-8秒：镜头缓慢拉远，露出整个兵马俑坑全景
8-12秒：画面叠化过渡到秦朝宫殿
12-15秒：少年嬴政的背影出现在宫殿台阶上
```

### 3. 正向约束替代负向描述
- ❌ "no blur, no ghosting, no distortion"
- ✅ "Maintain face and clothing consistency, high detail, stable picture, sharp clarity"
用正向描述告诉模型要什么，而不是不要什么。

### 4. 对话直接写入提示词
Seedance 2.0 可直接生成配音，对话直接写：
```
男人嘆著氣說："真拿你没办法！"
```

### 5. 情绪转折弧线
不写单一情绪，写完整的情绪曲线：
```
疲惫→深呼吸→收起负面情绪→变得轻松→被女儿拥抱的温馨
```

### 6. @素材参考的"保留+替换"公式
```
参考@视频1的[你想保留的部分] + 把[你想修改的部分]换成[你要的新内容]
```
示例：
- 参考@视频1的运镜和转场 + 把人物换成@图片1
- 参考@视频1的动作和节奏 + 风格改成水墨画

## 运镜术语速查

| 运镜 | 英文 | 效果 |
|------|------|------|
| 轨道环绕 | Orbital | 围绕主体旋转 |
| 推进 | Dolly-in / Push-in | 靠近主体 |
| 拉远 | Pull-out / Dolly-out | 远离主体 |
| 横移 | Pan L→R / R→L | 水平扫视 |
| 跟随 | Follow / Tracking | 跟着主体移动 |
| 航拍 | Aerial / Drone shot | 高空俯瞰 |
| 手持 | Handheld | 轻微晃动真实感 |
| 固定 | Static / Fixed | 不动 |
| 低角度 | Low-angle | 仰拍，显威严 |
| 鹤臂 | Crane shot | 垂直升降 |

## 多镜头叙事（Multi-Shot）要点

Seedance 2.0 的杀手锏是跨镜头保持角色一致性：
```
Close-up of a woman's determined face as she prepares to run,
then medium shot showing her starting to sprint,
then wide aerial shot following her running through the city streets,
then close-up again showing her reaching the finish line
```

关键：
- 用 "then" 或 "→" 连接不同镜头
- 明确写出每个镜头的景别（close-up / medium / wide）
- 角色描述只在第一个镜头写一次，后续用"她/他"指代
- Seedance 自动保持人脸、服装、体型一致

## 成本优化策略

1. **调试用短时长**：4-5秒（60-80积分），满意后升到15秒
2. **一次生成多变体**：不反复调一个，一次出3-4个选最优
3. **用模板改参数**：不从零开始，成功率80%+

## 人物一致性三层方案

1. **基础**：每次上传同一张人物照作首帧 + 提示词强调"保持脸部和服装一致"
2. **进阶**：第一个视频生成后，截最好的一帧作为后续参考图
3. **高级**：用@语法指定"该图中的人物作为主角"，多个场景串联

## 避坑清单

1. 有常识的领域不要写细节，写意图
2. 不要用抽象情绪词，用可视化动作替代
3. 正向约束 > 负向禁止
4. 每个镜头一个核心动词，保持干净
5. 复杂多人互动（打斗、握手）容易崩，尽量避免
6. 时长设置：复杂叙事用10-15秒，5秒太短会"急不择言"
7. 不上传素材但在提示词里@了 = 无效，模型会忽略
