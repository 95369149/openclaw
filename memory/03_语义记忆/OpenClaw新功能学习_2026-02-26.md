# OpenClaw 新功能学习笔记 — 2026-02-26

> 当前版本：2026.2.25
> 学习范围：2026.2.15 ~ 2026.2.18 (Unreleased) CHANGELOG

---

## 🔥 对我们直接有用的新功能

### 1. Anthropic 1M 上下文支持（2026.2.17）
- `params.context1m: true` 可开启 Opus/Sonnet 的 100万 token 上下文
- **价值**：处理超长文档（如产品手册、标书）时不用分段，一次性喂进去
- **行动项**：等厂长发操作手册时，可以考虑开启此功能处理大文件

### 2. Telegram 按钮样式（2026.2.17）
- inline button 支持 `style` 属性：`primary|success|danger`
- **价值**：给厂长发消息时可以用彩色按钮，交互更直观
- **已知**：我们的 message tool 已支持 buttons 参数

### 3. Telegram 表情反应事件（2026.2.17）
- 用户给消息点表情会触发系统事件
- 配置：`channels.telegram.reactionNotifications`
- **价值**：厂长可以用表情反应来触发操作（如👍=确认，❌=取消）

### 4. Cron Webhook 分离（2026.2.17）
- `delivery.mode = "webhook"` 独立于 announce
- **价值**：未来可以把巡逻结果推送到其他系统（如钉钉 webhook）

### 5. Apple Watch 支持（2026.2.18 Unreleased）
- Watch companion MVP，可以在手表上收消息
- **价值**：厂长如果有 Apple Watch，可以手腕上看 Kitt 的通知

### 6. 安全加固（2026.2.17-2026.2.18）
- exec safeBins 必须从可信目录解析，防 PATH 劫持
- SSRF 防护增强（NAT64/6to4/Teredo 地址全部封堵）
- cron webhook SSRF 防护
- **价值**：验证了我们 SOUL.md 安全红线的方向是对的，官方也在加固

### 7. Session Memory Hook 修复（2026.2.17）
- `/new` 命令的会话摘要恢复修复
- **价值**：压缩后恢复更可靠，减少"压缩后失忆"问题

### 8. Cron 超时修复（2026.2.17）
- `timeoutSeconds: 0` 现在表示无超时（之前被截断为1）
- **价值**：长时间运行的 cron 任务不会被误杀
