# 语义记忆：LobsterAI 竞品分析

## 来源
AI进化论-花生 实测（2026-02-19），2026-02-20 收藏消化

## 定位
中国版 OpenClaw 平替，面向非技术用户（全 GUI，零代码门槛）

## 核心能力
- 多 Agent 并行协作（4 个 Agent 同时从不同角度分析）
- 浏览器自动化（Chrome 控制 + 远程操作）
- 自主纠错（报错时自己修复，不打扰用户）
- 本地运行，数据不出设备

## 亮点场景
1. B站数据分析 → 4 Agent 并行 → 3-4 分钟出 HTML 报告
2. 定时新闻简报 → 自动搜索 + 飞书推送
3. 竞品分析 PPT → 50-60 次工具调用 + 自主纠错

## 与 OpenClaw 对比
| 维度 | OpenClaw | LobsterAI |
|------|----------|-----------|
| 门槛 | 高（需代码） | 零（GUI） |
| 数据 | 走云端 | 本地 |
| 扩展 | 强（Skill 生态） | 支持 zip/GitHub 导入 |
| 人群 | 技术极客 | 职场人/学生/超级个体 |

## 对我们的启示
- LobsterAI 的多 Agent 并行思路值得参考（我们的兵团是串行 fallback）
- 自主纠错是 Agent 成熟度标志 — 我们已有类似能力
- GUI 化是趋势，但我们走 CLI + Telegram 路线，定位不同
- 本地运行 + 数据不出域 — 制造业场景的刚需
