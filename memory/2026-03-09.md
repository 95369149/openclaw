# 2026-03-09

## 状态变更
- 将系统配置中的明文 API Key 和 Token 替换为外置环境变量引用，正确格式为 `${VAR_NAME}`（之前错误使用了 `${ENV:VAR_NAME}` 导致大面积 401/403 报错）。
- `mygptapi`、`mynewapi`、`telegram` 已经成功改为变量引用。
- `v1api` 的 Token 已失效（401），目前已从配置中移除。

## 阻塞问题
- **Discord 401 导致整个 Gateway 阻塞**：Discord 的 Token 失效（401 Unauthorized），导致网关重启时进入无限重试循环，连带拖垮了 Telegram 渠道的启动。厂长之前要求“不要关 Discord”，但目前必须暂时禁用以恢复 Telegram，或更换有效的 Discord Token。

## 经验教训
- OpenClaw 的环境变量引用没有 `ENV:` 前缀，直接使用 `${VAR}`。
- 当一个通道（如 Discord）启动失败进入重试时，会阻塞其他通道的初始化。必须先将其摘除才能保证主系统存活。

## 关键决策
- 在修改系统配置并进行连通性测试后，决定暂时挂起 Discord 通道（如果持续报错），以优先保住 Telegram 会话的响应能力。
