# 豆包(Doubao)内容提取方案 v2.0

> 更新：2026-02-22 | 整合 doubao-free-api 逆向发现 + GBK 根因分析 + CDP 原生方案
> 前版：豆包抓取方案_完整代码.md（2026-02-21）

## 核心问题

豆包(doubao.com)使用虚拟滚动渲染，DOM 中只保留可视区域内容。直接 `innerText` 无法获取完整对话。

## 方案决策树

```
需要提取豆包对话内容？
├── 提取「新对话」的实时回复 → 方案一：doubao-free-api（推荐）
├── 提取「已有对话」的历史内容
│   ├── 单条回复 → 方案二：复制按钮 + 剪贴板
│   ├── 整个对话 → 方案三：CDP 网络拦截
│   └── 降级兜底 → 方案四：滚动拼接（60-80%完整度）
└── 不要用 → 方案五：侧边栏提取（仅5%，废弃）
```

## 方案一：doubao-free-api 逆向 API（★★★★★ 推荐）

### 原理
GitHub 项目 `LLM-Red-Team/doubao-free-api` 已完整逆向豆包 API，用浏览器 Cookie 中的 `sessionid` 作为认证，兼容 OpenAI 接口格式。

### 获取 sessionid
1. 打开 https://www.doubao.com/ 并登录
2. F12 → Application → Cookies → 找到 `sessionid` 值

### 使用方式

```bash
# 方式A：Docker 部署（推荐）
docker run -it -d --init --name doubao-free-api -p 8000:8000 \
  -e TZ=Asia/Shanghai vinlic/doubao-free-api

# 方式B：本地部署
git clone https://github.com/LLM-Red-Team/doubao-free-api
cd doubao-free-api && npm install && npm start
```

```bash
# 调用（OpenAI 兼容格式）
curl http://localhost:8000/v1/chat/completions \
  -H "Authorization: Bearer YOUR_SESSION_ID" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao",
    "messages": [{"role": "user", "content": "你好"}],
    "stream": true
  }'
```

### 优势
- 完全绕过虚拟滚动问题
- 100% 完整内容，原始 Markdown 格式
- 支持流式输出、多轮对话、联网搜索
- 兼容 OpenAI SDK，可直接接入现有工具链
- 多 sessionid 轮换：`Bearer sid1,sid2,sid3`

### 限制
- sessionid 有过期风险（需定期更新）
- 仅限自用研究，不可商用
- 只能获取「新对话」回复，无法提取「已有历史对话」

### 与 ai-web-agent 的关系
我们的 `ai-web-agent v0.4` 已经实现了浏览器自动化方案（发消息→等回复→hover→click复制→读剪贴板）。doubao-free-api 是更轻量的替代：
- ai-web-agent：重（需要 Playwright + Chrome），但能操作任意网页
- doubao-free-api：轻（纯 API），但只能对话

## 方案二：复制按钮 + 剪贴板（★★★★ 已验证）

### 适用场景
提取单条已有回复的完整内容。

### 自动化流程（ai-web-agent v0.4 已实现）
```
hover 触发工具栏 → Playwright 原生 click 复制按钮 → 读剪贴板 → 转码
```

### 关键：GBK 编码根因

**根本原因**：`pbpaste` 使用 `LANG` 环境变量决定输出编码。macOS 中文环境下 `LANG` 可能为空或设为 `zh_CN.GBK`，导致剪贴板输出 GBK 编码。

**永久修复**（加入 `~/.zshrc`）：
```bash
export LANG=en_US.UTF-8
```

修复后不再需要 `iconv` 转码：
```bash
# 修复前
pbpaste | iconv -f GBK -t UTF-8 > output.md

# 修复后（直接可用）
pbpaste > output.md
```

**验证当前编码**：
```bash
locale  # 查看 LANG 值
pbpaste | file -  # 检测剪贴板内容编码
```

**补充说明**：ChatGPT macOS 客户端也有同样的中文乱码 bug（OpenAI 社区已确认），说明这是 macOS 剪贴板 + 中文的通病，不是豆包特有问题。

### 代码（Playwright 版，已验证）
```javascript
// ai-web-agent v0.4 中的实现
// 1. hover 触发工具栏
await page.locator('.message-actions-container').last().hover();
// 2. Playwright 原生 click（不用 JS click，React 需要完整鼠标事件链）
await page.locator('button:has-text("复制")').click();
// 3. 读剪贴板
const content = await page.evaluate(() => navigator.clipboard.readText());
```

> 踩坑记录：JS `el.click()` 在 React 框架下无效，因为 React 依赖完整鼠标事件链（mousedown→mouseup→click）。必须用 Playwright 原生 `locator.click()`。

## 方案三：CDP 网络拦截（★★★★ 理论最优）

### 原理
在 Chrome DevTools Protocol 层面拦截豆包的 API 请求，获取原始 JSON 数据。比 JS 注入更可靠，不受页面刷新影响。

### CDP 原生方式（推荐）
```javascript
const CDP = require('chrome-remote-interface');

async function interceptDoubaoAPI() {
  const client = await CDP({ port: 9222 });
  const { Network, Page } = client;
  
  await Network.enable();
  
  // 监听所有响应
  Network.responseReceived(async ({ requestId, response }) => {
    const url = response.url;
    // 豆包 API 端点特征（需实际抓包确认）
    if (url.includes('/alice/') || 
        url.includes('/samantha/') || 
        url.includes('/api/chat') ||
        url.includes('/api/conversation')) {
      try {
        const { body } = await Network.getResponseBody({ requestId });
        console.log(`[${new Date().toISOString()}] ${url}`);
        console.log(body.substring(0, 500));
        // 保存到文件
        require('fs').appendFileSync('doubao_api_log.jsonl', 
          JSON.stringify({ url, timestamp: Date.now(), body }) + '\n');
      } catch (e) {
        // 某些响应可能已被清理
      }
    }
  });
  
  console.log('Intercepting... Navigate to doubao.com and start a conversation.');
}

interceptDoubaoAPI();
```

### JS 注入方式（备选）
```javascript
// 注入到页面中，拦截 fetch + XHR
const originalFetch = window.fetch;
window._captured = [];

window.fetch = async function(...args) {
  const response = await originalFetch.apply(this, args);
  const url = typeof args[0] === 'string' ? args[0] : args[0]?.url;
  if (url && (url.includes('/api/') || url.includes('chat') || url.includes('message'))) {
    try {
      const clone = response.clone();
      const text = await clone.text();
      window._captured.push({ url, ts: Date.now(), data: text });
    } catch(e) {}
  }
  return response;
};
```

## 方案四：滚动拼接（★★☆ 降级兜底）

### 适用场景
其他方案都不可用时的最后手段。完整度约 60-80%。

```javascript
async function extractByScroll() {
  // 找到可滚动容器
  const scrollEl = document.querySelector('[class*="chat-scroll"]') 
    || [...document.querySelectorAll('*')].find(el => el.scrollHeight > el.clientHeight + 100);
  if (!scrollEl) return 'No scrollable container';

  scrollEl.scrollTop = 0;
  await new Promise(r => setTimeout(r, 500));

  const chunks = [];
  let prev = '';
  
  for (let i = 0; i < 100; i++) {
    const text = scrollEl.innerText;
    if (text !== prev) {
      // 简单去重：取新增部分
      if (!prev) {
        chunks.push(text);
      } else {
        const lines = text.split('\n');
        const prevLast = prev.split('\n').pop();
        const idx = lines.indexOf(prevLast);
        chunks.push(idx >= 0 ? lines.slice(idx + 1).join('\n') : text);
      }
      prev = text;
    }
    
    const before = scrollEl.scrollTop;
    scrollEl.scrollTop += scrollEl.clientHeight * 0.8;
    await new Promise(r => setTimeout(r, 300));
    if (scrollEl.scrollTop === before) break;
  }
  
  return chunks.join('\n');
}
```

### 已知问题
- 虚拟滚动的回收机制导致去重困难
- 长对话可能丢失中间段落
- DOM 选择器随豆包版本更新频繁变化
