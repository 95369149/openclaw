# 豆包(Doubao)网页内容抓取方案 - 完整代码

## 背景
豆包(doubao.com)的聊天内容使用虚拟滚动渲染，DOM中只保留可视区域的内容，无法直接通过 innerText 获取完整对话。需要通过浏览器自动化方案提取完整内容。

## 环境
- macOS + Chrome 远程调试（端口9222）
- 通过 Playwright/CDP 连接浏览器
- 豆包网页版：https://www.doubao.com/chat/

## 方案一：利用豆包自带复制按钮 + 剪贴板提取

### 步骤1：定位复制按钮
豆包每条AI回复底部有操作按钮栏，其中包含"复制"按钮。

```javascript
// 获取所有回复区域的操作按钮
const buttons = document.querySelectorAll('button');
// 复制按钮通常包含"复制"文字或特定SVG图标
const copyBtn = Array.from(buttons).find(b => b.textContent.includes('复制'));
if (copyBtn) copyBtn.click();
```

### 步骤2：从剪贴板提取并转码
豆包复制到剪贴板的内容是 GBK 编码，macOS 下需要转码：

```bash
# 提取并转码为 UTF-8
pbpaste | iconv -f GBK -t UTF-8 > output.md

# 验证内容
wc -c output.md
head -30 output.md
```

### 关键发现
- 豆包剪贴板内容编码为 **GBK/GB2312**，不是 UTF-8
- 必须用 `iconv -f GBK -t UTF-8` 转码才能正确显示中文

## 方案二：滚动拼接法（适用于主对话区域）

### 原理
虚拟滚动只渲染可视区域，通过逐步滚动 + 每次提取可见文本 + 去重拼接，获取完整内容。

```javascript
async function extractFullChat() {
  const chatContainer = document.querySelector('[class*="chat"]') || 
                         document.querySelector('main');
  
  // 找到可滚动容器
  let scrollEl = null;
  const candidates = chatContainer.querySelectorAll('*');
  for (let el of candidates) {
    if (el.scrollHeight > el.clientHeight + 100) {
      scrollEl = el;
      break;
    }
  }
  if (!scrollEl) return 'No scrollable container found';

  // 滚动到顶部
  scrollEl.scrollTop = 0;
  await new Promise(r => setTimeout(r, 500));

  const allChunks = [];
  let lastText = '';
  let maxIterations = 100;

  while (maxIterations-- > 0) {
    // 获取当前可见文本
    const currentText = scrollEl.innerText;
    
    // 去重：找到与上次文本的重叠部分
    if (currentText !== lastText) {
      if (lastText === '') {
        allChunks.push(currentText);
      } else {
        // 找重叠点
        const lines = currentText.split('\n');
        const lastLines = lastText.split('\n');
        let overlapStart = -1;
        
        for (let i = 0; i < lines.length; i++) {
          if (lines[i] === lastLines[lastLines.length - 1]) {
            overlapStart = i + 1;
            break;
          }
        }
        
        if (overlapStart > 0 && overlapStart < lines.length) {
          allChunks.push(lines.slice(overlapStart).join('\n'));
        } else {
          allChunks.push(currentText);
        }
      }
      lastText = currentText;
    }

    // 检查是否到底
    const beforeScroll = scrollEl.scrollTop;
    scrollEl.scrollTop += scrollEl.clientHeight * 0.8;
    await new Promise(r => setTimeout(r, 300));
    
    if (scrollEl.scrollTop === beforeScroll) break; // 已到底部
  }

  return allChunks.join('\n');
}
```

## 方案三：拦截网络请求（最可靠）

### 原理
豆包的对话内容通过 API 加载，拦截 XHR/Fetch 请求可以获取原始数据。

```javascript
// 拦截 fetch 请求
const originalFetch = window.fetch;
window._capturedResponses = [];

window.fetch = async function(...args) {
  const response = await originalFetch.apply(this, args);
  const url = typeof args[0] === 'string' ? args[0] : args[0]?.url;
  
  // 过滤豆包API请求（对话内容相关）
  if (url && (url.includes('/api/') || url.includes('chat') || url.includes('message'))) {
    try {
      const clone = response.clone();
      const text = await clone.text();
      window._capturedResponses.push({
        url: url,
        timestamp: Date.now(),
        data: text
      });
    } catch(e) {}
  }
  return response;
};

// 同时拦截 XMLHttpRequest
const originalXHROpen = XMLHttpRequest.prototype.open;
const originalXHRSend = XMLHttpRequest.prototype.send;

XMLHttpRequest.prototype.open = function(method, url) {
  this._url = url;
  return originalXHROpen.apply(this, arguments);
};

XMLHttpRequest.prototype.send = function() {
  this.addEventListener('load', function() {
    if (this._url && (this._url.includes('/api/') || this._url.includes('chat'))) {
      try {
        window._capturedResponses.push({
          url: this._url,
          timestamp: Date.now(),
          data: this.responseText
        });
      } catch(e) {}
    }
  });
  return originalXHRSend.apply(this, arguments);
};
```

### 使用方式
1. 先注入拦截代码
2. 刷新页面或触发对话加载
3. 读取 `window._capturedResponses`

## 方案四：侧边栏/智能体面板提取

豆包的"智能体"回复有时会在右侧 `aside` 面板中展示，该面板也有虚拟滚动。

```javascript
// 获取侧边栏内容
const aside = document.querySelector('aside') || 
              document.querySelector('[role="complementary"]');
if (aside) {
  console.log('Aside text length:', aside.innerText.length);
  // 同样需要滚动加载
}
```

## 实际验证结果

| 方案 | 可行性 | 完整度 | 备注 |
|------|--------|--------|------|
| 复制按钮+剪贴板 | ✅ 已验证 | 100% | 需GBK转码，最简单可靠 |
| 滚动拼接 | ⚠️ 部分可行 | ~60-80% | 虚拟滚动去重困难 |
| 网络拦截 | 🔲 未验证 | 理论100% | 需要刷新页面触发 |
| 侧边栏提取 | ⚠️ 有限 | ~5% | 虚拟滚动严重，仅渲染可视区 |

## 最佳实践（当前推荐）

```bash
# 1. 通过浏览器自动化点击豆包的"复制"按钮（或手动点击）
# 2. 终端执行：
pbpaste | iconv -f GBK -t UTF-8 > /path/to/output.md

# 3. 验证
cat /path/to/output.md | head -50
wc -c /path/to/output.md
```
