# 红太阳周培训图表示例

下面这版是给你看的效果样稿，重点看“表达形态”，不是最终排版软件导出的截图。

## 1) 周培训进度卡

```infographic
infographic list-grid-badge-card
data
  title 红太阳周培训看板
  desc 本周聚焦：企业文化、交付纪律、责任闭环、售后响应
  items
    - label 培训主题数
      desc 4个核心主题 | 文化+执行+交付+售后
    - label 参训对象
      desc 销售+生产+售后+管理 | 全链条覆盖
    - label 本周目标
      desc 统一语言 | 统一动作 | 统一标准
    - label 输出要求
      desc 会后落地到日报、周报、动作清单
```
