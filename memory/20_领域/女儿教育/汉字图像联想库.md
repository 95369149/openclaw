# 汉字图像联想库

## 设计思路
将汉字的形状转化为有趣图像，帮助三年级学生记忆。

## 一级汉字（100个）

### 象形类
- **日** → 太阳（圆形，中间一点是太阳黑子）
- **月** → 弯月（像夜晚的月亮）
- **山** → 三座山峰
- **水** → 流动的河流
- **火** → 火焰（像火苗跳动）
- **木** → 一棵树（树干+树枝）
- **人** → 侧身站立的人
- **口** → 张开的嘴巴

### 会意类
- **明** → 日+月，太阳和月亮都亮→明亮
- **休** → 人+木，人靠在树上休息
- **看** → 手+目，手搭在眼睛上看
- **森** → 三木，很多树就是森林

### 形声类
- **妈** → 女+马，妈妈像马一样勤劳？（趣味联想）
- **爸** → 父+巴，爸爸的巴掌握家庭方向

## 使用方法
1. **闪卡模式**：显示汉字 → 让孩子想图像 → 展示联想图
2. **画画模式**：让孩子画出心中的联想图像
3. **故事模式**：用几个汉字编一个小故事

## AI生成提示词
```prompt
生成汉字“{汉字}”的图像联想描述，适合三年级学生：
1. 形状像什么（实物）
2. 编一个简短故事（20字以内）
3. 制作一个记忆口诀（押韵）

例如“明”：形状像太阳和月亮挨在一起。故事：太阳和月亮是好朋友，一起照亮世界。口诀：日月明，亮晶晶。
```
