# 提示词工程 SOP（发给外部 App 用）

> 最后更新：2026-03-11
> 适用场景：给 Coze、豆包、AI Studio、GPT、Gemini 等外部工具写提示词
> 核心原则：上下文工程 > 提示词措辞

---

## 一、发之前必须自检（5 项）

| # | 检查项 | 不合格就别发 |
|---|--------|-------------|
| 1 | 目标明确吗？ | "帮我写个东西" ❌ → "写一篇 300 字朋友圈文案，卖点是省料 15%" ✅ |
| 2 | 有没有给背景？ | 不给背景 = 让模型猜 = 大概率跑偏 |
| 3 | 有没有给示例？ | 一个好示例 > 十句描述 |
| 4 | 输出格式说了吗？ | 长度、语言、结构、禁忌都要写清 |
| 5 | 有没有写"不要做什么"？ | 否定约束比肯定约束更有效 |

---

## 二、提示词模板（通用版）

```
【角色】你是{角色}，擅长{能力}。

【背景】
- 公司：济南红太阳数控设备有限公司
- 产品：{具体产品}
- 目标客户：{客户画像}
- {其他必要背景}

【任务】
{一句话说清楚要做什么}

【要求】
1. {具体要求1}
2. {具体要求2}
3. {具体要求3}

【示例】
输入：{示例输入}
输出：{示例输出}

【禁忌】
- 不要{禁忌1}
- 不要{禁忌2}

【输出格式】
- 长度：{字数}
- 语言：中文
- 格式：{markdown/纯文本/列表}
```

## 三、按场景的提示词模板

### 场景 1：朋友圈/短文案
```
【角色】你是工业设备行业的营销文案专家。

【背景】
- 公司：济南红太阳数控设备有限公司
- 产品：振动刀切割机/气动刀切割机/多层裁床
- 客户：皮革、汽车内饰、家纺、复合材料等行业的工厂老板

【任务】
写一条朋友圈文案，主题是{主题}。

【要求】
1. 控制在 150 字以内
2. 前 10 个字必须抓眼球
3. 必须包含一个具体数据（如省料 15%、效率提升 3 倍）
4. 结尾有行动号召（CTA）
5. 语气：专业但不端着，像老板跟同行聊天

【禁忌】
- 不要用"赋能""助力""一站式"等空话
- 不要超过 200 字
- 不要用感叹号超过 1 个

【示例】
主题：振动刀切割精度
输出：3mm 厚真皮，切口比剃刀还干净——我们客户实测，振动刀切割毛刺率降到 0.1% 以下。手工裁的时代该翻篇了。想看效果的扣 1，发视频给你。
```

### 场景 2：短视频脚本
```
【角色】你是工业短视频编导，擅长抖音/视频号风格。

【背景】
- 公司：济南红太阳数控设备有限公司
- 设备类型：{具体设备}
- 目标平台：{抖音/视频号/小红书}

【任务】
写一个 60 秒短视频脚本，主题是{主题}。

【要求】
1. 前 3 秒必须有视觉冲击或悬念（情绪钩子）
2. 中间展示核心卖点，用对比或数据
3. 结尾有明确 CTA
4. 标注每个镜头的画面描述 + 时长 + 文案/旁白
5. 总时长控制在 45-60 秒

【格式】
| 时间 | 画面 | 文案/旁白 | 备注 |
|------|------|-----------|------|

【禁忌】
- 不要纯口播，必须有产品画面
- 不要用行业黑话，观众是老板不是工程师
```

### 场景 3：客户话术/拜访准备
```
【角色】你是 B2B 工业设备销售顾问，有 10 年经验。

【背景】
- 我方：济南红太阳数控设备有限公司，主营柔性材料智能切割设备
- 客户：{客户名称}，行业：{行业}，规模：{规模}
- 客户痛点（已知）：{痛点}
- 竞品情况：{竞品信息}

【任务】
准备一份拜访话术，包含：
1. 开场白（30 秒内建立信任）
2. 痛点挖掘问题（3-5 个）
3. 产品匹配话术（针对客户痛点）
4. 异议处理（价格贵/已有供应商/不急）
5. 促成话术

【要求】
- 语气：专业、自信、不卑不亢
- 每段话术控制在 2-3 句
- 必须包含至少 1 个客户同行案例

【禁忌】
- 不要贬低竞品
- 不要承诺做不到的事
```

### 场景 4：智能客服知识库
```
【角色】你是工业设备售后技术专家。

【背景】
- 产品：{具体产品型号}
- 常见问题类型：安装、调试、维护、故障排除

【任务】
为以下问题写标准回答：
{问题}

【要求】
1. 先判断问题类型（安装/调试/维护/故障）
2. 给出分步解决方案（不超过 5 步）
3. 每步必须具体可操作
4. 如果需要现场处理，明确说"建议联系售后工程师"
5. 语气：耐心、专业、不啰嗦

【禁忌】
- 不要说"可能""也许""大概"
- 不要给出不确定的技术参数
- 不确定的问题直接转人工
```

## 四、质量判断标准

发出去之后，用这 4 条判断输出是否达标：

| # | 标准 | 不达标的表现 |
|---|------|-------------|
| 1 | 能直接用吗？ | 还需要大改 = 提示词没写好 |
| 2 | 有具体数据/案例吗？ | 全是空话套话 = 缺背景信息 |
| 3 | 语气对吗？ | 太软/太官方/太 AI 味 = 缺风格示例 |
| 4 | 长度对吗？ | 太长或太短 = 没写输出约束 |

---

## 五、常见失败模式 + 修复

| 失败现象 | 根因 | 修复方法 |
|----------|------|----------|
| 输出太泛，没有针对性 | 没给背景 | 补公司/产品/客户信息 |
| 语气太 AI、太客服 | 没给示例 | 加一个厂长风格的示例 |
| 输出太长 | 没限字数 | 加"控制在 X 字以内" |
| 关键信息缺失 | 没列要求 | 用编号列出必须包含的要素 |
| 输出格式乱 | 没指定格式 | 加表格/列表/markdown 模板 |
| 重复废话多 | 没写禁忌 | 加"不要用XX""不要超过X" |

## 六、厂长专属风格指南

以下是厂长的表达偏好，写提示词时可以直接贴进去当示例：

**厂长喜欢的风格：**
- 零废话，一针见血
- 数据说话，不听空话
- 铁腕务实，不要鸡汤
- 能用一句话说完的不用两句

**厂长讨厌的：**
- "赋能""助力""一站式""全方位"
- 假大空的承诺
- 过度客套
- 没有数据支撑的结论

**示例对比：**
❌ "各位同事，让我们一起努力，共创美好明天！"
✅ "今天开始，每个人头上都有数字。完不成的，自己想清楚。"
