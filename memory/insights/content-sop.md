# 内容生成 SOP

> 最后更新：2026-03-11
> 灵感来源：@Graceruansu 的规则文件化方法

## 核心原则
内容生成不靠临场 prompt，靠预设规则 + 自检闭环。

## 通用流程

### 1. 输入校验
- 确认目标受众
- 确认输出格式（md/html/ppt/图片）
- 确认长度要求
- 确认语言（中文/英文）
- 缺任何一项 → 先问清楚再动手

### 2. 结构先行
- 先出大纲/目录
- 厂长确认结构后再写内容
- 不确认结构就开写 = 大概率返工

### 3. 输出自检
- 检查是否覆盖所有要求
- 检查格式是否正确
- 检查长度是否合适
- 检查是否有明显错误

### 4. 不合格自动重写
- 自检发现问题 → 直接修，不问厂长
- 修完再提交

### 5. 结果留痕
- 写入 memory/shared/
- 更新 task-board（如适用）

## 特定场景规则

### 培训教材
- 必须包含实操步骤
- 检测方法嵌入对应工序（不单独成章）
- 质量事故案例必须真实
- 数值标准必须精确（如 ≤0.1mm）

### 短视频内容
- 前 3 秒必须有情绪钩子
- 每条控制在 60 秒以内
- 必须有明确 CTA

### 通知/公文
- 简洁、正式
- 必须包含：时间、地点、参会人员、主题
- 不废话
