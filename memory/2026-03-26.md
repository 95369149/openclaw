#### 3. 经验教训
- **外部模型吐出的前端代码不能盲信**：即便 UI 看起来高级，也可能混入 JSX/模板字符串残缺/运算符丢失等低级硬伤，必须先做语法级验收。
- **设计类任务也要做最小可运行检查**：至少要扫一遍对象字面量、模板字符串、字符串引号、条件运算、URL 拼接、`innerHTML` 片段、`fetch` 路径，避免“看起来很像成品”的假阳性。
- **同一 cron 告警反复刷屏，说明不能只改 timeout**：这类短任务更可能要么缩 prompt、要么换快模型、要么拆任务，单纯把超时拉长不一定有效。

#### 4. 阻塞问题
