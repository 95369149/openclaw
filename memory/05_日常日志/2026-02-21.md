## 教训
- NotebookLM source add --type text 会把文件路径当文本传入，应该直接传文件路径让它自动检测
- Chrome 安装需要 hdiutil attach + cp，DMG 挂载可能卡住
- OpenClaw browser 工具需要 Chrome 且 Gateway 需重启才能识别新浏览器
- NotebookLM 不支持 .py 文件上传，需转成 .md（代码块包裹）
- Kimi K2.5 子 agent 会读文件但不写文件（只输出代码不执行 write），重要任务自己写
- M1 16GB 同时 import pyautogui + pytesseract + google-generativeai 会被 OOM kill，需分开加载
- 操作完立刻记日志，不要攒到最后补——容易漏
- Scout-豆包不适合批量长文（验证码拦截），仅用于简短问答和创意
- Perplexity 的 Claude Opus 4.6 Max 需升级才能用，不要选
