# 读取证据检查

## 规则

**任何改动交付时，必须能展示读取证据。没有证据 = 没有完成。**

## 强制要求

交付时必须包含：

```
read_evidence:
  - file: <读取的文件路径>
    key_finding: <读取后的关键发现>
```

## 禁止行为

- ❌ 说"我已经读了"但没有展示读取内容
- ❌ 凭上轮记忆直接改，不重新读
- ❌ 读取证据字段为空或缺失

## 验证方式

apply_manifest.py 检查 `read_evidence` 字段：

- 存在且非空 → 通过
- 缺失或为空 → 打回重做

## 棘轮价值

防止 agent "假装读了"然后凭印象改动，导致：

- 改了已经变化的文件
- 引入和现有模式冲突的实现
- 上下文漂移后的错误累积
