#### 多实例

# OpenClaw 多 Agent 配置指南

## 核心概念

### 1. 什么是 Agent？
一个 **Agent** 是拥有完整独立环境的智能体，包含：
- **工作空间 (Workspace)**: 文件、AGENTS.md/SOUL.md/USER.md、本地笔记、人格规则
- **状态目录 (agentDir)**: 认证配置文件、模型注册表、每个 Agent 的配置
- **会话存储 (Session store)**: 聊天历史 + 路由状态，位于 `~/.openclaw/agents/<agentId>/sessions`

### 2. 路径结构
- **配置**: `~/.openclaw/openclaw.json`
- **状态目录**: `~/.openclaw` (或 `OPENCLAW_STATE_DIR`)
- **工作空间**: `~/.openclaw/workspace` (或 `~/.openclaw/workspace-<agentId>`)
- **Agent 目录**: `~/.openclaw/agents/<agentId>/agent` (或 `agents.list[].agentDir`)
- **会话**: `~/.openclaw/agents/<agentId>/sessions`

## 单 Agent 模式 (默认)

不做任何配置时，OpenClaw 运行单一 Agent:
- `agentId` 默认为 `main`
- 会话键格式：`agent:main:<mainKey>`
- 工作空间：`~/.openclaw/workspace`
- 状态目录：`~/.openclaw/agents/main/agent`

## 多 Agent 配置步骤

### 步骤 1：创建 Agent 工作空间

```bash
# 使用向导创建新的隔离 Agent
openclaw agents add work
openclaw agents add coding
openclaw agents add social
```

每个 Agent 获得自己的：
- 工作空间 + `SOUL.md`, `AGENTS.md`, `USER.md`
- 独立的 `agentDir`
- `~/.openclaw/agents/<agentId>` 下的会话存储

### 步骤 2：创建频道账户

为每个 Agent 创建独立的频道账户：

```bash
# 每个 Agent 的 WhatsApp 账户
openclaw channels login --channel whatsapp --account work
openclaw channels login --channel whatsapp --account personal

# 每个 Agent 的 Telegram Bot
# 通过 BotFather 创建不同的 Bot，获取不同的 token
```

### 步骤 3：配置 Agent、账户和路由绑定

## 路由规则 (消息如何选择 Agent)

**确定性路由：最具体优先**：

1. `peer` 匹配 (精确 DM/群组/频道 ID)
2. `parentPeer` 匹配 (线程继承)
3. `guildId + roles` (Discord 角色路由)
4. `guildId` (Discord)
5. `teamId` (Slack)
6. `accountId` 频道账户匹配
7. 频道级匹配 (`accountId: "*"`)
8. 回退到默认 Agent (`agents.list[].default`，否则第一个列表条目，默认：`main`)

如果多个绑定在同一层级匹配，**配置顺序第一个获胜**。

## 会话隔离 (dmScope)

### 安全 DM 模式 (多用户设置推荐)

当 Agent 能接收**多个用户**的私聊时，启用安全 DM 模式：

```json5
{
  session: {
    // 安全 DM 模式：按频道+发送者隔离 DM 上下文
    dmScope: "per-channel-peer",
  },
}
```

### dmScope 选项

- `"main"` (默认): 所有 DM 共享主会话（单用户设置适用）
- `"per-peer"`: 按发送者 ID 隔离（跨频道）
- `"per-channel-peer"`: 按频道+发送者隔离（多用户收件箱推荐）
- `"per-account-channel-peer"`: 按账户+频道+发送者隔离（多账户收件箱推荐）

### 使用 identityLinks 跨频道识别同一用户

```json5
{
  session: {
    dmScope: "per-channel-peer",
    identityLinks: {
      alice: ["telegram:123456789", "discord:987654321012345678"],
    },
  },
}
```

## 子 Agent (Sub-Agents)

### 基础配置

```json5
{
  agents: {
    defaults: {
      subagents: {
        maxSpawnDepth: 2,      // 允许子 Agent 生成子子 Agent (默认: 1)
        maxChildrenPerAgent: 5, // 每个 Agent 会话的最大活跃子 Agent (默认: 5)
        maxConcurrent: 8,       // 全局并发限制 (默认: 8)
        archiveAfterMinutes: 60, // 子 Agent 会话自动归档时间 (默认: 60)
      },
    },
  },
}
```

### 深度级别

| 深度 | 会话键格式 | 角色 | 能否生成？ |
|------|-----------|------|-----------|
| 0 | `agent:<id>:main` | 主 Agent | 总是 |
| 1 | `agent:<id>:subagent:<uuid>` | 子 Agent (调度器) | 当 `maxSpawnDepth >= 2` |
| 2 | `agent:<id>:subagent:<uuid>:subagent:<uuid>` | 子子 Agent (工作者) | 从不 |

### 工具使用

```json5
{
  tools: {
    subagents: {
      tools: {
        // deny 优先
        deny: ["gateway", "cron"],
        // 如果设置了 allow，则变为仅允许列表 (deny 仍然优先)
        // allow: ["read", "exec", "process"]
      },
    },
  },
}
```

# 总裁九大机制 — 完整课程体系
> 来源：网络多源整理（中恩教育、大脑银行等总裁课程提炼），结合中小企业实战落地经验总结。

## 课程概述
**讲师背景**：主要源自国内头部商学院（如中恩教育贺传智/张致铭、大脑银行苏引华等）的企业自动运转管理课程。
**核心痛点**：老板忙而无效、员工没有动力、企业大而不强、管理流于形式。
**课程宗旨**：把老板从繁杂的日常事务中解放出来，通过建立套套相环的“九大机制”，让企业实现自动运转。
**适用对象**：中小企业创始人、总裁、核心高管，特别适合60-200人规模、处于快速成长期但管理粗放的制造型、服务型企业。

---

## 第一机制：文化机制（解决"心"的问题）

### 核心理念
- 企业的灵魂：资源会枯竭，唯有文化生生不息。
- 经营企业就是经营人的思想和灵魂。老板想向东，员工想向西，企业做大后必然产生内耗，唯有统一思想才能统一行动。
- 核心三段论：使命（为何而战）、愿景（去向何方）、价值观（行为底线与红线）。

### 操作步骤
1. **共创提取（非老板独裁）**：组织核心高管封闭开会，每人写下公司成功的最关键3个词，合并同类项，提炼出具有公司DNA的价值观。
2. **故事化宣贯**：文化不能只挂在墙上。要把每个价值观对应到一个真实的员工故事，并在早晚会上反复宣讲。
3. **制度化考核**：将价值观纳入员工转正和绩效考核，权重至少占30%-50%。违背价值观（触碰红线）实行一票否决制。

### 落地工具
- **《企业文化手册》（白皮书）**：包含使命、愿景、价值观的详细定义及行为准则。
- **“红黑榜”制度**：每周评选践行价值观的“标杆员工”上红榜，违规者上黑榜。

### 经典案例
- **阿里巴巴的“六脉神剑”**：阿里的考核是50%业绩+50%价值观。业绩好但价值观不合的称为“野狗”，坚决开除；价值观好但业绩差的称为“小白兔”，予以淘汰或转岗。

### 常见误区
- 抄袭大公司的文化，词藻华丽但员工记不住、不理解。
- 文化只是老板的口号，老板自己不带头践行，导致“上梁不正下梁歪”。

---

## 第二机制：战略机制（解决"路"的问题）

### 核心理念
- 战略不是看你想要什么，而是看你愿意放弃什么。战略的本质是“舍得”。
- 最大的浪费就是做根本不该做的事情。许多中小企业死于“盲目多元化”，用战术上的勤奋掩盖战略上的懒惰。

### 操作步骤
1. **市场洞察与聚焦**：画出企业的核心优势圈，砍掉不赚钱且无未来的边缘业务，把所有资源（人、财、物）投入到一个极窄但足够深的市场口子（一米宽，一万米深）。
2. **差异化定位**：提炼出你与竞争对手的最大不同（比如：服务最快、质量最硬、性价比最高），形成独特的“品牌超级符号”。
3. **制定战略目标拆解表**：将年度战略目标拆解为季度、月度目标，并落实到每个部门的具体行动指标上。

### 落地工具
- **波士顿矩阵分析表**：梳理公司现有业务，分清明星、现金牛、问题和瘦狗业务，坚决砍掉瘦狗。
- **年度战略地图（OGSM）**：Objective（目的）、Goal（目标）、Strategy（策略）、Measure（测量），一张图看清全图。

### 经典案例
- **长城汽车**：曾砍掉盈利的轿车业务，全面聚焦SUV，最终成为国内SUV霸主。战略就是“不做什么”。

### 常见误区
- 战略只是老板脑子里的想法，没有形成纸面文件并向全员宣贯。
- 什么都想做，既想低成本又想高品质，缺乏取舍。

## 第三机制：人才机制（解决"人"的问题）

### 核心理念
- 先人后事：有了对的人，才能做对的事。选对人事半功倍，选错人灾难不断。
- 选拔大于培养（宁愿花重金选一头狼，也不要花精力教一头猪爬树）。
- 头狼决定狼群的战斗力，关键岗位必须用“自己人”（能力强且价值观一致）。

### 操作步骤
1. **构建人才画像**：对于核心岗位（如车间主任、销售总监），明确写出所需的能力素质（硬技能）和性格特质（软技能）。
2. **多渠道持续招募**：老板必须是公司的首席招聘官（CHO），每天花20%以上的时间找人，建立常态化的“人才蓄水池”。
3. **结构化面试与试用期淘汰**：引入STAR面试法；试用期实行“严进严出”，不合格者在转正前坚决淘汰，绝不将就。

### 落地工具
- **《关键岗位胜任力模型表》**
- **人才盘点九宫格**：按“业绩”和“价值观”两个维度给现有员工打分，识别出高潜人才和待淘汰人员。

### 经典案例
- **雷军创业初期**：雷军在创办小米的第一年，花了80%的时间在找人上。为了挖一个硬件工程师，他可以连续几个月请对方喝咖啡。

### 常见误区
- 业务忙的时候才招人，导致饥不择食。
- 留不住牛人，因为没有舍得分钱分权；对庸才心慈手软，导致劣币驱逐良币。

## 第四机制：产品机制（解决"物"的问题）

### 核心理念
- 产品是企业一切战略的载体。不解决用户痛点的产品都是耍流氓。
- 从“我能生产什么”转变为“客户真正需要什么”。打造极致单品，用爆品撕开市场缺口。

### 操作步骤
1. **深度用户调研**：走出办公室，老板带头去一线（如展会、客户工厂）倾听客户的抱怨和痛点，记录成册。
2. **提炼价值锚点**：基于痛点，开发出能够一针见血解决问题的产品功能，并将其包装为客户听得懂的“卖点”。
3. **快速迭代MVP**：不追求一次性完美，先推出“最小可行性产品”，让客户试用，根据反馈快速改进（小步快跑，试错迭代）。

### 落地工具
- **《客户痛点与产品功能映射表》**：左边列痛点，右边列解决方案，没有对应的功能一律砍掉。
- **爆品打造画布**：明确目标人群、核心卖点、信任背书和定价策略。

### 经典案例
- **苹果的极致单品策略**：乔布斯回归苹果后，砍掉几十条产品线，只留下4款产品（两款台式、两款便携），集中所有研发力量打造精品，最终颠覆手机行业。

### 常见误区
- 老板闭门造车，陷入“自嗨”式研发。
- 产品线过长，什么都卖，不仅占用大量资金和库存，还导致没有一个产品有核心竞争力。

---

## 第五机制：培训机制（解决"能"的问题）

### 核心理念
- 企业是最大的学校，经营企业的本质是经营人的动力和能力。
- 培训不是开销，而是利润翻倍的最有效投资。不培训的员工是企业最大的成本。
- 解决“老员工靠经验主义，新员工无人带”的断层痛点。

### 操作步骤
1. **建立“师徒制”**：让销冠和技术骨干带徒弟，签订师徒协议，徒弟出业绩，师傅拿提成（绑定利益）。
2. **沉淀标准动作（SOP）**：把优秀员工的隐性经验显性化，变成可复制的《标准作业指导书》和《话术本》。
3. **落实培训四化**：内容实战化（缺什么补什么）、形式多样化（内训+外训+视频课）、考核严格化（考不过不上岗）、结果应用化（与晋升和加薪挂钩）。

### 落地工具
- **《新员工入职通关手册》**：包含第1天、第3天、第7天、第30天必须掌握的知识清单。
- **《岗位技能矩阵表》**：一目了然看出哪个岗位缺哪项技能，定向开展培训。

### 经典案例
- **餐饮巨头海底捞的师徒制**：店长培养出新店长，可以从徒弟的门店甚至徒孙的门店抽成，极大地激发了老员工带新人的热情，实现快速裂变扩张。

### 常见误区
- 以为上几堂大课就是培训，缺乏落地辅导。
- 只有培训没有考核，大家听得激动，回去不动。

## 第六机制：薪酬机制（解决"利"的问题）

### 核心理念
- 钱散人聚，钱聚人散。薪酬不是成本，是投资。
- 为价值付薪，不为苦劳付薪。打破大锅饭，让雷锋不吃亏。
- 薪酬机制的最高境界：老板发钱发到手软，员工拿钱拿到手软，但公司的利润率依然在涨。

### 操作步骤
1. **梳理薪酬结构**：将固定死工资拆分为：底薪（保障生存）+ 绩效提成（激发动力）+ 年终奖/分红（绑定长期）。
2. **设定宽带薪酬**：同一个岗位设定5-7个薪级。打破“只有当官才能加薪”的魔咒，让技术极客和超级销售的收入能超过总经理。
3. **提成阶梯化**：设置底线目标、基础目标和冲刺目标，越往上提成比例越高，刺激员工主动挑战高目标。

### 落地工具
- **《薪酬宽带等级表》**
- **KSF（关键成功因子）薪酬绩效模式**：把员工的薪酬与企业的利润、产值、质量、成本等多个关键指标挂钩。

### 经典案例
- **华为的薪酬体系**：“以奋斗者为本”，通过高底薪抢夺顶尖人才，通过TUP（奖励期权计划）和ESOP（员工持股计划）让十几万员工变成事业合伙人，力出一孔。

### 常见误区
- 只给高底薪不重考核，养了一群毫无斗志的“养老族”。
- 提成制度朝令夕改，员工一旦拿多了老板就眼红降提成，彻底摧毁团队信任。

---

## 第七机制：绩效机制（解决"效"的问题）

### 核心理念
- 绩效的目的是为了改进，不是为了扣钱！赛马不相马，结果论英雄。
- 没有考核就没有管理。凡是公司想得到的结果，都必须纳入考核。

### 操作步骤
1. **分层设定指标**：高层考核战略落地（如OKR），中层考核部门协同和目标达成度，基层考核执行力和具体动作（如每天打多少个电话、残次品率）。
2. **数据透明公开**：建立数据看板，每天在早晚会上公布排名，让落后者如坐针毡，让优秀者充满自豪感。
3. **强制绩效面谈**：每月底，主管必须与下属进行一对一绩效面谈，分析差距，制定下个月的改进计划。

### 落地工具
- **《目标责任书》**（军令状）：年初签订，白纸黑字，仪式感拉满。
- **《月度绩效评估与面谈记录表》**。

### 经典案例
- **GE（通用电气）的末位淘汰制（活力曲线）**：杰克·韦尔奇坚持每年将员工分为前20%、中间70%和后10%，必须淘汰最后的10%，以保持组织的狼性与活力。

### 常见误区
- 考核指标拍脑袋定，无法量化（如考核“工作态度积极”），导致打分全凭人情。
- 考核结果只用来发工资，没有用于员工能力的提升辅导。

---

## 第八机制：晋升机制（解决"位"的问题）

### 核心理念
- 晋升不仅是给员工现在的肯定，更是给他们未来的希望。没有通道，留不住有野心的人才。
- 破除论资排辈，让“能者上，平者让，庸者下”。

### 操作步骤
1. **双通道设计**：建立“管理通道”（M序列，带团队）和“专业通道”（P序列，钻研技术/业务），满足不同性格人才的发展需求。
2. **建立任职资格标准**：明确从初级到中级、高级、专家的具体硬性条件（如：连续3个季度业绩达标、带出2个合格徒弟、通过转正考试等）。
3. **竞聘上岗制**：所有主管及以上岗位空缺，优先内部公开竞聘，通过述职报告、答辩、民主评议来选拔，做到公平公正。

### 落地工具
- **《员工职业发展双通道模型图》**
- **《内部竞聘管理办法》及配套打分表**。

### 经典案例
- **阿里巴巴的P序列与M序列**：一个P8级别的技术专家（高级专家），不带团队，但其薪酬待遇和权限可以等同于M3级别的总监，让技术人员安心搞技术。

### 常见误区
- 把最优秀的销售提拔为销售经理，结果公司失去了一个销冠，多了一个平庸的管理者（彼得原理）。
- 晋升全靠老板一句话，员工觉得不公平。

## 第九机制：营销机制（解决"销"的问题）

### 核心理念
- 营销是企业的发动机。酒香也怕巷子深。
- 彻底摆脱对“明星销售员”的依赖，建立一套“铁打的营盘”，实现流水线式销售。

### 操作步骤
1. **提炼销冠心法**：把公司销冠逼到墙角，让他吐出怎么破冰、怎么挖需求、怎么逼单的全部细节。
2. **打造销售漏斗模型**：把销售过程拆解为：线索获取→客户建档→首次跟进→方案报价→商务谈判→签单回款。监控每个环节的转化率。
3. **全员营销与CRM管理**：通过系统强制录入客户信息，客户属于公司而非个人。利用新媒体（短视频、直播）建立全网矩阵，实现低成本获客。

### 落地工具
- **《销售标准化话术本》（百问百答）**：包含所有客户可能提出的拒绝理由及标准破解话术。
- **客户关系管理系统（CRM）**。

### 经典案例
- **中供铁军（阿里早期销售团队）**：通过极其严酷的培训（形成肌肉记忆）、标准化的拜访流程（每天必须跑满多少家）和强大的CRM考核，硬生生把一批普通人变成了全国最强悍的销售铁军。

### 常见误区
- 销售全凭个人天赋，新人存活率极低。
- 老销售把持着大客户资源要挟公司，一旦离职客户全部流失。

## 二、规划阶段：分步实施，小步快跑

### 2.1 数字化转型路径图（接地气版）

**阶段一：数字化基础（0-6个月）**  
**投入：低（5-15万） | 见效：3-6个月**

1. **生产数据采集**
   - 工具：黑湖小工单（2天部署，月均2300元起）
   - 目标：工单电子化、工时自动统计、设备状态监控
   - HTYCNC应用：每台CNC设备装传感器，实时采集开机率、故障时间

2. **质检数字化**
   - 工具：AI视觉质检系统（如华为工业AI、百度EasyDL）
   - 目标：0.02mm精度缺陷识别，准确率98.5%+
   - HTYCNC应用：铝合金表面划痕、毛刺、尺寸偏差自动检测

3. **客户管理数字化**
   - 工具：简道云/钉钉+轻量CRM
   - 目标：询盘响应<2小时，客户跟进记录可追溯

**阶段二：系统集成（6-12个月）**  
**投入：中（20-50万） | 见效：6-12个月**

1. **MES系统选型**（50-200人规模对比）

| 厂商 | 适用场景 | 价格 | 部署周期 | 优势 | 劣势 |
|------|---------|------|---------|------|------|
| **黑湖小工单** | 中小工厂首选 | 2-10万/年 | 2天 | 云化SaaS、低门槛、快速上线 | 高级功能需定制 |
| **用友MES** | 已用用友ERP | 30-80万 | 3-6个月 | ERP-MES协同好 | 实施周期长 |
| **鼎捷MES** | 离散制造业 | 50-150万 | 6-12个月 | 行业深耕、功能全 | 价格高、需本地化 |
| **SAP/西门子** | 大型企业 | 200万+ | 12个月+ | 国际标准 | 不适合中小企业 |

**HTYCNC推荐方案**：
- 初期：黑湖小工单（快速验证价值）
- 成熟期：黑湖MES或鼎捷MES（已有鼎捷ERP则选鼎捷）

2. **ERP系统升级**（如已有系统）
   - 目标：打通MES-ERP数据，实现"订单→排产→生产→质检→交付"全流程数字化
   - 关键：选择API开放、支持二次开发的系统

**阶段三：智能化应用（12-24个月）**  
**投入：高（50-150万） | 见效：12-24个月**

1. **AI排产优化**
   - 技术：机器学习算法，基于历史数据优化排产
   - 效果：换产时间缩短30%，设备利用率提升20%

2. **预测性维护**
   - 技术：设备振动/温度传感器+AI预测模型
   - 效果：非计划停机减少20-40%，维护成本降10%

3. **数字孪生车间**
   - 技术：3D可视化+实时数据
   - 效果：远程监控、虚拟调试、提前发现瓶颈

### 4.3 常见坑与失败原因

**坑1：盲目追求大而全**
- 表现：一次性上ERP+MES+WMS+PLM，投入200万+
- 后果：系统复杂，员工不会用，80%功能闲置
- 避坑：从最痛的点切入，单模块验证后再扩展

**坑2：只买系统不做流程优化**
- 表现：系统照搬线下流程，数字化变成"电子化"
- 后果：效率没提升，反而增加录入负担
- 避坑：先做流程再造（BPR），去掉不增值环节

**坑3：高层不重视，IT部门单打独斗**
- 表现：老板觉得"买个软件就行"，不参与不推动
- 后果：各部门不配合,项目烂尾
- 避坑：一把手工程，纳入战略KPI

**坑4：忽视数据治理**
- 表现：数据口径不统一，ERP/MES数据打架
- 后果：报表不可信，决策靠拍脑袋
- 避坑：建立数据标准，主数据管理（MDM）

**坑5：过度依赖供应商**
- 表现：所有需求都找供应商定制，成本失控
- 后果：实施周期拖延，费用超预算2-3倍
- 避坑：80%用标准功能，20%定制；培养内部团队

**坑6：数字营销烧钱无效果**
- 表现：盲目投Facebook/Google广告，转化率<1%
- 后果：月烧2万美金，0成交
- 避坑：先做内容（短视频+案例），再投广告；小额测试，数据驱动
