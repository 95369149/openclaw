# 厂长个人 AI 操作系统｜资料入池规则 v0.1

## 入池原则

目标：把“以后还会反复用”的东西留下来，把“看过就算”的垃圾挡在外面。

## 一、该进中枢的内容

### 厂长学习中枢

- 值得反复查的文章、PDF、书摘、课程讲义
- AI / 管理 / 英语 / 演讲 / 古文学相关资料
- 未来可能拿来总结、分享、复盘的材料

### 女儿学习中枢

- 课本、讲义、练习题、错题
- 安全、适龄、明确用途的阅读资料
- 未来要反复复习的内容

### 厂长自媒体资料池

- 案例、观点、数据、素材原文
- 可转化成短视频 / 文章 / 讲话的资料
- 风格样本、爆款结构样本、表达样本

## 二、不该进中枢的内容

- 一次性聊天记录
- 没价值的碎片截图
- 临时通知
- 无法确认来源的垃圾内容
- 看完就丢、未来不会复用的东西

## 三、处理顺序

1. 先判断属于哪一个中枢
2. 再决定是否上传 NotebookLM
3. 上传后记录一句“这批资料是干什么的”
4. 后续所有提问优先基于对应中枢进行

## 四、提问原则

- 问学习问题 → 先用厂长学习中枢
- 问女儿辅导问题 → 先用女儿学习中枢
- 问内容选题 / 素材整理 → 先用厂长自媒体资料池

## 五、系统目标

NotebookLM 负责：

- 存资料
- 检索
- 引用
- 资料内回答

OpenClaw / Claude 负责：

- 推理
- 编排
- 输出
- 行动建议
