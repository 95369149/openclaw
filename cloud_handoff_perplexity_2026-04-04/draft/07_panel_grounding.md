## 7.5 配电板布局分区（v0.2 新增，基于用户确认清单）

配电板尺寸：1650×350mm（横向安装板）

### 分区原则

```
 ←—————————————————————————— 1650mm ——————————————————————————→
 ┌──────────────┬──────────────────┬──────────────┬────────────┐
 │  A区 强电    │  B区 伺服驱动    │  C区 控制    │  D区 端子  │
 │  ~380mm      │  ~500mm          │  ~420mm      │  ~350mm    │
 │  380V/220V   │  220V动力+编码器 │  DC24V弱电   │  现场接线  │
 └──────────────┴──────────────────┴──────────────┴────────────┘
```

- A区：RCD、QF0、KM1（CJX2-1810）、KM2、QF2、EMI1、EMI2
- B区：QF3~QF8、SRV1~SRV5（DS2系列）、TC-6832
- C区：PS1（S-250-24）、CB1~CB4、SF1（Pilz）、KA继电器组×7
- D区：XT-IN（蓝20节）、XT-OUT（橙16节）、XT-PE（黄绿8节）、XT-MP（24芯）、PE铜排

### 强弱分离规则

| 规则 | 说明 |
|------|------|
| H1（动力）与 H2（控制）上下间距 | ≥80mm |
| H4 编码器线槽 | 铝合金封闭，全程不与其他线槽共槽 |
| A区与C区 | 由B区物理隔断，V2竖槽为强弱分界 |
| 继电器组 | 集中C区，远离A区强电 ≥300mm |
| 伺服动力线（H5） | 走B区上方，不经过C区 |
