## 1.2 主回路拓扑（已确认）

```
三相 380V + N + PE  进线（W-MAINS）
    │
  ┌─────────────────────────────────┐
  │  左侧小配电箱（与变频器同箱）      │
  │  QF-MAIN（总断路器 3P+N 125A）   │
  │  VFD1（变频器 上海奔日/贝士德）   │
  └──────────────┬──────────────────┘
                 │
  ┌──────────────▼──────────────────┐
  │  大配电箱                        │
  │  RCD（漏保 32A，30mA）           │
  │    │                            │
  │  QF0（施耐德 NSX100F 3P+N 63A） │
  └──────────────┬──────────────────┘
                 │  W-L1A / W-L2A / W-NA
                 ├──────────────────────────────┐
                 │                              │
              KM1（CJX2-1810，主接触器）    KM2（NC1-12，风机接触器）
                 │  W-L1B / W-L2B               │  W-FAN-U/V/W
                 │                            风机 9kW 380V（瑞驰/金桥通）
              QF2（1P 20A）
                 │  W-L1B
              EMI1（主回路 EMI 滤波器，20A）
                 │  W-L1C / N → 220V 伺服总线（W-AC220-BUS）
                 │
  ┌──────┬──────┬──────┬──────┬──────┐
 QF3    QF4    QF5    QF6    QF7    QF8
 6A     6A     6A     4A     4A     6A
  │      │      │      │      │      │
SRV1   SRV2   SRV3   SRV4   SRV5   PS1
400W   400W   400W   100W   100W  24V/10A
前后轴1 前后轴2 左右轴  升降轴  旋转轴
```

> 注：伺服驱动器供电为单相 220V（L1C + N），非三相。  
> 注：总断路器 125A 和变频器在左侧小配电箱，不在大配电箱 BOM 范围内。

**线号规则（已确认）：** `W-[总线名]-[支路号]`，例：W-L1A = QF0 之后 L1，W-SRV3-L = SRV3 进线 L，W-PE2 = SRV2 接地线
