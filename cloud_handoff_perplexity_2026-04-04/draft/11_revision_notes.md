## 原图存在的主要问题（用户指出）

**核心问题：强电与弱电未分流**

原图中以下回路混走，不符合工业电气规范：
1. 380V/220V 动力线与 DC24V 控制线未分槽走线
2. 110V 控制电源（变压器降压）与 DC24V 逻辑混用，电压等级混乱
3. 伺服驱动器 CN1 脉冲信号线与动力线未隔离
4. 编码器线（CN2）与动力线未分开
5. 无 EMI 滤波器（原图未见）

## 强弱电分流改版要点

### 分流原则（按 GB/T 6988 + GB14048）

```
强电回路（≥220V）          弱电回路（≤DC24V）
─────────────────          ─────────────────
H1 线槽（红色 50×50）      H2 线槽（24V 控制，40×40）
主回路动力线               H3 线槽（信号线，40×25）
380V 进线                  H4 铝合金封闭槽（编码器专用）
KM1/KM2 主触点线           H5 线槽（信号，40×40）
VFD 进出线（U/V/W）        脉冲线（ASTP 2对 0.2mm²）
伺服动力线（RVVP 1.5mm²）  编码器线（ASTP 6对 0.2mm²）
```

### 关键隔离要求

1. 动力线与控制线**物理分槽**，不得共槽
2. 伺服动力线（U/V/W）与编码器线间距 ≥ 50mm，或用铝合金封闭槽隔离
3. VFD 输出线（U/V/W）单独走线，不与其他线共槽
4. 24V 控制线与 220V/380V 动力线交叉时，必须垂直交叉，不得平行走线
5. 拖链内分层：气管（上）→ 动力线 → 24V 控制线 → 信号线 → 编码器线（下）
