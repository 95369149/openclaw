# OpenClaw 深度集成到红太阳内部运营

## Executive Summary

这个项目的目标是把 OpenClaw 从个人 AI 助手升级为红太阳的组织级数字中枢，服务于客服、销售、内容、管理和知识沉淀。

## State

- 类型：项目
- 当前状态：持续推进
- 重要性：P0
- 关键关系：Kitt、红太阳、AI 落地、自动化工作流

## Compiled Truth

- 项目核心不是“接更多模型”，而是把 AI 真正嵌进业务动作链。
- 已知高价值方向包括：客服自动回复、数据分析、内容生产、知识沉淀、流程提醒。
- 成本策略上倾向优先使用中国模型与低成本方案，但关键节点不排斥高质量付费模型。
- 当前新增的 `brain/` 结构，正是把 OpenClaw 从“会做事”升级为“会积累长期知识”的关键步骤。
