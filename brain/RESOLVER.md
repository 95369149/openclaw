# RESOLVER.md

本目录是 Kitt 的长期知识脑（brain），不是运行记忆（memory）。

## 先判定：写到 brain 还是 memory

- **memory/**：运行态、任务态、规则、今天发生了什么、agent 协作痕迹、配置风险、执行日志
- **brain/**：关于世界的长期知识，尤其是人、公司、项目、概念、制度、内容资产、历史脉络

## 一级路由

1. **人** → `people/`
2. **公司/组织/品牌** → `companies/`
3. **正在推进的具体事项/系统/项目** → `projects/`
4. **尚未开工但值得保留的想法** → `ideas/`
5. **可复用的方法论/认知/框架** → `concepts/`
6. **组织制度/企业文化/管理机制** → `org/`
7. **内容资产/对外叙事/IP 方向** → `media/`
8. **原始材料、导入源、外部抓取、转录件** → `sources/`
9. **一时分不清先暂存** → `inbox/`
10. **废弃或历史冻结内容** → `archive/`

## 决策规则

- 同一实体只能有一个主页面，避免重复建页。
- 每个页面采用 **Compiled Truth + Timeline** 双层结构：
  - 上半部分：当前结论 / 状态 / open threads
  - `---` 下半部分：按时间倒序追加事实记录
- 新信息优先更新已有页面，不轻易新建重复页。
- 新内容落页前，先在相邻目录查重。

## 当前适配原则（针对厂长这台机器）

- `memory/` 保持现有职责：Agent 记忆与运行状态
- `brain/` 新增职责：红太阳经营知识、人物画像、项目脉络、方法论沉淀
- 先从高价值页面开始，不做全量搬家
