# 售后高频问题 SOP 候选池

## Executive Summary

这不是最终 SOP 成品，而是根据近期售后电话数据整理出的优先制作清单，目的是把重复电话变成可复用的图文、视频和排障步骤。

## State

- 类型：SOP backlog
- 当前状态：初版候选池
- 重要性：P1
- 关键关系：售后、培训、内容、客户满意度

## Compiled Truth

- 高优先级题目已经出现明显聚类：切不透材料、驱动器报警、调对角线、换震动刀、跑料、换刀片、图形异常、刀芯方向不对。
- 这些题目适合做成“三件套”：文字 SOP + 微信短视频 + 售后知识页。
- 同一题目一旦出现第 2 次，就值得标准化；第 3 次开始就应该作为培训与预防内容。

## Candidate Queue

- [ ] 切不透材料：检查刀尖、材料硬度、刀深、速度参数
- [ ] 驱动器报警：报警类型识别、复位、常见原因排查
- [ ] 调对角线：步骤、注意事项、什么时候需要拆毛毡
- [ ] 更换震动刀：安装、刀深、速度联调
- [ ] 送料跑料：气压、压料、送料机构检查
- [ ] 更换刀片：标准教学流程
- [ ] 打板图形变大 / 图形超界面：软件与定位参数检查
- [ ] 刀芯方向不对：方向识别与安装修正
