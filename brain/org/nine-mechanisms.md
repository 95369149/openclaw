# 红太阳九大机制

## Executive Summary

九大机制是厂长的核心管理操作系统，不是口号，而是红太阳日常管理节奏、执行文化和组织控制力的底层框架。

## State

- 类型：组织制度 / 管理机制
- 当前状态：已作为核心管理信仰长期执行
- 重要性：P0
- 关键关系：厂长、红太阳、培训、执行力、组织升级

## Compiled Truth

- 九大机制分别是：早启动、晚复盘、军令状、红黑榜、师徒制、积分制、PK制、会议制、培训制。
- 它们共同作用于目标明确、节奏管理、公开激励、责任绑定、持续成长。
- 这是厂长的管理信仰，不能轻易挑战，只能优化其落地方式。
- Kitt 后续给管理建议时，最好主动挂接到九大机制中的某一项，否则建议会显得悬空。
